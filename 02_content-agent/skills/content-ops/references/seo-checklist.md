# SEO 체크리스트

## 필수 필드 (HIGH)

### 1. metaTitle (30-60자)
- [ ] 핵심 키워드를 앞부분에 배치
- [ ] 30자 이상 60자 이하
- [ ] 페이지 제목과 다른 표현 (중복 방지)
- [ ] 클릭을 유도하는 표현 포함 (방법, 가이드, 완벽 정리 등)

**좋은 예:** "AI 마케팅 자동화로 전환율 200% 높이는 5가지 전략"
**나쁜 예:** "AI 마케팅" (너무 짧음)

### 2. metaDescription (120-160자)
- [ ] 120자 이상 160자 이하
- [ ] 핵심 키워드 자연스럽게 포함
- [ ] 독자가 얻을 가치 명시
- [ ] 행동 유도 문구 (알아보세요, 확인하세요 등)

**좋은 예:** "AI 기반 마케팅 자동화 전략 5가지를 실무 사례와 함께 소개합니다. 전환율 개선부터 고객 세그먼트 자동화까지, 마케터가 바로 적용할 수 있는 가이드를 확인하세요."
**나쁜 예:** "AI 마케팅 자동화에 대해 알아봅시다." (너무 짧고 가치 불명확)

### 3. 본문 구조
- [ ] H2 헤딩 3개 이상 사용
- [ ] 본문 300단어 이상
- [ ] 핵심 키워드가 첫 100단어 안에 등장
- [ ] 내부 링크 1개 이상 (관련 글 연결)

## 권장 필드 (MEDIUM)

### 4. ogTitle (40-60자)
- [ ] SNS 공유 시 클릭을 유도하는 제목
- [ ] metaTitle과 약간 다른 표현 (호기심 유발)
- [ ] 이모지 사용 가능 (과도하지 않게)

### 5. ogDescription (80-120자)
- [ ] SNS에서 읽히는 간결한 요약
- [ ] 가치 제안 중심
- [ ] metaDescription보다 짧고 임팩트 있게

### 6. ogImage
- [ ] 설정 여부 확인
- [ ] 1200x630px 권장
- [ ] 텍스트 오버레이 시 가독성 확인

## 선택 필드 (LOW)

### 7. canonicalUrl
- [ ] 중복 콘텐츠가 있는 경우만 설정
- [ ] 원본 URL을 정확히 지정

### 8. noIndex
- [ ] 기본값 false 확인
- [ ] 테스트/임시 페이지만 true

## 콘텐츠 타입별 키워드 전략

### Post (인사이트)
- 롱테일 키워드 타겟 ("AI 마케팅 자동화 방법" > "마케팅")
- 제목에 숫자 활용 ("5가지", "3단계")
- "방법", "가이드", "전략", "사례" 등 검색 의도 키워드

### FAQ
- 질문형 키워드 ("~란?", "~하는 방법은?")
- "뜻", "차이", "비교" 등 정보 탐색 키워드
- 구조화 데이터(FAQ Schema) 활용 가능

### Class (용어사전)
- 정의형 키워드 ("~란", "~이란", "~뜻")
- 영어 원문 + 한국어 번역 동시 노출
- 관련 용어 내부 링크 네트워크

## 점수 산출 기준

| 체크 항목 | 가중치 | PASS 기준 |
|----------|--------|----------|
| metaTitle 길이 | 15 | 30-60자 |
| metaDescription 길이 | 15 | 120-160자 |
| 본문 길이 | 10 | 300단어 이상 |
| ogImage 설정 | 10 | 존재 여부 |
| 헤딩 구조 | 5 | H2 사용 여부 |

**총점 = (획득 가중치 / 전체 가중치) × 100**
