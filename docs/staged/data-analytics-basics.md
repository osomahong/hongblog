데이터 분석 기초는 마케터가 매일 만나는 숫자를 모으고 읽고 보여주는 세 단계를 순서대로 정리한 코스입니다. 통계학 전공자가 아니라 광고 리포트와 GA4 화면을 보며 판단해야 하는 실무자를 위해 만들었습니다.

모으는 단계에서는 GA4의 구조, GTM의 역할, UTM 파라미터 다섯 가지, 세션과 이벤트와 사용자의 관계, 참여율과 이탈률을 다룹니다. 읽는 단계에서는 평균과 중앙값의 차이, 표준편차, 상관관계와 회귀분석, 표본과 p값, AB 테스트 설계를 다룹니다. 보여주는 단계에서는 대시보드 구성, 태블로와 루커 스튜디오, 데이터 마이닝과 NPS를 다룹니다.

데이터가 쌓이는 곳을 알아야 하는 실무자를 위해 ETL과 데이터 웨어하우스, 레이크, 마트, 빅쿼리, 마케터가 쓰는 SQL도 뒤쪽에 넣었습니다. 코드를 쓸 일은 SQL 한 강뿐이고 나머지는 화면과 개념으로 따라갈 수 있습니다.
