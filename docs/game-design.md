# AI 오피스 서바이벌 — 게임 설계 문서

> `feat/office-survival-game` 브랜치에 구현되어 있던 턴제 시뮬레이션 게임의 설계를 텍스트로 보존한 문서. 실제 구현(엔진/UI/테스트/시나리오 코드)은 폐기하고, 개발 의도·구성·진행 개요·결과 노드만 남긴다.

## 개발 의도

- 배경: XP/배지/진행률 추적형 게이미피케이션(`feat/gamification-learning`, 2026-06-12 전량 폐기)을 "콘텐츠 흐름에 진행바만 붙여놓고 게임이라 우기는 방식"으로 판단해 폐기함.
- 핵심 원칙: 게임이려면 플레이어가 내리는 **의미 있는 선택 → 결과 → 실패 가능성**이 있어야 한다. 점수판(XP/배지)이 아니라 게임플레이 메커니즘부터 설계할 것.
- 방향: 신입/저연차 직장인이 한 주(월~금) 동안 실제 업무를 AI에게 위임하거나 직접 처리하며 생존하는 턴제 시뮬레이션. 인게임 학습이 그 자체로 완결되고, 블로그 인사이트·클래스 글은 보조 링크로만 연결.
- 판정에는 난수를 쓰지 않는다: "맞게 했는데 운으로 망함"은 교육 게임에서 학습을 부정하는 설계라고 보고, 선택과 결과를 결정론적으로 연결했다.

## 구성 (게임 시스템)

### 자원
- **time**: 하루 남은 시간 블록 (일별 예산이 다름, 소진 시 야근/강제 퇴근 분기)
- **energy**: 0~10, 0이 되면 강제 퇴근
- **trust**: 0~100, 신뢰. 0 이하가 되면 게임오버
- **kpi**: 누적 성과 점수, 엔딩 산정에 사용

### 업무 처리 3방식과 판정
- **직접 처리**: 품질 점수(Q) 6 고정 → 항상 "통과"지만 시간·에너지 비용이 비싸고 "우수" 등급이 나오지 않는다.
- **AI 위임**: Q = 3(기본) + 요구 요소와 일치하는 프롬프트 카드 1장당 +3, 검증 선택 시 +1
- **가명화 후 위임**: 위 위임 계산에 +2 보너스 (기밀 업무 전용 우회 경로)
- 등급: Q≥9 우수 / Q 6~8 통과 / Q<6 반려(재작업 기회 1회, 다시 반려되면 마감 실패로 전환)

### 프롬프트 카드 = 학습 개념 8개 (해금형)
1. **역할 지정** — 프롬프트 카드 [역할]
2. **맥락 제공** — 프롬프트 카드 [맥락]
3. **예시 제시** — 프롬프트 카드 [예시]
4. **결과 검증** — 제출 전 [검증하고 제출]
5. **위임 판단** — 업무 카드에 위임 적합도 힌트 표시
6. **민감정보 주의** — 기밀 업무에 [가명화 후 위임] 가능
7. **단계 분해** — 프롬프트 카드 [단계분해]
8. **반대 의견 요청** — 점검 업무에서 비판 요청 선택지 활성화

각 개념은 관련 블로그 클래스 글(`prompt-engineering-basics`, `what-is-hallucination`, `four-ds-of-ai-fluency`, `responsible-ai-use`, `what-is-sycophancy`)과 연결되어, 게임 내 학습과 실제 콘텐츠가 이어지도록 설계했다.

### 함정 태그 (업무별 특수 분기)
- **confidential + 가명화 없는 AI 위임** → 제출 여부와 무관하게 즉시 보안 사고 발동 (신뢰 대폭 하락)
- **trivial + AI 위임** → 결과는 "통과"로 고정되지만 결국 직접 마무리가 필요해 시간 손해만 발생 (잡무는 직접 처리가 더 싸다는 걸 학습시키는 장치)
- **hallucination + 미검증 제출** → "지연 폭탄" 장전. 표면상 정상 통과하지만, 금요일 보스전에서 근거를 추궁당하며 발각됨

### 하루 루프
아침 브리핑 → 업무 선택 → 업무별 처리 방식 결정(직접/위임/가명화 위임 + 검증 여부) → 판정 결과 확인 → (반려 시 1회 재작업 기회) → 점심/커피로 에너지 회복 선택 → 시간 소진 시 야근 여부 선택(수락 시 에너지 대량 소모로 잔여 업무 처리, 거부 시 마감 실패 처리) → 하루 정산(회고에서 놓친 개념을 보상으로 지급받기도 함)

## 진행 개요 — 챕터 1 "AI 기초" (1주차 5일)

| 요일 | 제목 | 핵심 사건 |
|---|---|---|
| 월 | 도구가 먼저 출근했다 | 역할·맥락 개념 첫 학습. 회의록 정리, 거래처 일정 연기 회신, AI 도구 사용 신청서 |
| 화 | 너무 깔끔한 보고서 | 예시·검증 개념 학습. 30페이지 보고서 요약, 시장 규모 조사(hallucination 함정 태스크 내장), SNS 이벤트 문구, 영문 계약 메일 번역 |
| 수 | 맡길 일과 맡기면 안 되는 일 | 위임 판단·민감정보 개념 학습. 신제품 단가표 요약(대외비 함정), 회의실 예약, 경쟁사 신제품 분석, 보고 방향 1장 정리 |
| 목 | 보고 전야 | 단계 분해 개념 학습. 본부장 보고서 초안과 부록 준비 |
| 금 | 14시, 본부장 보고 (디데이) | 오전 잔무 2건(최종 오탈자 점검, 배포용 1장 요약) 처리 후 보스전 돌입 |

### 보스전 (금요일 보고, 3라운드 Q&A)
1. **R1 — 시장 성장 근거**: 검증됨(5점) / 보류·금일 회신(3점) / 현장 체감(1점) / "AI라 정확할 것"(0점, 책임 소재를 되묻는 역풍)
2. **R2 — 경쟁사 점유율 근거**: 화요일 시장 조사 태스크를 검증하지 않았다면 여기서 근거 없는 출처(가상 기관)가 발각됨. 검증했다면 부록으로 방어해 만점
3. **R3 — 다음 분기 실행안**: 단계 분해 개념을 보유하고 있으면 "3단계로 나눴다"는 최고점 선택지가 해금됨

통과선(passScore)은 한 주간 쌓은 준비도(사전 업무 품질 누적)와 Q&A 점수 합산으로 결정되며, 검증·단계분해 개념을 놓친 플레이는 통과선 근처에서 아슬아슬해지도록 설계했다.

## 결과 노드 (엔딩 / 게임오버)

### 정상 엔딩 (보스전 통과 시, trust·kpi 기준 우선순위 순 첫 매치)
- **엔딩 A: 팀의 AI 에이스** — 신뢰 90 이상 + KPI 40 이상. 신사업 리드 제안까지 받는 최상 엔딩
- **엔딩 B: 무사히 한 주 생존** — 신뢰 40 이상. 무난한 통과, 다음 주에 대한 기대로 마무리
- **엔딩 C: 턱걸이 통과** — 조건 없음(catch-all). 보고는 통과했지만 경고성 면담이 남음

### 게임오버 (3가지 원인)
- **신뢰 게임오버**: 신뢰 0 이하 → "프로젝트 제외" (다른 업무로 배치 전환)
- **보안 게임오버**: 대외비 유출 2차 위반 → "보안 사고" (징계위원회 회부)
- **보고 게임오버**: 보스전 통과선 미달 → "보고 실패" (금요일 아침으로 돌아가고 싶은 심정으로 마무리)
