## 2. 클로드 코워크 묶음 진단

### 2.1 세 글이 같은 검색어를 나눠 받는다

180일 기준이다. 같은 검색어를 두 페이지가 함께 받고 있다.

| 검색어 | claude-cowork-what-you-can-do | claude-cowork-5-ai-tasks | claude-work-use-cases |
|---|---|---|---|
| 클로드 코워크 사용법 | 1,370 (8.2위) | 475 (3.5위) | |
| 클로드 활용 사례 | 496 (6.3위) | | 102 (4.4위) |
| 클로드 업무 자동화 사례 | 369 (4.5위) | | 21 (11.5위) |
| 클로드 업무 활용 | 332 (5.8위) | | 64 (2.4위) |

**순위가 높은 쪽이 노출을 적게 받는 역전이 네 건 모두에서 나타난다.** `클로드 업무 활용`은 work-use-cases가 2.4위인데 노출 64이고, what-you-can-do는 5.8위인데 노출 332다. 구글이 어느 페이지를 보여줄지 정하지 못한 상태로 보인다.

### 2.2 원인은 제목과 메타와 섹션의 어긋남

세 글의 현재 상태다.

| 글 | 제목이 말하는 것 | metaDescription이 말하는 것 | 실제로 받는 검색어 |
|---|---|---|---|
| what-you-can-do | 코워크 기능 총정리 | "실전 활용법을 정리합니다" | 코워크 30,441 + 활용 사례 1,197 |
| 5-ai-tasks | 해야 할 5가지 AI 작업 | 먼저 시도해 볼 5가지 작업 | 코워크 사용법 475 |
| work-use-cases | 업무 활용 사례 4가지와 프로젝트 설정법 | "클로드 프로젝트는 작업 공간입니다" | 업무 활용 64 |

세 가지가 어긋나 있다.

- **what-you-can-do**: 제목은 기능인데 메타가 활용법을 말한다. 본문에도 `실전 활용 사례 5가지` 섹션이 있어 사례 검색어를 끌어간다.
- **5-ai-tasks**: 앞쪽 H2 두 개가 `클로드 코워크로 뭘 할 수 있나요`, `클로드 코워크 쓰면 뭐가 좋은가요`인데 이것이 what-you-can-do의 주제와 겹친다. 정작 `클로드 코워크 사용법`으로 3.5위를 받고 있는데 제목에 사용법이라는 말이 없다.
- **work-use-cases**: 제목은 업무 활용 사례인데 metaDescription 첫 문장이 프로젝트 정의로 시작한다. 제목과 메타와 본문 도입부의 개체를 맞추는 규칙에 어긋난다.

### 2.3 what-you-can-do는 조심해서 다룬다

이 글은 `클로드 코워크` 하나로 30,441노출에 클릭 1,034를 받는 주력이다. 사이트 전체에서도 상위권이다. 본문을 크게 바꾸면 잃을 것이 크므로, 이 글은 메타와 링크만 고치고 섹션 구조는 유지한다.
