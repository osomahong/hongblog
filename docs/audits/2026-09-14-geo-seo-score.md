# 전체 콘텐츠 GEO/SEO 점수 점검 (2026-09-14)

362편(insights 220, classes 131, courses 11) 전수 측정과 보강 기록이다.

## 측정 도구

`npm run check:geo` (`scripts/geo-seo-score.ts`). 규칙 원본은
`.claude/skills/inspect-content/references/{seo,aeo,geo}-rules.md`이고, 그 가운데
결정론으로 판정 가능한 층을 전수 실행한다.

종합 점수 = SEO × 0.35 + AEO × 0.30 + GEO × 0.35. 타입별로 적용되지 않는 규칙은
N/A로 빼고 적용 가중치 합으로 나눠 100점으로 환산한다.

### 원본 명세에서 바꾼 기준

| 규칙 | 원본 | 이 저장소 | 이유 |
|---|---|---|---|
| R-SEO-01 | metaTitle 30~60자 | 표시 폭 18~36 | `check-titles.ts`가 표시 폭 36을 SOFT 상한으로 쓴다. 글자 수로 재면 두 검사가 반대 방향을 가리킨다 |
| R-SEO-06 | ogTitle + ogDescription | ogDescription만 | `check-titles.ts`가 metaTitle의 축약판 ogTitle을 SOFT로 지적한다. 공유용 문장이 따로 없으면 없는 편이 맞다 |
| R-AEO-02, R-AEO-03 | classes 면제 | classes도 적용 | 클래스도 FAQPage를 발행한다. 면제하면 실제 구멍이 가려진다 |
| R-AEO-05 | 요약 헤딩 + summary3 둘 다 | 둘 중 하나 | summary3는 화면에서 잠겨도 HTML에는 항상 들어간다(`src/lib/summary-gate.ts`). 답변 엔진 기준으로는 같은 값이다 |
| R-AEO-07 | 모든 약어 | 본문에 3회 이상 쓰인 약어, 일반 약어 제외 | AI, PDF, PNG까지 정의를 요구하면 오탐이 전체의 절반을 넘는다. 내부 링크가 걸린 용어는 정의된 것으로 센다 |

`R-GEO-01`(출처 인용)과 `R-GEO-02`(통계 밀도)는 보강 작업 목록에서 제외했다. 없는 근거와
수치를 지어내는 것이 점수를 올리는 가장 빠른 길이기 때문이다. 측정은 하되 조치는
주제별로 따로 판단한다.

## 찾은 결손

### 1. 코스 페이지의 세팅 결손 세 가지

하위 11편이 전부 코스였다. 본문 문제가 아니라 페이지 쪽 결손이었다.

- **코스의 `summary3`가 어디에서도 렌더되지 않았다.** `getCourseSummary3()` 함수와
  `ContentSummary`의 `course` 분기까지 있는데 페이지가 부르지 않아 11편의 3줄 요약이
  HTML에 한 줄도 나가지 않았다. 인사이트만 렌더하고 있었다
- **코스 소개 본문이 `stripMarkdown`을 거쳐 단일 문단으로 출력됐다.** 표와 목록, 질문형
  헤딩을 넣어도 화면에 구조가 남지 않는다
- **클래스와 인사이트가 발행하는 FAQPage를 코스만 발행하지 않았다**

`Course.content`에 원본 마크다운을 담고 `description`은 첫 문단으로 좁혔다. 코스 목록
카드가 소개 세 문단을 통째로 물고 오던 것도 함께 고쳐졌다.

### 2. llms.txt의 코스 목록 누락

11개 코스 가운데 6개만 적혀 있었고, 디지털 마케팅 핵심 용어 코스의 개념 수가 11개로
적혀 있었다(실제 16개). 전체 코스와 각 코스가 담은 개념을 채웠다.
