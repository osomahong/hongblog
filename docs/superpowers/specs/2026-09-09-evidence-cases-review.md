# 독립 익명 사례 작업 전후 보고

## 변경 전과 후
기존에는 소개 페이지의 대표 사례 3개와 구역 앵커가 있었다. 이번에는 /cases 목록과 /cases/[slug] 상세 7개를 추가했다. 본문에는 총 30개의 작업 단계를 담고, 배경·담당 역할·산출물·확인 근거·성과 범위를 구분했다.

- SNS 마케팅과 생성형 AI 교육: 교안 구성, 사전 준비 협의, 개별 실습 지원, 교육 후 피드백.
- 소비재 기업 공동 교육: 요구 확인, 역할 분담, 데이터 질의응답, 참고 자료 전달.
- 온라인 서비스 구매 측정: 기존 수집 진단, 구매 시점 정의, 수정 요청, 온보딩과 잔여 검수.
- 식품 유통 사이트 분석 구축: 사이트별 개발 가이드, 화면별 점검, 집계와 권한 문의, 종료 자료 전달.
- 전자상거래 매출 정의: 실제 결제 상황 대조, 지표 의미 협의, 미검증 조건 기록.
- 분석 환경 인수인계: 작업 문서 정리, 설치·초대 안내, 종료 문서와 권한 인계 요청.
- AI 분석 도입 계획: 현황 진단, 이벤트 정비, 자연어 조회, 보고와 콘텐츠 업무 계획. 구축 완료 사례가 아니다.

소개 대표 사례에서 상세 원고로 연결하고, 교육·홈·푸터에 목록/상세 접근 경로를 추가했다. 각 사례에는 고유 metadata와 canonical, Article/BreadcrumbList를 제공하고 사이트맵에 등록했다. fragment는 상세 본문의 목차 이동 용도로 유지했다.

## 사실 확인
RAG 유사업무 검색 후 source 검색 발췌와 Notion/Drive 추출 원문, 강사명이 기재된 교안의 목차와 실습 예시를 확인했다. Gmail 전문 읽기는 추출 텍스트 없음 응답이어서 source 검색 발췌를 교차 확인했다. 전체 스레드·첨부·교안 이미지까지 검수했다고 간주하지 않는다.

다른 컨설턴트와 공동 진행한 교육의 역할을 기존 소개 요약과 교육 안내에도 반영했다. 계획, 요청, 온보딩, 종료 안내를 각각 구분했다. 개별 오류 해결률, 권한 이전 최종 승인, 매출이나 생산성 상승을 추정해 추가하지 않았다. 고객 규모도 근거 없이 대기업·중견기업 등으로 부풀리지 않았다.

개인 근거표와 고객 매핑은 저장소 밖에 보관했다. 독립 검토에서 피드백 수신을 별도 작성 산출물처럼 표현한 부분과 조사 오탈자 1건을 수정했다.

## 제3자 독자 관점 재편집
사용자의 매출 사례 수정 예시를 기준으로 7개 사례의 도입과 핵심 설명을 재편집했다. 상황을 이해할 배경, 용어 의미, 문제가 되는 이유, 실제 판단과 작업을 연결했다. 이벤트/태깅/value/매개변수/dataLayer/퍼널/온보딩/UTM/SQL/에이전트를 필요한 글에서 설명했다. 가상 주문과 쿠폰 조합 등 설명용 예시는 실제 고객 사실과 구분했다. 확인된 교육 제안6회, 사이트2개 유지.

독립 검수2건 반영: GA4 value가 임의 지표처럼 읽히지 않게 상품 금액 합계 기준과 포인트 처리 설명 추가, Google 공식 purchase 명세 대조 및 기술 참고 링크 연결. 공공교육 사전준비 반복 축소. 재검수 중대오류 없음. 본문과 목업 계산 기준 동기화.

검증: production build/변경 파일 ESLint/diff-check 통과. 문체 HARD0, SOFT22는 7개 글 합산 반복 표현으로 문맥 검토. 문어체 HARD/WARN0. HTML400개 내부 링크 오류0, 개인정보20파일/110토큰0. 목록/7개 상세390/768/1440px 총24화면 브라우저 오류/넘침0. 관련글 이동과404확인. 매출 도입 스크린샷 가독성 확인. 공개원고/localhost갱신, 커밋/배포 없음.

제목 개정: 7개 제목을 도구/과업과 실제 질문에 대응하는 문제 중심으로 변경. 독립검수에서 수행범위 과장없음 확인. 제목 표시폭24.5~29, 빌드/검색검사314경로/ESLint 통과. 모바일8페이지 가로넘침없음. H1/metadata/Article/목록 동일 title사용, URL유지. 공개 원고/localhost 갱신.
