# Class / Cases 배포 전 SEO 점검

요청: 인사이트 대비 클래스 검색 성과 차이를 실제 데이터로 진단하고 새 사례 경로의 배포 전 결함을 방지한다. 배포하지 않는다. 성과 원인은 관측과 가설로 구분한다.

Search Console readonly 성과 조회(90일/28일/직전28일)와 클래스97개 및 비교표본 URL검사. 현재 공개 HTML/robots/sitemap/headers와 빌드 HTML398개 검사. 비공개 원본 리포트는 저장소 밖에 둔다.

확인된 구조화 데이터 오류만 수정: Course.numberOfCredits에 개념수를 넣은 부분 제거, 고정1시간 대신 화면에 표시한 총 예상 학습분으로 동기화. 새 cases 경로를 전용 회귀검사에 포함한다. 사례 lastmod는 실제 원고 수정일로 관리하고 Article.dateModified와 동기화하며 공개일은 배포 전 만들지 않는다. 공식 문서와 현재 기록에서 지원되는 변경만 적용한다.

새 자동 검사: /class, /insights, /cases 빌드 HTML에 canonical/noindex/title/H1/본문/JSON-LD/사이트맵 및 실제 OG 파일 검사. 사례는 본문 문장이 script를 제외한 HTML에 존재하는지, 단계 그림이 렌더링됐는지 검증. 이미지/메타/내부링크 오류는 실패 종료. 변경된 클래스 구조화 데이터 학점/고정학습시간 회귀검사.

결과물: 관측 성과와 URL검사 요약, 원인/추정/미확인 구분, 수정 내역, 남겨둘 콘텐츠개선 우선순위, 배포 전후 체크리스트. 신규 AI 파일이나 반복 FAQ/띠카드 등 근거 약한 작업은 하지 않는다.
