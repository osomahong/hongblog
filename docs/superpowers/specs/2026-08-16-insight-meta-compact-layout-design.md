# 인사이트 메타 정보 압축 레이아웃 설계

## 목표

글 상세 상단의 날짜, 읽기 시간, 인기 상태와 태그가 모바일에서 각각 한 줄을 차지하는 문제를 해결한다. 사용 가능한 가로 공간을 우선 채우고, 화면 폭이 부족할 때만 자연스럽게 다음 줄로 넘긴다.

## 검토한 대안

1. **인라인 자동 줄바꿈**: 모든 메타 항목과 태그를 하나의 `flex-wrap` 흐름에 둔다. 화면과 태그 길이에 맞춰 가장 적은 줄을 사용한다.
2. **메타/태그 2행 고정**: 날짜·시간·인기 상태는 첫 줄, 태그는 둘째 줄에 둔다. 구조는 명확하지만 태그가 적어도 둘째 줄을 강제한다.
3. **2열 그리드**: 날짜·시간과 인기 상태를 양쪽에 두고 태그를 전체 폭으로 배치한다. 정렬은 안정적이지만 작은 화면과 긴 문구에서 빈 공간이나 어색한 줄바꿈이 생긴다.

인라인 자동 줄바꿈을 채택한다. 현재 콘텐츠마다 태그 개수와 길이가 달라 고정 행이나 열보다 공간 활용률이 높다.

## 레이아웃

- 기존 세로 방향 `flex-col`을 제거하고 모든 화면에서 `flex-wrap`을 사용한다.
- 날짜, 읽기 시간, 인기 상태와 태그 목록을 동일한 흐름의 형제 항목으로 유지한다.
- 가로 간격과 세로 간격을 따로 지정해 항목 사이 구분은 유지하면서 줄 간격은 압축한다.
- 각 메타 항목에는 `whitespace-nowrap`을 적용해 아이콘과 문구가 중간에서 갈라지지 않게 한다.
- 태그 컨테이너는 별도 폭을 차지하지 않도록 `contents`를 사용하거나 태그를 상위 흐름에 직접 배치한다.
- 상단 구분선과 기존 글꼴·색상·태그 디자인은 유지한다.

## 콘텐츠와 데이터

문구, DOM의 의미 순서, 링크와 데이터 산출 방식은 변경하지 않는다. 날짜 → 읽기 시간 → 인기 상태 → 태그 순서를 유지하므로 검색엔진과 생성형 검색이 해석하는 콘텐츠에도 변화가 없다.

## 반응형 동작

- 모바일: 가능한 항목을 첫 줄부터 채우고 부족한 항목만 다음 줄로 넘긴다.
- 태블릿·데스크톱: 대부분 한 줄에 표시하되 태그가 많으면 자연스럽게 두 번째 줄을 사용한다.
- 좁은 화면에서도 가로 스크롤이 생기지 않아야 한다.

## 검증

- Google Sheets AI 함수 글에서 날짜·읽기 시간·인기 상태가 한 줄 흐름으로 배치되는지 확인한다.
- 긴 태그와 여러 태그가 있는 글에서 줄바꿈과 가로 넘침을 확인한다.
- 모바일·데스크톱 뷰포트에서 스크린샷 또는 브라우저 확인을 수행한다.
- 타입 검사와 프로덕션 빌드를 실행한다.
