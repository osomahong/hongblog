# GEO 진단 후 블로그 수정

사용자가 승인한 1~6번 과제를 구현한다. 최신 HEAD c63d92c에 이미 포함된 교육 페이지, 사례 페이지, AUTHOR_PERSON_LD를 재사용한다. 사용자 변경이 있는 원 저장소와 분리한 worktree에서 작업한다.

- GA4 교육 두 설명을 공식 세션 규칙으로 수정하고 검증일/근거를 공개한다.
- 41배 성과 해석은 원자료가 없어 철회한다. 기간과 분모가 다른 스크린샷 수치는 역사적 관측으로 유지한다.
- AI referral과 직접 인용의 정의/장부를 분리하고 퀴즈, 요약, FAQ도 함께 수정한다.
- About에 실제 서비스의 협의 범위와 산출물, 준비사항, 완료 확인을 추가한다. 새 가격/일정/성과 약속은 만들지 않는다.
- 이미 작성된 익명 사례를 재사용한다. 공개 근거와 비공개 제한을 구분하고 고객 실명/내부 문서를 새로 공개하지 않는다.
- 작성자 공통값을 화면과 JSON-LD에서 재사용하고 회귀 검사한다.
- 유지보수는 저장소 AGENTS.md/CLAUDE.md, npm build의 점검, geo-scan 후속 작업 체크리스트에 연결한다. llms 목록의 변동 수치는 제거하고 실제 링크 검사를 포함한다.

검증: 콘텐츠 검사, 타입 검사, 빌드와 렌더 HTML 검사, 모바일/데스크톱 시각 확인. 원 저장소의 unrelated diff 보존. 커밋/배포는 공개문안 검토 가능한 결과를 만든 뒤 저장소 지침에 따라 처리한다.
