# AI 교육 안내와 익명 이력 — 작업 결과

## 완료 범위
- RAG source 레이어의 교육 종료·주최기관 피드백을 교차 확인하고 컨설팅 수행 계획서 전문을 확인했다.
- 대표 사례 3개를 산업군 중심으로 익명화했다. 완료 교육 2개와 현황 진단·계획 수립 1개를 구분했다.
- /about의 소개와 대표 사례를 보강하고, 재집계되지 않은 누적 고객·교육·이벤트·산업군 수치를 제외했다.
- /education에 교육 주제 3개, 대상, 준비 수준, 실습 산출물 예시, 운영 방식, 협의 항목, 문의와 독학 경로를 작성했다.
- 홈과 푸터, claude-fundamentals / claude-in-practice / claude-code-for-everyone 코스에서 교육 안내를 연결했다.
- 홈·소개·과정·교육의 인물 식별자를 통일했다. 교육 페이지 metadata와 Service 설명을 본문과 일치시켰다.

## 근거 사용의 한계
Gmail read_source는 추출 텍스트 없음 응답이어서 검색 source 발췌를 교차 확인했다. 전체 메일 스레드 및 첨부를 읽었다고 간주하지 않았다. 기존 고객 전체의 계약 완료 여부나 전체 교육 인원을 검증한 것은 아니다. 계획서는 계획 수립의 근거로만 사용했고 예시 성과·예정 교육을 완료 실적으로 전환하지 않았다. 고객 규모, 점수, 정확한 날짜와 기관명을 새 공개 사례에 넣지 않았다.

개인 근거 기록과 고객 매핑은 저장소 밖에서 관리한다. 새 공개 소스·메타·HTML에는 내부 문서 식별자나 고객 매핑이 없다.

## 검수
- 문서 설계 검토와 독립 구현 내용 검토 완료. 완료 교육 상태를 명확하게 수정했다.
- 공개 데이터 및 교육 페이지 문체 검사 HARD 0건. 서로 다른 카드에서 같은 종결어가 반복되는 SOFT는 문맥상 유지했다.
- production build와 TypeScript 통과.
- 수정 파일 ESLint 오류 0건, 기존 코스 img 경고 1건.
- 전체 lint: 기존 13개 오류가 있어 미통과. 대상은 별도 분석 스크립트와 기존 입력 컴포넌트이며 이번 수정 범위 밖이다.
- HTML 링크 검사 392개 통과. 빌드 manifest의 실제 정적 경로를 검사기에 반영해 정상 앱 페이지를 오탐하는 문제도 해결했다.
- 6개 경로, 390px/1440px 화면 너비에서 HTTP 200, H1 1개, pageerror 및 가로 넘침 없음. 교육 문의 앵커와 mailto 확인, 실제 메일 전송 없음.
- 추가 768px 검사에서는 기존 공통 Nav의 버튼 영역이 화면 밖으로 나가 문서 너비가 855px이 되는 문제를 확인했다. Nav는 이번에 수정하지 않은 파일이며 소개/교육 본문의 넘침은 없었다. 후속 작업에서 1024px 미만에 기존 접이식 메뉴를 적용해 수정했다.
- 고객명·약칭·내부 URL 등 금지 토큰 101개를 소개/신규 소스와 about/education HTML에서 검사해 0건 확인.
- 사이트 전체 SEO 도구가 보고한 기존 43개 이슈 중 about/education 관련 이슈 없음. 전체 SEO 재정비는 보류.

## 보류
1. 전체 계약과 교육 인원 재집계: 일부 자료만으로 숫자를 재구성하지 않는다.
2. 사례별 상세 페이지, 대상별 교육 랜딩페이지, 전체 클래스 개편.
3. 외부 기관 소개·후기 확보: 외부 연락이나 게시를 실행하지 않았다.
4. 다중 AI 서비스 자동 측정: 이번 작업은 실제 추천률 상승을 입증하지 않는다.
5. 전면 디자인 및 기존 lint/SEO 문제 수정.
