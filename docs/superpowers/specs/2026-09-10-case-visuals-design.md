# 사례별 실무 화면 목업

사용자 요청: 완료 상태 표시 제거. 각 사례에 1~2개 실제적인 작업 구조/결과물/참고 화면 목업 삽입. 기존 본문과 근거 범위를 유지한다. 기존 사용자 승인 범위에서 로컬 구현 및 브라우저 검수까지 진행한다.

HTML/CSS로 구현해 텍스트를 읽고 선택할 수 있게 한다. 실제 서비스의 정확한 UI 복제품보다 문서/스프레드시트/분석 작업 화면을 재구성한다. 고객명, 식별값, 실제 수치 및 작업 완료를 암시하는 허위 성과는 넣지 않는다. 그림에 '설명용 목업' 표시, 가상 수치/이벤트명은 캡션에 예시로 표시한다. AI는 실행 결과가 아닌 도입 계획 화면으로 명시한다.

공공 교육: AI 소재 실습 작업지, 설명/실습 진행안 예시.
소비재 교육: 요구사항-커리큘럼 협의 문서, 행동 정의-보고서 해석 작업 화면.
구매 측정: 이벤트 정의 시트, 행동별 검수 보드.
다중 사이트: 환경별 점검 매트릭스, 이벤트 상세 검사 화면.
매출 정의: 가상 주문 금액 대조, 계산 기준 협의 시트.
권한 인계: 인수인계 문서 1개.
AI 계획: 조회 설계 흐름, 주간 보고 초안 검토 화면.

목업 데이터는 별도 lib, 공통 figure와 화면 타입은 컴포넌트, 상세 섹션 뒤에 삽입. 총 13개. 작은 화면은 목업 내부만 가로 스크롤, 문서 전체 넘침 방지. 링크 가능한 고유 figure id와 의미 있는 caption. 상태 텍스트는 목록/상세에서 제거하되 AI 계획이라는 본문/분류 유지.

검수: 사실/시각 독립 검토, TS/ESLint/build, 7개 사례 3개 너비(390/768/1440)와 그림13개 표시/가로 스크롤/본문 넘침/브라우저 오류/완료 상태 제거, 스크린샷 육안 확인, 개인정보 검사 및 HTML 링크 검사. 커밋/배포 없음.

독립 설계 검수 반영: 숫자뿐 아니라 검수/권한/후속 교육/AI 응답의 수행 상태 혼동도 검토한다. 목업 내부 스크롤 영역은 tabIndex=0과 식별 가능한 aria-label을 제공하고 ArrowRight 키로 가로 스크롤되는지 확인한다.

후속 사용자 수정: 색 배경+세로선 띠 강조 박스 금지. 모든 목업의 note는 일반 문장으로, 단계 카드 제목도 색 띠 없이 표현. 확인된 비식별 작업 규모만 선택적으로 공개: 교육 제안 총 6회, 판매 사이트 2개. 각 숫자의 근거와 수행 범위는 비공개 검수 기록에 보관.
