**Tech Stack:** Next.js App Router, TypeScript, Tailwind.

## 자료 한계
Gmail read_source는 추출 텍스트 없음 응답. 검색 source 발췌를 교차 확인하며 전체 스레드나 첨부를 읽었다고 주장하지 않는다. 다른 사람이 작성한 프로젝트 요약을 단독 담당 근거로 사용하지 않는다.

확인 질문에 답변이 없으면 확인된 사실만 작성하며, 신규 AI 교육 제안은 완료 사례에서 제외한다. 상세 조사로 확인된 공동 역할/상태를 기존 about 대표 사례와 education 소개 문구에도 동기화한다.

검수 결과와 미응답 확인 사항은 ../specs/2026-09-09-evidence-cases-review.md에 기록했다. 미응답 사실은 확정 서술하지 않았으며 근거가 확보된 범위만 로컬 반영했다.
