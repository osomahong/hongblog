# GA4 Edu 튜토리얼 커리큘럼

GA4 Edu는 GA4와 같은 모양의 데모 화면으로 GA4 사용법과 데이터 해석법을 배우는 학습 페이지입니다. 학습자는 화면을 자유롭게 만지지 않고, 튜토리얼이 정한 순서대로 클릭하며 진행합니다.

이 문서는 만들 튜토리얼의 주제 목록입니다. 운영 방식과 학습 설계는 `ga4-edu-design.md`에서 다룹니다.

## 주제 표기 규칙

주제 이름 앞에 다루는 영역을 붙입니다.

| 접두어 | 다루는 영역 |
|---|---|
| GA4 기본 | 기간 설정, 보고서 조작 같은 공통 기능 |
| GA4 분석 | 표준 보고서를 읽고 해석하는 법 |
| GA4 탐색 | 탐색 보고서를 직접 만들어 보는 법 |
| GA4 세팅 | 관리 화면에서 수집과 설정을 바꾸는 법 |
| GA4 연동 | 외부 서비스와 연결하는 법 |

## 순서 기준

각 단계 안에서 **실무 수요가 큰 주제를 앞에** 놓았습니다. 난이도 순서가 아니라 마케터가 GA4를 열었을 때 가장 먼저 하려는 일 순서입니다.

기간 선택기와 보조 측정기준처럼 다른 튜토리얼의 밑바탕이 되는 조작은 앞쪽 튜토리얼 안에서 필요한 만큼 짚고 지나가고, 독립 주제로는 뒤에 배치했습니다. 이렇게 하면 학습자가 첫 편에서 바로 쓸모 있는 결과를 얻습니다.

> 지금 순서는 실무 질문 빈도를 근거로 한 판단입니다. 검색 데이터로 확인하려면 `seo-topic-finder` 스킬로 Search Console 노출과 네이버 검색광고 월간 검색량을 뽑아 다시 배열할 수 있습니다.

## 공개 2편 (게이트 없음)

구독 없이 끝까지 볼 수 있는 두 편입니다. 각 단계의 1번을 하나씩 뽑았습니다.

| 순서 | 주제 | 단계 | 이 둘을 고른 이유 |
|---|---|---|---|
| 1 | GA4 분석: 유입 정보(마케팅 채널 전략) 분석하기 | 초급 1번 | 마케터가 GA4를 여는 가장 흔한 이유. 한 편만 봐도 바로 쓸 수 있음 |
| 2 | GA4 탐색: 자유 형식 보고서 만들고 행과 열 배치하기 | 중급 1번 | GA4에서 가장 많이 막히는 기능. 잠긴 탐색 8편으로 이어지는 고리 |

두 번째 편을 중급에서 뽑은 이유는 표준 보고서만 보다가 탐색으로 넘어가는 순간이 GA4 실력이 나뉘는 지점이기 때문입니다. 무료 구간에서 이 벽을 한 번 넘게 하면 나머지를 보려는 이유가 생깁니다.

세 번째 편부터 뉴스레터 구독 확인을 거칩니다.

## 초급 10개

GA4 화면에서 원하는 숫자를 찾아 읽는 단계입니다. 설정은 바꾸지 않고 보는 것에 집중합니다.

| # | 주제 | 시나리오에서 다루는 것 | 조작 화면 |
|---|---|---|---|
| 1 | GA4 분석: 유입 정보(마케팅 채널 전략) 분석하기 **[공개]** | 기본 채널 그룹으로 유입을 나누고 채널별 성과 비교 | 보고서 > 트래픽 획득 |
| 2 | GA4 분석: 페이지 및 화면 보고서에서 조회수 상위 콘텐츠 찾기 | 페이지 경로와 페이지 제목의 차이, 정렬과 검색 | 보고서 > 페이지 및 화면 |
| 3 | GA4 분석: 참여율과 이탈률을 같이 읽기 | 참여 세션의 세 조건, 맞춤설정으로 이탈률 열 붙이기, 화면의 목적과 함께 읽기 | 보고서 > 방문 페이지 |
| 4 | GA4 분석: 사용자, 세션, 이벤트 수를 구분해서 읽기 | 세 숫자가 각각 세는 대상, 합계가 맞지 않는 이유 | 보고서 > 개요 |
| 5 | GA4 분석: 랜딩 페이지 보고서에서 유입 후 첫 화면 확인하기 | 비교로 광고 채널만 떼어 보기, 도착 화면을 주요 이벤트로 판단하기 | 보고서 > 방문 페이지 |
| 6 | GA4 기본: 보고서에 보조 측정기준 추가하고 필터 걸기 | 표에 측정기준 하나 더 얹기, 조건 필터로 행 줄이기 | 보고서 공통 |
| 7 | GA4 기본: 기간 선택과 이전 기간 비교 적용하기 | 기간 선택기, 비교 기간 설정, 증감 표시 읽는 법 | 보고서 공통 |
| 8 | GA4 분석: 이벤트 보고서에서 자동 수집 이벤트 확인하기 | 자동 수집 이벤트 목록, 이벤트 수와 사용자 수의 관계 | 보고서 > 이벤트 |
| 9 | GA4 분석: 신규 사용자와 재사용자 구분해서 보기 | 신규와 재방문 측정기준, 재방문 비율 해석 | 보고서 > 유지 |
| 10 | GA4 분석: 지역과 기기로 사용자 나눠 보기 | 측정기준을 바꿔 같은 지표를 다른 각도로 보기 | 보고서 > 사용자 속성, 기술 |

## 중급 10개

탐색 보고서를 직접 만들고, 수집 설정을 바꾸는 단계입니다.

| # | 주제 | 시나리오에서 다루는 것 | 조작 화면 |
|---|---|---|---|
| 1 | GA4 탐색: 자유 형식 보고서 만들고 행과 열 배치하기 **[공개]** | 변수 패널과 탭 설정의 관계, 세그먼트, 측정기준, 측정항목 끌어놓기 | 탐색 > 자유 형식 |
| 2 | GA4 세팅: 맞춤 이벤트 만들고 주요 이벤트로 표시하기 | 기존 이벤트 조건으로 새 이벤트 만들기, 주요 이벤트 지정 | 관리 > 이벤트 |
| 3 | GA4 세팅: 맞춤 측정기준 등록해 매개변수를 보고서에 올리기 | 이벤트 매개변수가 보고서에 나오지 않는 이유, 등록 후 반영 시점 | 관리 > 맞춤 정의 |
| 4 | GA4 탐색: 유입경로 탐색으로 이탈 단계 찾기 | 단계 정의, 열린 유입경로와 닫힌 유입경로의 차이 | 탐색 > 유입경로 탐색 |
| 5 | GA4 탐색: 검색광고 데이터 성과 분석하기 | 세션 소스와 매체, 캠페인으로 유료 검색만 뽑아 성과 비교 | 탐색 > 자유 형식 |
| 6 | GA4 분석: UTM 규칙 정하고 캠페인 성과 나눠 보기 | 소스, 매체, 캠페인 값의 역할, 표기 흔들림이 만드는 문제 | 보고서 > 트래픽 획득 |
| 7 | GA4 탐색: 세그먼트 만들어 특정 사용자만 비교하기 | 사용자, 세션, 이벤트 세그먼트의 범위 차이 | 탐색 > 세그먼트 |
| 8 | GA4 세팅: 데이터 스트림 향상된 측정에서 개별 이벤트 끄기 | 향상된 측정이 자동으로 만드는 이벤트 목록, 끄기 전에 확인할 것 | 관리 > 데이터 스트림 |
| 9 | GA4 탐색: 접속 기준 리텐션 확인하기 | 코호트 탐색의 기준 조건, 재방문 코호트 표 읽는 법 | 탐색 > 코호트 탐색 |
| 10 | GA4 탐색: 경로 탐색으로 다음 화면 흐름 따라가기 | 시작점과 종료점 설정, 노드를 펼쳐 경로 추적 | 탐색 > 경로 탐색 |

## 심화 10개

여러 설정이 맞물린 상황을 다루고, 숫자가 어긋나는 원인을 찾습니다.

| # | 주제 | 시나리오에서 다루는 것 | 조작 화면 |
|---|---|---|---|
| 1 | GA4 분석: 기여 분석 모델 바꿔 채널 평가 비교하기 | 기여 분석 모델의 차이, 채널별 평가가 달라지는 이유 | 광고 > 기여 분석 |
| 2 | GA4 세팅: 내부 트래픽과 원치 않는 추천 제외하기 | IP 필터 정의와 활성화 순서, 결제 도메인이 추천으로 잡히는 문제 | 관리 > 데이터 필터, 데이터 스트림 |
| 3 | GA4 분석: 데이터 기준 적용과 카디널리티 흔적 찾기 | 기타 행이 생기는 조건, 숫자가 가려질 때 대응법 | 보고서, 탐색 공통 |
| 4 | GA4 세팅: 채널 그룹 직접 만들어 유입 분류 바꾸기 | 기본 채널 그룹의 한계, 규칙 우선순위 정하기 | 관리 > 채널 그룹 |
| 5 | GA4 세팅: 잠재고객 만들어 광고 계정으로 내보내기 | 조건과 기간 설정, 잠재고객이 소급 적용되지 않는 점 | 관리 > 잠재고객 |
| 6 | GA4 세팅: 이벤트 수정으로 기존 이벤트 이름과 매개변수 고치기 | 이벤트 수정과 이벤트 만들기의 적용 순서, 되돌릴 수 없는 범위 | 관리 > 이벤트 |
| 7 | GA4 세팅: 사용자 ID와 구글 신호 데이터로 기기 넘나드는 사용자 잇기 | 보고 ID 우선순위, 설정에 따라 사용자 수가 달라지는 이유 | 관리 > 보고 ID |
| 8 | GA4 연동: BigQuery 내보내기 설정과 원본 이벤트 표 구조 읽기 | 일일 내보내기와 스트리밍의 차이, 중첩 필드 구조 | 관리 > BigQuery 링크 |
| 9 | GA4 탐색: 세그먼트 중복분석으로 겹치는 사용자 찾기 | 세그먼트 세 개의 교집합 읽기, 겹침이 알려 주는 것 | 탐색 > 세그먼트 중복분석 |
| 10 | GA4 탐색: 이커머스 항목 보고서에서 상품 성과 나누기 | 항목 범위 측정기준, 상품 조회부터 구매까지 단계 비교 | 탐색 > 자유 형식 |

## 정리할 때 쓴 기준

- 한 튜토리얼은 클릭 5회에서 12회 사이로 끝나는 분량으로 잡았습니다.
- 초급은 화면을 읽는 것만, 중급부터 설정을 바꾸는 조작을 넣었습니다.
- 설정을 바꾸는 주제는 되돌리는 절차까지 시나리오에 포함합니다.
- 실무에서 숫자가 어긋나는 원인이 되는 항목을 심화에 배치했습니다.

## 확인이 필요한 것

- 주신 주제 가운데 "데이터 스트림에서 향상된 이벤트 제외하기"는 GA4 화면 명칭이 "향상된 측정"이라 중급 8번에서 그 표기로 바꿨습니다.
- 데모 화면에 넣을 데이터를 준이아빠블로그 실제 수치로 할지, 시나리오용으로 만든 고정 데이터로 할지 정해야 합니다. 이커머스와 광고 연동 주제는 실제 데이터로는 다룰 수 없습니다.

- 2026-08-14: 세 단계 모두 실무 수요 순으로 다시 배열하고, 공개 2편을 초급 1번과 중급 1번으로 정했습니다.
- 2026-08-15: 공개 2편 가운데 중급 1번 자유 형식을 만들었습니다. 랜딩 페이지와 기기를 교차해, 행만 읽을 때와 열을 더했을 때 먼저 고칠 페이지가 바뀌는 것을 학습자가 직접 보게 했습니다.
- 2026-08-15: 초급 2번 페이지 및 화면을 만들었습니다. 측정기준을 경로에서 제목으로 바꾸면 흩어져 있던 주소가 한 줄로 합쳐지면서 조회수 1위가 바뀌는 것을 다룹니다. 구독자 전용이라 실습은 게이트 뒤에 있고 본문만 열립니다.
- 2026-08-15: 초급 3번과 5번의 조작 화면을 참여도 개요와 랜딩 페이지에서 모두 방문 페이지로 바꿨습니다. 참여율과 이탈률은 방문 페이지 표에서 맞춤설정으로 붙여야 나란히 볼 수 있고, 광고 도착 화면 점검도 같은 표에서 비교를 걸어야 합니다. 3번은 맞춤설정, 5번은 비교로 다루는 조작을 나눴습니다.
- 2026-08-15: 초급 4번 사용자, 세션, 이벤트 수와 5번 랜딩 페이지를 만들었습니다. 이로써 초급 다섯 편과 중급 한 편이 완성됐습니다.
- 2026-08-15: 초급 6번 보조 측정기준과 필터를 만들었습니다. 채널 표에 기기를 붙여 줄이 다섯 개에서 열다섯 개로 늘어나는 것과, 필터로 모바일만 남겼을 때 순위가 위아래로 뒤집히는 것을 다룹니다.
