# 코덱스 CLI, 클로드 코드 세팅 가이드 최신화 계획

작성 2026-08-17. 대상은 설치 가이드 4편이고, 검증은 실제 CLI 실행과 공식 문서 대조로 마쳤다.

## 1. 먼저 알아야 할 것: 이 4편은 사이트 최대 유입 자산이다

Search Console 90일(2026-05-17 ~ 08-15) 실측이다.

| 글 | 클릭 | 노출 | 평균 순위 |
|---|---|---|---|
| `codex-cli-windows-easy-setup-guide` | **5,871** | 84,492 | 4.6 |
| `claude-code-mac-easy-setup-guide` | **2,298** | 24,477 | 4.9 |
| `codex-cli-mac-easy-setup-guide` | **1,129** | 18,568 | 5.1 |
| `claude-code-windows-easy-setup-guide` | 555 | 10,145 | 5.7 |

**그래서 이 작업의 성격은 리라이트가 아니라 정비다.** 슬러그, 제목, H2 구조를 바꾸면 쌓인 순위가 흔들린다. 아래 원칙을 지킨다.

- 슬러그를 바꾸지 않는다
- 제목과 metaTitle을 바꾸지 않는다. 유입 질의어(`codex cli 설치`, `맥북 클로드 코드 설치`)와 이미 맞물려 있다
- H2 헤딩은 유지하고 그 안의 내용만 고친다
- 실질 개편이므로 `updatedAt`을 갱신한다

## 2. 편별 진단과 수정 내역

### 2-1. `claude-code-mac-easy-setup-guide` (최우선)

**5월 발행 이후 한 번도 갱신되지 않았다.** `updatedAt` 필드 자체가 없다. 클릭 2,298인데 방치된 상태다.

| # | 문제 | 근거 | 수정 |
|---|---|---|---|
| 1 | Node.js를 9단계 중 필수 단계(Step 3)로 안내 | 공식 문서: 네이티브 설치는 자체 실행 파일이라 Node.js를 쓰지 않는다. npm 설치일 때만 Node.js 22 이상 필요 | 윈도우 편에 이미 있는 설명을 그대로 가져온다. 단계에서 빼지 말고 "필수가 아니지만 다른 도구를 붙일 때 필요해서 함께 깐다"로 성격을 바꾼다 |
| 2 | Homebrew 설치 경로가 없음 | 공식 문서에 `brew install --cask claude-code` 추가됨 | 대안 설치로 추가. 안정 채널(`claude-code`)과 최신 채널(`claude-code@latest`) 차이를 한 줄로 |
| 3 | 진단 명령 없음 | `claude doctor`가 설치 상태와 설정 오류를 읽기 전용으로 점검 | 자주 발생하는 문제 섹션 맨 앞에 배치 |
| 4 | 자동 업데이트 설명 없음 | 네이티브 설치는 백그라운드 자동 갱신, Homebrew는 수동 | 정리 섹션에 한 문단 |
| 5 | 요구 사양 없음 | macOS 13.0 이상, 4GB 이상 RAM | 도입부 인용 블록에 추가 |
| 6 | 지원 플랜 안내 없음 | Pro, Max, Team, Enterprise, Console. **무료 플랜은 안 됨** | 로그인 단계에 명시. 이걸 모르고 무료 계정으로 시도하다 막히는 사례가 많다 |

### 2-2. `codex-cli-mac-easy-setup-guide`, `codex-cli-windows-easy-setup-guide`

두 편의 노후 지점이 같아서 함께 처리한다. 윈도우 편이 클릭 5,871로 가장 크다.

| # | 문제 | 근거 | 수정 |
|---|---|---|---|
| 1 | **기본 모델을 GPT-5.5로 안내** | 실제 설정값은 `gpt-5.6-sol`. 공식 문서 예시도 `gpt-5.6-sol medium` | GPT-5.6으로 전면 교체. 라인업 표를 Sol, Terra, Luna로 다시 씀 |
| 2 | GPT-5.4를 이전 세대로 언급 | 세대가 한 칸씩 밀렸다 | 비교 대상을 GPT-5.5로 교체 |
| 3 | 공식 문서 링크가 죽음 | `developers.openai.com/codex/cli`가 `learn.chatgpt.com/docs/codex/cli`로 308 리다이렉트 | 새 주소로 교체 |
| 4 | 공식 단독 설치 스크립트 누락 | 공식 문서가 안내하는 `curl -fsSL https://chatgpt.com/codex/install.sh | sh` | npm 방식을 그대로 주력으로 두고, 단독 설치를 대안으로 추가 |
| 5 | 진단 명령 없음 | `codex doctor`가 설치, 설정, 인증, 실행 상태를 한 번에 점검 | 자주 발생하는 문제 섹션 맨 앞에 배치 |
| 6 | 버전 표기 없음 | 확인 시점 0.147.0 | "2026년 8월 기준 0.147.0" 형태로 시점 명시 |

**주의할 것이 하나 있다.** 코덱스 모델 라인업의 세부 구성은 내 계정에서 `/model`로 직접 확인한 뒤에 표를 쓴다. 기존 표(Instant, 일반, Pro)를 GPT-5.6에 그대로 옮겨 쓰지 않는다. 확인되지 않은 구성은 쓰지 않고 확인된 것만 남긴다.

### 2-3. `claude-code-windows-easy-setup-guide`

**손댈 것이 거의 없다.** 8월 5일에 갱신됐고 내용이 이미 정확하다. Node.js가 필수가 아니라는 점, 관리자 권한이 필요 없다는 점, Git for Windows가 선택이라는 점이 공식 문서와 일치한다.

추가할 것은 두 가지뿐이다.

- `claude doctor` 진단 명령
- WinGet 설치 대안(`winget install Anthropic.ClaudeCode`)과 수동 업데이트 필요 여부

## 4. 함께 풀어야 할 문제: 검색어 잠식

`codex-cli-windows-easy-setup-guide`가 **`codex cli 사용법`으로 클릭 157, 4.0위**를 받고 있다. 그런데 8월 16일에 발행한 `codex-cli-practical-guide`의 제목이 "코덱스 CLI 사용법"이고, 이 글은 클릭 0, 노출 8이다.

같은 검색어를 두 글이 나눠 갖는 상태다. 새 글은 순위를 못 잡았고 기존 글은 이미 4위에 있다.

**처리 방향은 이렇다.**

- 기존 윈도우 설치 가이드는 그대로 둔다. 4위를 흔들지 않는다
- 새 글(`codex-cli-practical-guide`)의 제목에서 `사용법`을 빼고 **도구를 만드는 과정**을 앞세우는 쪽으로 바꾼다. 설치 검색어와 겹치지 않게 한다
- 설치 가이드 본문에서 새 글로 "설치를 마쳤다면 실제로 무엇을 만들 수 있는지" 흐름으로 링크한다

제목 변경은 클릭 0인 글에만 적용하므로 잃을 순위가 없다.

## 5. 실행 순서

한 편씩 고치고 각각 게이트를 통과시킨 뒤 다음으로 넘어간다. 4편을 한꺼번에 손대지 않는다.

| 순서 | 대상 | 이유 |
|---|---|---|
| 1 | `claude-code-mac` | 갱신 이력이 없고 잘못된 안내(Node.js 필수)가 남아 있다 |
| 2 | `codex-cli-windows` | 클릭 5,871로 가장 크다. 모델명 오류의 영향도 가장 크다 |
| 3 | `codex-cli-mac` | 윈도우 편과 같은 수정을 맥 환경에 맞춰 적용 |
| 4 | `claude-code-windows` | 두 항목만 추가 |
| 5 | `codex-cli-practical-guide` 제목 변경 | 검색어 잠식 해소 |

## 6. 편마다 통과할 검증

1. 문서에 적은 명령을 **실제로 실행해 결과를 확인한다.** 공식 문서를 옮겨 적는 것으로 끝내지 않는다
2. `npm run check:prose` HARD 0건
3. `check-literary.mjs` HARD 0건
4. 낭독 검수 1회 (표 안 문장 포함)
5. 금지 기호 두 개(em dash, 가운뎃점) grep 각 0건
6. `npm run check:links`로 내부 링크와 바뀐 공식 문서 링크 확인
7. 전문을 사용자에게 출력하고 승인받은 뒤 커밋

## 7. 하지 않을 것

- 슬러그, 제목, metaTitle 변경 (클릭 0인 `codex-cli-practical-guide` 제외)
- H2 구조 개편
- 4편 통합이나 분리
- 확인하지 못한 모델 라인업을 추정해서 쓰기
