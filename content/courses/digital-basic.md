디지털 환경 기초 지식은 웹사이트가 어떤 재료로 만들어지고 브라우저에서 어떻게 움직이는지를 비개발자 눈높이로 정리한 코스입니다. 개발을 배우려는 것이 아니라 개발자와 같은 말을 쓰려는 사람을 위해 만들었습니다.

마케터와 디자이너가 개발자에게 요청을 넘길 때 가장 자주 어긋나는 지점은 무엇을 고쳐 달라는 것인지가 서로 다르게 들린다는 데 있습니다. 버튼의 색을 바꾸는 일과 버튼이 눌렸을 때 기록을 남기는 일은 건드리는 대상이 다릅니다. 앞은 CSS, 뒤는 자바스크립트와 [DOM](/class/digital-basic/what-is-dom)입니다. 이 차이를 알면 요청이 한 번에 전달됩니다.

## 📚 다루는 개념 13가지

- **웹페이지의 재료**: HTML, CSS, 요소, 속성, 선택자
- **브라우저가 다루는 모형**: DOM, BOM, 자바스크립트
- **데이터가 오가는 통로**: API, JSON과 데이터 구조, 웹 크롤링
- **기록과 주소**: 쿠키, 도메인과 셀프호스팅

태그 관리 도구에서 선택자를 적어야 하거나 개발자 도구를 열어 값을 확인해야 하는 상황이 실무에서 계속 나옵니다. 앞의 두 묶음을 읽어 두면 그 화면에서 무엇을 보고 있는지가 잡힙니다.

## ❓ 자주 묻는 질문

### 코드를 직접 써야 하는 편이 있나요?

없습니다. 코드를 읽고 무엇을 가리키는지 알아보는 데까지만 다룹니다. 예시는 모두 브라우저에서 바로 확인할 수 있는 형태로 넣었습니다.

### GA4나 GTM을 쓰려면 어디까지 알아야 할까요?

HTML 요소와 속성, 선택자 세 편이면 태그 관리 도구의 트리거 설정을 읽을 수 있습니다. dataLayer를 직접 설계해야 한다면 JSON과 데이터 구조 편까지 보는 것을 권합니다.

### 웹 크롤링 편은 검색엔진 이야기인가요?

검색엔진이 페이지를 가져가는 방식과 데이터를 긁어 오는 방식을 함께 다룹니다. 검색 노출 쪽을 더 보고 싶으면 [검색엔진 최적화 기초](/class/seo-fundamentals) 코스로 이어집니다.
