앤트로픽 공식 Claude Code 가이드(platform.claude.com/docs)를 터미널을 처음 켜본 비개발자도 따라갈 수 있게 풀어 정리한 코스입니다. Claude Code 설치 첫걸음부터 슬래시 명령, Plan Mode, 서브에이전트, 훅, MCP까지 8개 개념을 차례로 다룹니다. 터미널 명령은 한 줄씩, 익숙해질 만큼만 다룹니다.
