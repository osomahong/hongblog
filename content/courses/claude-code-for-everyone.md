이 코스는 앤트로픽이 운영하는 platform.claude.com/docs의 **Claude Code 공식 가이드**를 터미널을 처음 켜본 비개발자도 따라올 수 있도록 한국어로 풀어 정리한 것입니다. 원문 링크는 각 클래스 끝 참고 자료에 모두 모았습니다.

8개 클래스를 따라가면 다음이 가능해집니다.

- Claude Code가 무엇이고, 왜 Claude.ai 웹과 다른지 — 그래서 어떤 일에 더 잘 맞는지 판단할 수 있습니다.
- macOS·Windows에서 터미널을 처음 여는 단계부터 Claude Code를 설치하고 실행해 봅니다.
- 슬래시 명령(Slash Commands), Plan Mode, 서브에이전트(Subagents), 훅(Hooks)으로 작업을 자동화하는 방법을 익힙니다.
- MCP(Model Context Protocol)와 CLAUDE.md 메모리로 내 PC가 Claude의 협업 공간이 되는 그림을 잡습니다.

개발자가 아니어도 따라갈 수 있게 만들었습니다. 터미널 명령은 한 줄씩, 손에 익을 만큼만 다룹니다.
