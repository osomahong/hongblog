이 글은 앤트로픽이 운영하는 code.claude.com/docs의 비용 관리 문서를 한국 입문자가 보기 편하게 정리한 글입니다. 플랜 이름과 명령어는 **2026년 7월 기준**이고, 원문 링크는 글 끝 참고 자료에 모았습니다. 플랜별 가격은 자주 바뀌므로 claude.com/pricing에서 직접 확인하시기 바랍니다.

## 💳 클로드 코드의 지불 방식은 두 갈래입니다

[클로드 코드](/class/claude-code-for-everyone/what-is-claude-code)를 쓰는 방법은 지불 구조에 따라 두 가지로 나뉩니다.

| 방식 | 요금 | 주로 쓰는 곳 |
|---|---|---|
| **구독 플랜** (Pro, Max, Team, Enterprise) | 월 정액에 사용량이 포함 | 대부분의 개인 사용자 |
| **API 종량제** | 쓴 토큰만큼 청구 | 회사 계정, 자동화 연결 |

구독 플랜을 쓴다면 클로드 코드 사용량이 이미 구독에 포함되어 있습니다. 따로 결제할 것이 없고, 대신 **정해진 양까지만** 쓸 수 있습니다. 이 양을 사용량 한도라고 부릅니다.

> Pro와 Max 같은 구독 플랜에는 클로드 코드 사용량이 포함되어 있습니다. 별도 결제 없이 쓰는 대신 세션 한도와 주간 한도가 적용되고, API 종량제는 반대로 한도 없이 쓴 만큼 요금이 붙습니다.

## ⏱️ 한도는 두 개의 창으로 나뉘어 있습니다

사용량 한도는 하나가 아니라 두 개의 시간 창으로 관리됩니다.

- **세션 창**: 일정 시간 동안 쓸 수 있는 양. 시간이 지나면 다시 채워집니다.
- **주간 창**: 한 주 동안 쓸 수 있는 양.

Team과 Enterprise 플랜은 공식 문서가 이 구조를 명확히 밝히고 있습니다. 좌석마다 할당량이 있고, 5시간 단위로 리셋되는 창과 주간 창을 함께 씁니다. 이 할당량은 클로드 코드만의 것이 아니라 **클로드 채팅, 코워크와 함께 나눠 쓰는 양**입니다. 채팅으로 오래 대화한 날은 클로드 코드에 남는 양도 줄어듭니다.

Pro와 Max 플랜에서도 한도에 도달하면 세션 한도와 주간 한도를 알리는 메시지가 나타납니다.

## 🚦 한도 메시지 세 가지를 구분해야 합니다

작업 중에 나오는 메시지는 비슷해 보여도 뜻이 다릅니다. 구분해서 읽어야 다음 행동이 정해집니다.

**1. "세션 한도에 도달했습니다" 또는 "주간 한도에 도달했습니다"**

사용량 한도에 걸린 상태입니다. 메시지에 언제 다시 열리는지가 함께 표시됩니다. 여기서 **모델을 바꿔도 한도는 다시 열리지 않습니다.** 두 창은 모든 모델이 함께 쓰기 때문입니다.

**2. "Opus 한도에 도달했습니다"**

특정 모델만 막힌 상태입니다. 이 경우에는 `/model`로 다른 모델로 바꾸면 작업을 이어갈 수 있습니다.

**3. 컨텍스트 경고 또는 자동 요약 안내**

이건 사용량 한도가 아닙니다. 대화가 모델이 한 번에 읽을 수 있는 크기에 가까워져서, 클로드 코드가 오래된 대화를 요약해 자리를 비우는 중이라는 뜻입니다. [컨텍스트 윈도우](/class/claude-fundamentals/context-window-explained)와 관련된 안내이고 기다리면 계속 작업할 수 있습니다.

## 📊 /usage로 남은 양을 확인합니다

클로드 코드 세션 안에서 `/usage`를 입력하면 현재 사용량이 나옵니다.

```
/usage
```

구독 플랜을 쓰고 있다면 플랜 사용량 막대와 활동 통계가 함께 표시됩니다. 화면에서 `d`를 누르면 최근 24시간, `w`를 누르면 최근 7일 기준으로 바뀝니다.

여기서 유용한 부분은 **무엇이 사용량을 많이 먹었는지 항목별로 나눠 보여준다**는 점입니다. 스킬, [서브에이전트](/class/claude-code-for-everyone/what-are-subagents), 플러그인, [MCP](/class/claude-code-for-everyone/what-is-mcp) 서버가 각각 몇 퍼센트를 차지했는지 나옵니다. 어느 하나가 최근 사용량의 10% 이상을 차지하면 그 항목을 따로 표시해 줍니다.

한 가지 주의할 점이 있습니다. 이 수치는 지금 쓰는 컴퓨터에 남은 기록으로 계산합니다. 다른 기기나 claude.ai에서 쓴 양은 여기에 포함되지 않습니다.

화면 맨 위의 세션 항목에 달러 금액이 보이는데, 이건 API 사용자를 위한 표시입니다. 구독자라면 청구와 관계가 없으므로 신경 쓰지 않아도 됩니다.

## 🔥 사용량이 빨리 닳는 네 가지 이유

작업을 많이 하지 않았는데 한도가 빨리 차는 경우가 있습니다. 공식 문서가 꼽는 원인은 다음과 같습니다.

**1. 대화가 길어졌을 때**

클로드 코드는 메시지를 보낼 때마다 **그때까지의 대화 전체를 함께 보냅니다.** 아침부터 열어 둔 창에서 한 줄짜리 질문을 하면, 그 한 줄이 아니라 하루치 대화만큼의 양을 쓰게 됩니다.

**2. 캐시가 끊겼을 때**

같은 내용을 반복해서 보낼 때는 캐시가 적용되어 양이 절약됩니다. 이 캐시는 구독 플랜에서 한 시간 동안 유지됩니다. 한 시간보다 오래 쉬었다가 보낸 첫 메시지는 캐시를 쓰지 못하고 전체를 다시 읽습니다.

**3. 예약 작업이 돌고 있을 때**

예약해 둔 작업은 창을 보고 있지 않아도 정해진 주기마다 실행되고, 그때마다 대화 전체를 함께 보냅니다.

**4. 여러 작업을 동시에 돌릴 때**

에이전트 팀 기능으로 여러 인스턴스를 띄우면 각자 자기 대화를 따로 갖습니다. 공식 문서는 팀원들이 계획 단계에서 도는 경우 일반 세션의 약 7배까지 쓴다고 밝히고 있습니다.

## 🧹 사용량을 아끼는 실제 방법

명령어 세 개만 익혀도 차이가 납니다.

**`/clear`: 다른 일로 넘어갈 때 대화를 비웁니다**

앞의 작업과 상관없는 일을 시작한다면 대화를 이어 갈 이유가 없습니다. 비우고 시작하면 그때부터의 양만 쓰게 됩니다. 나중에 돌아올 대화라면 `/rename`으로 이름을 붙여 둔 뒤 `/resume`으로 다시 열면 됩니다.

**`/compact`: 이어서 작업하되 대화를 줄입니다**

같은 작업을 계속해야 해서 대화를 지울 수 없을 때 씁니다. 무엇을 남길지 함께 적을 수도 있습니다.

```
/compact 코드 예시와 수정 내역만 남겨 주세요
```

다만 요약하는 동작 자체가 대화를 한 번 읽는 일이라, 이미 대화가 아주 길어진 상태에서는 요약도 큰 작업이 됩니다. 이어 갈 필요가 없다면 `/clear`가 더 낫습니다.

**`/model`: 작업에 맞는 모델을 씁니다**

공식 문서는 대부분의 코딩 작업에 Sonnet이면 충분하고, Opus는 복잡한 구조 결정이나 여러 단계 추론이 필요할 때 쓰라고 권합니다.

이 밖에 `/context`로 지금 무엇이 자리를 차지하는지 볼 수 있고, `/mcp`로 쓰지 않는 서버를 꺼 둘 수 있습니다. [CLAUDE.md](/class/claude-code-for-everyone/claude-code-memory)는 매 세션 시작 시 읽히므로 200줄 안쪽으로 줄여 두는 편이 좋습니다.

## ⚠️ 한도에 걸렸을 때 할 수 있는 일

한도에 도달하면 메시지에 다시 열리는 시각이 표시됩니다. 그때까지 기다리는 것이 기본입니다.

기다릴 수 없다면 사용 크레딧이라는 선택지가 있습니다. 한도를 넘어서도 작업을 이어 가도록 추가 사용량을 붙이는 방식이고, `/usage-credits`로 관리합니다.

```
/usage-credits
```

Pro와 Max 구독자는 이 명령이 브라우저의 결제 설정을 엽니다. Team이나 Enterprise에서 결제 권한이 없는 구성원이라면 관리자에게 요청이 전달됩니다.

한 가지 알아 둘 점은 사용 크레딧으로 넘어가면 **캐시 유지 시간이 한 시간에서 5분으로 짧아진다**는 것입니다. 그만큼 같은 작업을 해도 쓰는 양이 늘어날 수 있습니다.

## ❓ 자주 묻는 질문

### Pro 플랜으로도 클로드 코드를 쓸 수 있나요?

쓸 수 있습니다. Pro, Max, Team, Enterprise 구독 모두 클로드 코드 사용량이 포함되어 있습니다. 다만 새 대화를 시작할 때 자동으로 잡히는 모델은 플랜마다 다르므로, 상위 모델을 쓰려면 `/model`로 직접 고르면 됩니다.

### 모델을 Haiku로 바꾸면 한도가 다시 열리나요?

열리지 않습니다. 세션 한도와 주간 한도는 모든 모델이 함께 쓰는 창이라서 모델을 바꿔도 회복되지 않습니다. 다만 "Opus 한도"처럼 특정 모델을 가리키는 메시지라면 다른 모델로 바꿔 작업을 이어 갈 수 있습니다.

### 클로드 채팅을 많이 쓰면 클로드 코드에 영향이 있나요?

Team과 Enterprise 플랜에서는 영향이 있습니다. 좌석 할당량을 클로드 채팅, 코워크, 클로드 코드가 함께 나눠 쓰기 때문입니다.

### /usage에 나오는 달러 금액은 제가 내야 하는 돈인가요?

구독자라면 아닙니다. 그 금액은 API 사용자를 위해 토큰 수를 표준 요금으로 환산해 보여주는 값이고, 구독 사용량과는 별개입니다.

## 📋 3줄 요약

1. 클로드 코드의 지불 방식은 월 정액에 사용량이 포함된 구독 플랜과 쓴 토큰만큼 청구되는 API 종량제로 나뉩니다.

2. 한도는 5시간 단위로 다시 채워지는 세션 창과 주간 창 두 개로 관리되고 이 양은 클로드 채팅과 코워크가 함께 나눠 씁니다.

3. 세션에서 /usage를 입력하면 스킬과 서브에이전트, MCP 가운데 무엇이 사용량을 많이 썼는지 항목별로 확인할 수 있습니다.
