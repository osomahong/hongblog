이 글은 앤트로픽 공식 요금 페이지(claude.com/pricing)를 한국 입문자가 보기 편하게 정리한 글입니다. 가격과 포함 기능은 **2026년 7월 기준**이며 시점이 지나면 달라질 수 있으니, 결제 전에는 원문 페이지를 함께 확인하시기 바랍니다.

## 💡 플랜을 가르는 기준은 두 가지입니다

[클로드](/class/claude-fundamentals/what-is-claude) 플랜을 고를 때 따져야 할 것은 두 가지뿐입니다.

- **쓸 수 있는 양**: 하루에 얼마나 많이 대화할 수 있는지
- **열리는 도구**: Claude Code, Cowork 같은 도구를 쓸 수 있는지

많이 쓰는 것과 도구가 열리는 것은 다른 문제입니다. 무료에서 Pro로 올라갈 때는 **도구가 열리고**, Pro에서 Max로 올라갈 때는 **양이 늘어납니다.**

> Claude Code, Claude Cowork, Claude Design은 Pro 플랜부터 포함됩니다. 무료 플랜에서는 채팅과 웹 검색, 파일 생성 같은 기본 기능만 쓸 수 있고, Max는 Pro의 기능을 그대로 둔 채 사용량을 5배 또는 20배로 늘린 플랜입니다.

## 📊 개인 플랜 한눈에 비교 (2026년 7월 기준)

| 항목 | Free | Pro | Max |
|---|---|---|---|
| **가격** | $0 | 월 $20 (연간 결제 시 월 $17) | 월 $100부터 |
| **사용량** | 기본 | Free보다 많음 | Pro의 5배 또는 20배 |
| **Claude Code** | 없음 | 포함 | 포함 |
| **Claude Cowork** | 없음 | 포함 | 포함 |
| **Claude Design** | 없음 | 포함 | 포함 |
| **프로젝트** | 제한 | 무제한 | 무제한 |
| **모델 선택** | 제한 | 여러 모델 선택 가능 | 여러 모델 선택 가능 |
| **새 기능 우선 접근** | 없음 | 없음 | 있음 |

연간 결제는 $200을 한 번에 내고 월 $17꼴로 쓰는 방식이라, 1년 이상 쓸 계획이라면 월 결제보다 부담이 적습니다.

## 🆓 무료 플랜으로 할 수 있는 일

무료 플랜은 생각보다 넓습니다. 공식 페이지가 밝히는 포함 범위는 다음과 같습니다.

- 웹, iOS, 안드로이드, 데스크톱 앱에서의 대화
- 코드 작성과 데이터 시각화, 콘텐츠 제작
- 웹 검색과 메모리, 파일 생성, 코드 실행
- 데스크톱 확장과 Slack, Google Workspace 연결
- 원격 MCP 연결
- [확장 사고](/class/claude-in-practice/what-is-extended-thinking)

문서를 요약하거나 글을 다듬는 정도의 일상 업무라면 무료로도 충분합니다. 하루에 몇 번 쓰는지가 판단 기준이 됩니다. 대화 도중 한도에 걸려 다음 시간을 기다리는 일이 반복된다면 그때 올리면 됩니다.

## 🔓 Pro에서 열리는 도구들

Pro로 올라갈 때 생기는 가장 큰 변화는 사용량이 아니라 **도구가 열린다**는 점입니다.

- **[Claude Code](/class/claude-code-for-everyone/what-is-claude-code)**: 터미널에서 대화로 코딩을 시키는 도구
- **[Claude Cowork](/class/claude-in-practice/claude-cowork-overview)**: 파일 정리, 문서 작성 같은 사무 작업을 맡기는 도구
- **Claude Design**: 콘셉트를 동작하는 프로토타입으로 옮기는 도구
- **Claude Science**: 연구 작업을 위한 도구
- **[무제한 프로젝트](/class/claude-in-practice/what-are-claude-projects)**: 자료와 지침을 미리 넣어 두고 반복 사용
- **Research 접근**과 여러 [모델 선택](/class/claude-fundamentals/claude-model-family)
- Microsoft 365 연결

반복 업무를 자동화하거나 코딩을 시켜 보려는 분에게는 이 지점이 갈림길입니다. 무료 플랜에서는 아무리 오래 써도 이 도구들이 나타나지 않습니다.

## 📈 Max를 고려할 시점

Max는 Pro의 기능을 그대로 두고 **사용량만 늘린** 플랜입니다. 5배와 20배 두 가지가 있고 월 $100부터 시작합니다.

Max가 더해 주는 것은 다음과 같습니다.

- Pro 대비 5배 또는 20배의 사용량
- 더 높은 출력 한도
- 새 기능 우선 접근
- 트래픽이 몰릴 때 우선 처리

판단 기준은 단순합니다. **Pro를 쓰면서 한도에 자주 걸린다면** 올릴 때입니다. 반대로 도구를 쓰고 싶어서 Max를 고르는 것은 낭비입니다. 도구는 Pro에서 이미 다 열려 있습니다.

## 👥 Team과 Enterprise는 계정 관리가 목적입니다

여러 명이 함께 쓸 때 고르는 플랜입니다. 개인 플랜과 다른 점은 기능보다 **관리 기능**에 있습니다.

| 플랜 | 가격 | 특징 |
|---|---|---|
| **Team (Standard 좌석)** | 연간 결제 시 월 $20, 월 결제 시 $25 | SSO, 관리자 제어, 중앙 청구 |
| **Team (Premium 좌석)** | 연간 결제 시 월 $100, 월 결제 시 $125 | Standard보다 많은 사용량 |
| **Enterprise** | 좌석당 $20에 사용량 기반 비용 추가 | 감사 로그, 데이터 보존 설정, IP 허용 목록 |

Team 플랜부터는 입력한 내용이 기본적으로 모델 학습에 쓰이지 않습니다. 회사 자료를 다루는 자리라면 이 항목이 판단 기준이 됩니다.

## 💼 직무별 플랜 선택 기준

**글쓰기와 자료 정리가 주 업무인 분**

무료로 시작해도 됩니다. 하루에 몇 번 요약이나 초안 작업을 하는 정도라면 한도에 잘 닿지 않습니다. 한도 메시지를 자주 보게 되는 시점이 Pro로 올릴 때입니다.

**반복 업무를 자동화하려는 마케터, 기획자**

Pro가 필요합니다. Cowork로 매주 반복되는 리포트 정리를 맡기거나 프로젝트에 회사 양식을 넣어 두는 일이 Pro부터 가능합니다.

**코딩을 시켜 보려는 분**

Pro가 시작점입니다. Claude Code가 Pro부터 열리고, 사용량 한도는 [플랜과 사용량 한도](/class/claude-code-for-everyone/claude-code-plans-and-limits) 클래스에서 따로 다룹니다.

**하루 종일 클로드를 실행해 두는 분**

Max를 검토할 단계입니다. 다만 먼저 Pro에서 한 달을 써 보고 한도에 실제로 얼마나 걸리는지 확인한 뒤 결정하는 편이 안전합니다.

## ❓ 자주 묻는 질문

### 무료 플랜으로 클로드 코드를 쓸 수 있나요?

쓸 수 없습니다. Claude Code는 Pro 플랜부터 포함됩니다. Cowork와 Design도 마찬가지입니다.

### Pro와 Max 중에 무엇을 골라야 할까요?

Pro로 시작하는 편이 좋습니다. 두 플랜의 기능은 같고 Max는 사용량만 늘린 것이라, Pro를 쓰면서 한도에 자주 걸릴 때 올리면 됩니다.

### 연간 결제가 얼마나 저렴한가요?

Pro 기준으로 월 결제는 $20이고, 연간 결제는 $200을 한 번에 내서 월 $17꼴이 됩니다. 1년에 $40 차이입니다.

### 회사 자료를 넣어도 학습에 쓰이나요?

Team과 Enterprise 플랜은 입력한 내용이 기본적으로 모델 학습에 쓰이지 않습니다. 개인 플랜에서 회사 자료를 다룰 때는 [책임감 있는 AI 사용](/class/claude-fundamentals/responsible-ai-use) 클래스의 기준을 함께 확인하시기 바랍니다.

## 📋 30초 요약

1. **무료에서 Pro로 올라갈 때는 도구가 열리고, Pro에서 Max로 올라갈 때는 양이 늘어납니다.** Claude Code, Cowork, Design은 모두 Pro부터 포함됩니다.

2. **Pro는 월 $20, 연간 결제 시 월 $17꼴이고 Max는 월 $100부터입니다**(2026년 7월 기준). Max는 Pro의 기능을 그대로 두고 사용량을 5배 또는 20배로 늘린 플랜입니다.

3. **자료 정리 정도면 무료로 시작하고, 자동화나 코딩을 시키려면 Pro, 한도에 자주 걸리면 Max를 검토합니다.** 여러 명이 쓰면서 회사 자료를 다룬다면 Team부터가 기준입니다.
