> 구글 안티그래비티(Google Antigravity)는 AI 에이전트를 실행하고 지켜보며 지시하는 구글의 독립 실행 프로그램입니다. 2026년 5월 19일 공개된 안티그래비티 2.0부터 편집기 없이 단독으로 돌아가고, 제미나이뿐 아니라 클로드와 GPT 계열 모델을 골라 쓸 수 있습니다.

## 클로드 코드 사용자 사이에서도 안티그래비티가 자주 언급되는 배경

[클로드 코드](/class/claude-code-for-everyone/what-is-claude-code)나 코덱스 CLI로 터미널에서 AI에 일을 맡기는 방식은 이제 익숙해졌습니다. 그런데 최근 검색창에 안티그래비티를 치는 사람이 늘었고, 안티그래비티가 편집기인지 명령어 도구인지 아니면 모델 이름인지 헷갈린다는 반응도 함께 나옵니다.

특히 제미나이 CLI를 쓰던 분들은 이미 영향을 받았습니다. 구글은 2026년 6월 18일부터 제미나이 CLI가 요청을 처리하지 않는다고 공지했습니다. 무료 사용자와 구글 AI 프로, 울트라 구독자가 대상이고 그 역할은 안티그래비티 CLI가 이어받습니다. 쓰던 명령어가 어느 날 멈추기 때문에 이름만 듣고 넘어가기 어려워졌습니다.

지금까지 쓰던 코딩 AI에 일을 맡기는 것이 연장 한 벌을 빌려주는 쪽이었다면, 안티그래비티에 일을 맡기는 것은 수리 기사에게 열쇠를 건네고 어느 방까지 들어가도 되는지 정해 주는 쪽에 가깝습니다. 무엇이 달라지는지 순서대로 정리했습니다.

![안티그래비티 2.0의 새 대화 화면, 프로젝트 이름과 지시문 입력창 아래에 모델 선택 메뉴와 로컬, 새 워크트리 모드를 고르는 목록이 열려 있다](/images/insights/google-antigravity-guide/01-antigravity-app.png)

위 이미지는 구글 안티그래비티 공식 사이트에 실린 제품 화면입니다. 폴더 이름 아래에 지시문 입력창이 있고, 그 아래에서 모델과 작업 방식을 고릅니다.

## 구글 안티그래비티의 정체, 편집기가 아니라 에이전트를 부리는 프로그램

안티그래비티는 코드 편집기도 AI 모델의 이름도 아닙니다. 공식 문서는 안티그래비티 2.0을 AI 에이전트를 한곳에서 지휘하는 중심 프로그램이라고 설명합니다. 예전에 편집기 안에 들어 있던 에이전트 매니저와 달리 편집기와 상관없이 단독으로 돌아갑니다.

쉽게 말해 **여러 AI 에이전트에게 일을 나눠 주고 진행 상황을 한 화면에서 보는 프로그램**입니다.

공식 문서가 밝힌 에이전트의 작업 범위는 이렇습니다.

- **시스템 명령 실행**: 터미널 명령을 직접 실행합니다
- **파일 읽기와 쓰기**: 지정한 폴더 안의 파일을 읽고 고칩니다
- **웹 검색**: 필요한 정보를 직접 찾습니다
- **외부 도구 연결**: 스킬과 [MCP](/insights/mcp-easy-guide-for-non-developers) 서버로 다른 도구를 붙입니다
- **서브에이전트 관리**: 에이전트가 다른 에이전트에게 일을 나눕니다
- **크롬 조작**: 브라우저를 직접 열어 결과를 확인합니다
- **아티팩트 생성**: 구현 계획과 작업 기록을 문서로 남깁니다

구글이 특히 내세우는 것은 마지막 항목입니다. 수리 기사가 시공 계획서와 작업 전후 사진을 남기듯, 에이전트도 무엇을 어떻게 하려는지 먼저 문서로 내놓습니다. 그 문서를 보고 사람이 판단합니다.

## 안티그래비티 2.0을 쓰는 세 가지 형태

2026년 9월 3일 기준으로 공식 문서에 올라온 구성입니다.

| 형태 | 버전 | 쓰는 방식 |
|---|---|---|
| 안티그래비티 2.0 데스크톱 | v2.12.0 | 맥, 윈도우, 리눅스용 프로그램을 설치 |
| 안티그래비티 CLI | v1.1.23 | 터미널에서 `agy` 명령으로 실행 |
| 편집기 확장(Antigravity for IDEs) | v2.5.5 | VS Code 같은 편집기에 확장으로 설치 |

여기에 파이썬, 타입스크립트, Go에서 쓰는 SDK와 기업용 매니지드 에이전트가 따로 있습니다. 개인 사용자는 위 세 가지에서 고르면 됩니다.

## 클로드와 GPT 모델을 안티그래비티 안에서 고르는 방법

안티그래비티 클로드 연동이라고 검색하는 분들이 많은데, 따로 연결할 것이 없습니다. 모델 선택 메뉴에서 바로 고르면 됩니다.

![안티그래비티 공식 문서의 모델 표, 제미나이 계열과 클로드 소넷 4.6, 클로드 오퍼스 4.6, GPT-OSS-120b의 요금제별 사용 가능 여부가 체크 표시로 정리되어 있다](/images/insights/google-antigravity-guide/02-models-table.png)

공식 문서의 모델 표를 보면 무료와 구글 AI 플러스, 프로, 울트라 요금제에서 아래 모델을 모두 쓸 수 있습니다.

- 제미나이 3.8 플래시, 3.7 플래시, 3.6 플래시, 3.1 프로
- 클로드 소넷 4.6(thinking), 클로드 오퍼스 4.6(thinking)
- GPT-OSS-120b

엔터프라이즈 요금제만 다릅니다. 이 요금제에서는 제미나이 계열만 쓸 수 있고 클로드와 GPT 계열이 빠집니다. 회사 계정으로 안티그래비티를 열었는데 클로드가 보이지 않는다면 요금제 종류를 먼저 확인하면 됩니다.

모델은 지시문 입력창 아래의 선택 메뉴에서 고르고, 한 대화 안에서는 직접 바꾸기 전까지 그대로 유지됩니다. UI 목업이나 다이어그램처럼 이미지를 만들어야 할 때는 나노 바나나 2가 자동으로 쓰입니다. 이 모델은 사용자가 고를 수 없습니다.

## 안티그래비티를 무료로 쓸 때 주어지는 사용량

공식 플랜 문서 기준으로 모든 요금제가 공통으로 받는 것은 제미나이 모델 사용과 무제한 탭 자동완성, 예약 작업과 CLI를 포함한 전체 기능입니다. 요금제에 따라 달라지는 것은 할당량을 다 쓴 뒤 다시 채워지는 주기입니다.

| 요금제 | 할당량 갱신 |
|---|---|
| 구글 AI 울트라 | 5시간마다 갱신, 주간 상한이 가장 높음 |
| 구글 AI 프로 | 5시간마다 갱신, 주간 상한에 닿으면 멈춤 |
| 프로와 울트라가 아닌 사용자 | 주 단위 갱신 |

한 가지 확인해 둘 점이 있습니다. 공식 문서는 한도가 프롬프트 개수가 아니라 에이전트가 처리한 작업량에 연동된다고 밝혔습니다. 간단한 지시는 여러 번 보낼 수 있고, 오래 걸리는 작업은 몇 번 만에 한도에 닿을 수 있다는 뜻입니다.

자기 API 키를 넣어 한도를 늘리는 방식은 지원하지 않습니다. AI 크레딧을 사서 기본 할당량을 넘겨 쓰는 것은 프로와 울트라 사용자만 가능합니다.

## 안티그래비티 설치와 첫 프로젝트 만들기

공식 문서가 밝힌 최소 사양입니다.

| 운영체제 | 요구 사항 |
|---|---|
| macOS | 12(몬터레이) 이상, 애플 실리콘 또는 인텔 |
| Windows | 윈도우 10 64비트 |
| Linux | glibc 2.28 이상, glibcxx 3.4.25 이상 |

설치 파일은 공식 다운로드 페이지에서 받습니다. 설치 중에 기존 안티그래비티를 그대로 두고 새로 설치할지 묻는 알림이 뜨면 Replace를 고르라고 문서에 적혀 있습니다.

설치를 마치면 프로젝트부터 만듭니다. 프로젝트는 에이전트가 들어갈 수 있는 폴더와 저장소의 범위입니다. 열쇠로 열리는 방을 미리 정해 두는 셈입니다.

1. 왼쪽 사이드바에서 폴더에 더하기 표시가 붙은 아이콘을 누릅니다
2. New Project를 고릅니다
3. Add Folder로 로컬 폴더나 깃 저장소를 넣습니다. 여러 개를 넣으면 저장소를 넘나드는 작업까지 지시합니다
4. Create를 누릅니다
5. 필요하면 프로젝트마다 독립된 설정과 보안 정책을 따로 둡니다

지시문을 입력하면 작업 방식을 고르는 창이 뜹니다. 로컬 모드는 지금 열어 둔 폴더에서 바로 작업하고, 새 워크트리 모드는 깃 워크트리를 따로 만들어 그 안에서만 작업합니다. 집으로 치면 안방을 바로 고치는 쪽과 똑같이 꾸민 옆방에서 먼저 시험해 보는 쪽의 차이입니다.

자주 쓰는 슬래시 명령은 네 가지입니다.

- `/goal`: 중간에 되묻지 않고 지시한 작업이 끝날 때까지 진행합니다
- `/grill-me`: 작업을 시작하기 전에 세부 사항을 되물어 계획을 맞춥니다
- `/schedule`: 지시를 예약해 한 번만 또는 주기적으로 실행합니다
- `/browser`: 크롬에서 확인하는 동작을 직접 지정합니다

## 안티그래비티 CLI(agy)와 제미나이 CLI 종료 일정

터미널에서 작업하던 분들에게는 CLI 쪽이 더 익숙할 수 있습니다. 안티그래비티 CLI는 데스크톱 프로그램이 쓰는 에이전트를 그대로 터미널에서 부르는 도구이고, 명령어는 `agy`입니다.

![안티그래비티 CLI 첫 실행 화면, 왼쪽에 색 구성표 목록이 있고 오른쪽에 에이전트가 코드를 고친 결과가 보인다](/images/insights/google-antigravity-guide/03-antigravity-cli.png)

설치 명령은 공식 문서에 이렇게 적혀 있습니다.

```bash
# macOS, Linux
curl -fsSL https://antigravity.google/cli/install.sh | bash

# Windows PowerShell
irm https://antigravity.google/cli/install.ps1 | iex
```

설치가 끝나면 프로젝트 폴더에서 `agy`를 실행합니다. 첫 실행에서 묻는 것은 색 구성표, 화면 표시 방식, 폴더 신뢰 여부 세 가지입니다. 폴더를 신뢰한다고 답하면 에이전트가 파일을 훑어 두고 지시를 기다립니다. CLI라는 말을 아직 안 써 보셨다면 [CLI 뜻 정리 글](/insights/cli-meaning-claude-code-guide)을 먼저 보시는 편이 빠릅니다.

[제미나이 CLI](/insights/gemini-cli-install-guide)를 쓰던 분들은 전환 일정을 확인해야 합니다. 구글은 2026년 5월 19일 안티그래비티 CLI를 전체 공개했습니다. 같은 공지에서 6월 18일부터 제미나이 CLI가 요청을 처리하지 않는다고 밝혔고, 대상은 무료 사용자와 구글 AI 프로, 울트라 구독자입니다. 깃허브 확장 설치도 같은 날 중단됐습니다. 제미나이 코드 어시스트 스탠다드나 엔터프라이즈 라이선스를 쓰는 기업 고객은 영향을 받지 않습니다.

만들어 둔 설정이 전부 사라지는 것은 아닙니다. 공식 공지는 에이전트 스킬과 훅, 서브에이전트가 안티그래비티 CLI에서도 유지된다고 밝혔습니다. 확장은 플러그인으로 이름만 바뀝니다.

## 클로드 코드, 코덱스와 무엇이 다를까요?

클로드 코드와 코덱스 CLI, 안티그래비티는 모두 AI에 코드를 맡기는 도구이지만 출발점이 다릅니다.

| 구분 | 클로드 코드, 코덱스 CLI | 안티그래비티 2.0 |
|---|---|---|
| 실행 형태 | 터미널 중심 | 데스크톱 프로그램, 터미널, 편집기 확장 |
| 쓰는 모델 | 만든 회사의 모델 | 제미나이와 클로드, GPT-OSS 중에서 선택 |
| 요금 근거 | 각 회사의 구독이나 API 키 | 구글 AI 요금제 |
| 작업 범위 | 실행한 폴더 기준 | 프로젝트에 여러 폴더와 저장소를 묶어 지정 |

여러 코딩 AI를 한 화면에서 돌린다는 점에서 [Orca](/insights/orca-ide-easy-guide) 같은 프로그램과 겹쳐 보이기도 합니다. Orca는 이미 설치해 둔 코딩 AI들을 불러와 지휘하고, 안티그래비티는 구글이 에이전트와 모델을 함께 제공하는 프로그램입니다.

지금 옮겨야 하는지는 쓰던 도구에 따라 달라집니다. 클로드 코드나 코덱스 CLI에 익숙하고 구독료를 이미 내고 있다면 서둘러 바꿀 이유는 크지 않아 보입니다. 반대로 제미나이 CLI를 쓰고 있었거나 구글 AI 프로나 울트라를 이미 결제하고 있다면 추가 비용 없이 시험해 볼 수 있습니다.

## 안티그래비티를 한국어로 쓸 때 확인할 두 곳

화면 메뉴와 에이전트 응답은 따로 움직입니다. 그래서 메뉴는 한국어인데 답변만 계속 영어로 나오는 경우가 생깁니다.

메뉴는 확장 탭에서 Korean Language Pack을 설치하고 프로그램을 다시 여는 방법이 커뮤니티에서 공유되고 있습니다. 편집기를 바탕에 둔 화면이라 VS Code에서 쓰던 방법이 그대로 통했다는 후기가 여럿 보입니다.

에이전트의 응답 언어는 다른 항목에서 정합니다. 안티그래비티는 Customizations라는 설정을 공식 기능으로 둡니다. 전역 규칙에 한국어로 답하라고 적어 두는 방법이 사용자들 사이에서 쓰이고 있습니다. 메뉴만 바꾸고 답변이 영어로 나온다면 이쪽을 확인하면 됩니다.

## 자주 묻는 질문

### 안티그래비티는 무료로 쓸 수 있나요?

설치와 사용 자체에는 구글 계정만 필요합니다. 공식 플랜 문서는 모든 요금제가 제미나이 모델과 무제한 탭 자동완성, 예약 작업과 CLI를 포함한 전체 기능을 받는다고 적었습니다. 다만 프로와 울트라가 아닌 사용자는 할당량이 주 단위로 갱신되어 한 번에 길게 쓰기는 어렵습니다.

### 안티그래비티에서 클로드를 쓰려면 앤트로픽 구독이 따로 필요한가요?

필요하지 않습니다. 공식 모델 표는 무료와 구글 AI 플러스, 프로, 울트라 요금제에서 클로드 소넷 4.6과 클로드 오퍼스 4.6을 쓸 수 있다고 표시합니다. 엔터프라이즈 요금제에서만 클로드와 GPT 계열이 빠집니다.

### 제미나이 CLI를 계속 쓸 수 있나요?

개인 사용자는 어렵습니다. 구글은 2026년 6월 18일부터 무료 사용자와 구글 AI 프로, 울트라 구독자에게 제미나이 CLI가 요청을 처리하지 않는다고 공지했습니다. 제미나이 코드 어시스트 스탠다드나 엔터프라이즈 라이선스를 쓰는 기업 고객, 그리고 유료 API 키를 쓰는 경우는 예외입니다.

## 3줄 요약

- 구글 안티그래비티는 제미나이와 클로드, GPT 계열 모델을 골라 여러 AI 에이전트에게 일을 시키는 구글의 독립 실행 프로그램입니다. 안티그래비티 2.0부터 편집기 없이 단독으로 돌아갑니다.
- 데스크톱 프로그램과 터미널 명령 `agy`, 편집기 확장 세 가지 형태가 있고, 프로젝트로 폴더 범위를 정한 뒤 로컬 모드와 새 워크트리 모드에서 작업 방식을 고릅니다.
- 구글 AI 프로와 울트라는 5시간마다, 그 아래 요금제는 주 단위로 할당량이 갱신되고 한도는 프롬프트 개수가 아니라 에이전트가 처리한 작업량에 연동됩니다.

안티그래비티라는 이름이 자주 들린다고 해서 지금 쓰는 도구를 바꿔야 하는 것은 아닙니다. 제미나이 CLI를 쓰고 있었다면 옮길 이유가 분명하고, 클로드 코드나 코덱스로 일이 되고 있다면 무료 할당량으로 안티그래비티를 한 번 띄워 보는 정도면 됩니다.
