제미나이 3.8 라이브(Gemini 3.8 Live)는 구글이 2026년 9월 15일 공개한 실시간 음성 대화 모델입니다. 같은 날 추론을 강화한 제미나이 3.8 라이브 확장 추론(Gemini 3.8 Live Extended Thinking)도 함께 나왔습니다.

AI와 말로 대화하는 기능은 이미 여러 서비스에 들어와 있습니다. 스마트폰 비서에게 말을 걸거나 AI 앱의 음성 대화 버튼을 눌러 본 분들이 많습니다.

덜 알려진 것은 이번에 나온 두 모델이 실제 상담 창구를 대신할 수 있는지입니다. 안내원이 서류를 찾는 동안 말을 이어 가듯, 음성 에이전트도 고객 정보를 찾아보는 동안 말을 이어 가야 통화가 끊기지 않습니다. 찾는 동안 무엇을 하느냐가 두 모델에서 달라집니다. 구글 공식 발표와 제미나이 API 문서를 근거로 2026년 9월 16일 기준으로 정리합니다.

![구글 공식 블로그의 제미나이 3.8 라이브 발표 이미지. Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking이라는 문구와 제미나이 로고가 표시되어 있다](/images/insights/gemini-3-8-live-voice-agent-guide/gemini-3-8-live-announcement.png)

## 제미나이 3.8 라이브와 확장 추론형의 쓰임 차이

같은 날 나왔지만 겨냥한 곳이 다릅니다. 구글은 기본형을 대량 처리와 비용을 아끼는 데 맞는 모델로, 확장 추론형을 복잡한 작업에 맞는 모델로 설명합니다.

| 항목 | 제미나이 3.8 라이브 | 제미나이 3.8 라이브 확장 추론 |
|---|---|---|
| 모델 이름 | gemini-3.8-live | gemini-3.8-live-extended-thinking |
| 겨냥한 용도 | 지연 없는 음성 응대와 실시간 대화 | 여러 단계를 처리해야 하는 작업 |
| 추론 방식 | 대화 흐름 우선 | 말하면서 동시에 추론 |
| 배경 작업 | 도구와 API 호출 | 여러 단계 작업을 이어서 처리 |

확장 추론형은 답을 찾는 동안에도 말을 멈추지 않습니다. 침묵이 길어지면 통화가 끊긴 것처럼 느껴지는데, 확인해 보겠다는 식의 말을 먼저 꺼내고 진행 상황을 말로 알려 주며 작업을 이어 갑니다.

## 제미나이 3.8 라이브 대화에서 달라진 세 가지

구글이 제미나이 3.8 라이브를 설명하며 밝힌 변화는 세 가지입니다.

- **언어 97개 자동 전환**: 대화 도중 언어가 바뀌면 알아서 감지하고 넘어갑니다. 설정에서 언어를 미리 고르지 않아도 됩니다.
- **시각 입력 처리**: 카메라로 비춘 화면을 거의 실시간으로 함께 봅니다. 눈앞의 물건을 보여 주면서 물어볼 수 있습니다.
- **배경 도구 호출**: 요청을 받아들였다고 먼저 말하고, 도구 호출과 API 조회는 대화를 이어 가는 동안 뒤에서 처리합니다.

세 번째 변화가 음성 상담에 직접 영향을 주는데, 조회가 끝날 때까지 말이 멈추는 시간이 사라지면 사람이 응대하는 통화에 가까워집니다.

공개 자료에는 실제 사용 예시도 나와 있습니다. 기본형은 사용자가 화면을 비추면 신입 교육 절차를 단계별로 안내하고, 확장 추론형은 손으로 그린 스케치와 음성 지시를 받아 리액트 화면 구성 요소를 만들어 냅니다.

## 벤치마크 점수와 경쟁 모델 비교

구글이 공개한 점수는 다음과 같습니다. 표에는 독립 평가 기관의 음성 품질 지수와 음성 에이전트 대상 평가가 섞여 있습니다.

| 평가 | 3.8 라이브 확장 추론 | 3.8 라이브 | 비교 대상 |
|---|---|---|---|
| 음성 품질 지수 | 82.6 | 76.0 | GPT 라이브 1 아스트라(GPT-Live-1 Astra, Medium) 81.5, 그록 보이스 싱크 패스트 2.0(Grok Voice Think Fast 2.0, High) 81.3 |
| 에이전트 작업 완수 | 68.6% | 공개되지 않음 | GPT 라이브 1 아스트라 67.9%, 그록 보이스 싱크 패스트 2.0 56.5% |
| 금융 상담 평가 | 35.1% | 공개되지 않음 | GPT 라이브 1 아스트라 32.0% |
| 오디오 추론 | 97.7% | 공개되지 않음 | 공개되지 않음 |

확장 추론형은 음성 품질 지수에서 1위를 기록했고, 기본형은 사용자가 직접 골라 순위를 매기는 음성 에이전트 아레나에서 2위에 올랐습니다.

눈여겨볼 것은 금융 상담 평가의 절대 점수입니다. 1위가 35.1%라는 것은 실제 상담 업무를 끝까지 처리하는 일이 아직 어렵다는 뜻입니다. 음성 품질이 좋아진 것과 업무를 완결하는 것은 다른 문제이므로, 상담 전체를 맡기기보다 앞단 응대와 정보 조회부터 적용해 보는 편이 안전하다고 봅니다.

## 두 모델의 가격과 실제 비용 차이

공식 가격표를 보면 두 모델의 단가가 같습니다. 아래 수치는 2026년 9월 유료 등급에 해당합니다.

| 구분 | 단가 |
|---|---|
| 오디오 입력 | 100만 토큰당 3달러 또는 분당 0.005달러 |
| 오디오 출력 | 100만 토큰당 12달러 또는 분당 0.018달러 |
| 이미지와 영상 입력 | 100만 토큰당 1달러 또는 분당 0.002달러 |
| 텍스트 입력 | 100만 토큰당 0.75달러 |
| 텍스트 출력 | 100만 토큰당 4.50달러 |

단가가 같다고 해서 청구액이 같아지지는 않습니다. 확장 추론형은 배경에서 생각하는 데 토큰을 더 쓰기 때문입니다.

독립 평가 기관이 입력 오디오 한 시간을 기준으로 잡은 계산에서는 시간당 비용이 기본형 0.84달러, 확장 추론형 3.50달러로 나왔습니다. 같은 기준에서 그록 보이스 싱크 패스트 2.0은 4.80달러, GPT 라이브 1 아스트라는 5.83달러였습니다. 셈하는 방식에 따라 달라지는 수치이므로 차이의 크기만 참고하면 됩니다.

통화 한 건의 평균 길이와 하루 건수부터 정리해 두면 비용을 미리 가늠할 수 있습니다. 분당 단가가 나와 있으니 통화 시간에 곱하면 월 비용이 대략 나옵니다.

## 제미나이 3.8 라이브를 지금 써 볼 수 있는 경로

개발자가 쓸 수 있는 곳은 제미나이 API와 구글 AI 스튜디오 두 군데이고, 어느 쪽에서든 두 모델을 모두 고를 수 있습니다. 기업용인 제미나이 엔터프라이즈에서는 두 모델 모두 아직 비공개 프리뷰 단계입니다.

연결에 쓰는 것은 Live API이고, 문서에는 프리뷰 단계라고 표시되어 있습니다. 앱과 모델이 웹소켓으로 계속 연결된 채 오디오와 영상, 텍스트를 주고받는 구조입니다.

![구글 AI for Developers의 제미나이 Live API 개요 문서 한국어 페이지. Live API가 프리뷰 단계라는 안내와 함께 앱과 Live API가 웹소켓으로 연결되어 텍스트, 오디오, 영상을 주고받는 구조 그림이 표시되어 있다](/images/insights/gemini-3-8-live-voice-agent-guide/gemini-live-api-docs.png)

개발 없이 써 보는 방법도 있습니다. 확장 추론형은 제미나이 라이브와 구글 워크스페이스의 문서, 지메일, 킵에 들어갔고, 기본형은 검색 라이브에서 쓰입니다. 워크스페이스 쪽은 구독 등급에 따라 제공 범위가 달라집니다.

음성 인프라를 직접 만들 필요도 없습니다. 구글은 발표에서 라이브키트(LiveKit)와 파이프캣(Pipecat), 아고라(Agora)를 비롯한 플랫폼들이 Live API 연동을 제공한다고 밝혔습니다.

## 음성 에이전트를 만들 때 먼저 정할 것

모델을 고르기 전에 생각해 둘 항목이 있습니다. 여기서 정해 두면 시행착오가 줄어듭니다.

1. **끊김을 어디까지 허용할지 정합니다.** 조회가 오래 걸리는 업무라면 배경 처리 중 무슨 말을 할지 대본을 먼저 만듭니다.
2. **사람에게 넘기는 조건을 정해 둡니다.** 금융 상담 평가 점수가 보여 주듯 끝까지 처리하지 못하는 문의가 남습니다.
3. **음성 기록의 보관 범위를 미리 잡습니다.** 통화 내용에는 개인정보가 섞이므로 저장 여부와 기간을 먼저 확인합니다.

세 번째와 이어지는 이야기가 하나 더 있습니다. 구글이 만든 음성에는 SynthID 워터마크가 들어갑니다. 사람 귀로는 알아채기 어렵지만 AI가 만든 소리인지 판별할 수 있게 넣는 표시라서, 안내 음성을 외부에 내보낼 때는 이 워터마크가 들어간 채로 나가도 되는지 미리 확인합니다.

## 자주 묻는 질문

### 한국어 음성 대화도 자연스럽게 되나요?

언어 97개에 한국어가 들어 있고, 대화 도중 언어가 바뀌어도 따라간다고 구글이 밝혔습니다. 다만 구글이 공개한 점수는 언어별로 나뉘어 있지 않아서, 한국어 통화 품질은 구글 AI 스튜디오에서 직접 말해 보고 판단해야 합니다.

### 기본형과 확장 추론형 가운데 무엇을 고르면 되나요?

문의 유형을 기준으로 정하면 쉽습니다. 영업시간 안내나 주문 조회처럼 한 번에 끝나는 문의가 많으면 기본형으로 충분하고, 조건을 따져 여러 시스템을 거쳐야 하는 업무라면 확장 추론형 쪽이 맞습니다. 단가는 같지만 실제로 내는 돈은 확장 추론형이 더 많습니다.

### 기존 전화 시스템에 바로 붙일 수 있나요?

모델은 Live API로 연결되므로 전화망과 잇는 작업은 따로 해야 합니다. 앞서 적은 라이브키트나 파이프캣 같은 플랫폼이 이 부분을 맡아 주므로, 전화망 연결을 처음부터 만들지 않아도 됩니다.

## 3줄 요약

- 제미나이 3.8 라이브와 3.8 라이브 확장 추론은 구글이 2026년 9월 15일 공개한 실시간 음성 대화 모델이고, 제미나이 API와 구글 AI 스튜디오에서 바로 고를 수 있습니다.
- 기본형은 대화 도중 언어가 바뀌면 97개 안에서 알아서 감지해 따라가고, 말을 이어가면서 배경으로 도구와 API를 호출하며, 카메라로 비춘 화면도 거의 실시간으로 봅니다.
- 확장 추론형은 음성 품질 지수 82.6으로 1위에 올랐고, 공식 단가는 기본형과 같지만 배경에서 생각하는 데 토큰을 더 쓰기 때문에 실제로 내는 돈은 더 듭니다.
