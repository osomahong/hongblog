미니맥스 H3(MiniMax H3)는 중국 AI 기업 미니맥스가 2026년 7월 31일 공개한 옴니모달 영상 생성 모델로, 텍스트, 이미지, 영상, 오디오를 하나의 컨텍스트로 읽어 최대 15초 영상을 스테레오 음향과 함께 생성합니다. 자사 영상 서비스인 하이루오(Hailuo) AI 앱에 탑재된 모델이라, 국내외 매체에서는 하이루오 3.0이라는 별칭으로 부르기도 합니다. 공식 명칭은 미니맥스 H3 하나입니다.

영상 생성 AI를 지켜봐 온 분들에게 새 모델 소식 자체는 낯설지 않을 겁니다. 그런데 이번 모델은 성능 이야기보다 먼저 확인할 것이 있습니다. 오픈 웨이트로 공개됐는데, 그 라이선스 원문이 대한민국을 제외 지역으로 명시하고 있다는 점입니다. 이 조건을 모른 채 "오픈 소스니까 받아서 쓰면 되겠다"로 접근하면 라이선스 위반 위에서 작업하게 됩니다.

스펙과 요금, 그리고 한국 사용자에게 실질적인 라이선스 쟁점까지 공식 문서와 라이선스 원문을 기준으로 정리하겠습니다. 2026년 8월 12일 기준입니다.

![미니맥스가 공식 블로그의 멀티모달 컨텍스트 데모에 참조 입력으로 쓴 카페 장면 이미지. 야외 카페에서 컵을 든 여성의 실사풍 프레임](/images/insights/minimax-h3-overview/h3-cafe-reference.jpg)

위 이미지는 미니맥스가 공식 블로그의 데모에서 참조 입력으로 쓴 카페 장면입니다. H3는 이런 이미지를 참조로 받아 인물과 장면의 일관성을 유지한 영상을 만드는 방식을 내세우고 있습니다.

## 스펙: 하나의 모델로 합쳐진 영상 작업들

공식 모델 카드와 API 문서 기준의 사양입니다.

| 항목 | 내용 |
|------|------|
| 모델 구조 | 33B 파라미터 옴니모달 트랜스포머 |
| 입력 | 텍스트, 이미지(최대 9장), 영상 클립(최대 3개), 오디오(최대 3개)를 한 컨텍스트로 |
| 출력 | 4~15초(API 기준, 정수 단위) 영상, 24fps, 32kHz 스테레오 오디오 동시 생성 |
| 해상도 | 768p 생성 후 2K 재생성 |
| API 모델 ID | MiniMax-H3 |

미니맥스가 공식 블로그에서 내세우는 차별점은 통합입니다. 그동안 영상 편집, 인물 참조, 모션 전이가 각각 별도의 전문 모델로 나뉘어 있던 것을, 하나의 사전학습 체계로 합쳤다는 설명입니다. 요리사마다 담당 요리가 나뉘어 있던 주방을 한 명이 전 메뉴를 만드는 주방으로 바꿨다는 주장인 셈입니다. 지시 이행과 텍스트, 브랜드 렌더링 정확도도 강조 지점에 들어 있습니다.

성능의 외부 평가로는 Artificial Analysis의 Video Arena 리더보드가 참고가 됩니다. 2026년 8월 기준 텍스트 투 비디오 부문에서 H3는 Elo 1,237로 2위에 올라 있고, 오픈 웨이트 모델 가운데는 최상위입니다. 다만 Elo는 사람들의 선호 투표에 기반한 상대 평가라, 순위 하나로 품질을 단정하기는 어렵습니다.

## 2K의 실제 구조: 한 번이 아니라 두 단계

발표 문구의 "2K 영상"은 그대로 읽으면 오해가 생기는 지점입니다. 공식 문서 기준으로 H3의 2K는 한 번에 생성되지 않습니다.

![미니맥스 H3 시스템 개요 공식 도식. 멀티모달 입력이 컨텍스트 이해를 거쳐 H3-Base에서 768p 영상으로 생성되고, H3-Regenerate-2K가 이를 다시 2K 영상으로 재생성하는 흐름이 세 단계로 그려져 있다](/images/insights/minimax-h3-overview/h3-system-overview.png)

위 공식 도식이 보여주듯 기본 모델(H3-Base)이 768p 영상을 만들고, 별도의 재생성 모델(H3-Regenerate-2K)이 원본 컨텍스트를 다시 참고해 2K로 다시 만듭니다. 요금표에도 재생성이 별도 과금 항목으로 잡혀 있어 이 구조가 그대로 반영되어 있습니다.

이 구조가 중요한 이유는 오픈 웨이트와 이어지기 때문입니다. 공개된 가중치로 받을 수 있는 기본 모델 단독으로는 768p까지이고, "오픈 웨이트로 2K 영상을 만든다"는 서술은 성립하지 않습니다.

## API 요금: 15초 2K 한 편의 계산

2026년 8월 12일 기준 공식 종량제 요금표의 주요 항목입니다.

| 항목 | 요금 |
|------|------|
| 768p 출력 | 초당 $0.08 |
| 2K 출력 | 초당 $0.13 |
| 재생성 (768p에서 2K로) | 초당 $0.05 |
| 참조 이미지 | 5장까지 무료, 이후 장당 $0.04 |
| 참조 오디오 | 무료 |

최대 길이인 15초를 2K로 뽑으면 출력 요금만 $1.95입니다. 참조 소재 과금이 별도로 붙을 수 있으니 실제 비용은 소재 구성에 따라 달라집니다. 미니맥스는 자사 블로그에서 2K 기준 초당 단가가 주류 모델의 3분의 1 미만이라고 주장하는데, 비교 대상 모델을 특정하지 않은 자사 발표라 그대로 받아들이기보다 참고 수준으로 두는 편이 맞겠습니다. 포인트 방식 패키지는 H3를 지원하지 않아 API는 종량제로만 쓸 수 있습니다.

## 핵심 쟁점: 라이선스가 한국을 제외 지역으로 명시

이 글에서 가장 중요한 대목입니다. H3의 가중치는 2026년 8월 초 허깅페이스에 공개됐는데, 함께 실린 커뮤니티 라이선스 원문이 적용 지역을 이렇게 정의합니다.

> 라이선스 원문은 제외 지역(Excluded Territories)을 유럽연합, 영국, 대한민국, 미국으로 정의하고, 적용 지역을 그 제외 지역을 뺀 전 세계로 규정합니다.

대한민국이 국호로 명시되어 있습니다. 그리고 금지 조항은 흔히 요약되는 "로컬 배포 금지"보다 범위가 넓습니다. 원문은 적용 지역 밖에서 이 모델과 그 산출물을 사용, 복제, 수정, 배포, 표시하는 것을 허용하지 않는다고 적고 있어, 가중치를 내려받아 돌리는 행위뿐 아니라 산출물의 사용까지 문언에 포함됩니다.

한편 미니맥스는 공식 저장소의 라이선스 Q&A 문서에서 이렇게 구분해 설명합니다. API는 안전장치를 갖춰 전 세계에 제공하고, 오픈 웨이트는 규제와 컴플라이언스 체계가 명확해질 때까지 일부 지역에서 일시적으로 제한한다는 것입니다. 제외 지역 사용자를 위한 개별 승인 신청 경로도 안내되어 있습니다. 다만 이 구분은 계약서 본문이 아니라 회사의 해설 문서에 근거한 것이라, 산출물 조항과 API 약관의 관계까지 정리된 공식 문서는 아직 없습니다. 상업 규모가 크거나 결과물을 캠페인에 쓸 계획이라면 이 글이 아니라 법률 검토가 판단 근거가 되어야 합니다.

## 국내 실무자의 현실적인 접근 순서

라이선스 조건을 전제로 놓으면 국내에서의 선택지는 이렇게 정리됩니다.

- **하이루오 앱과 공식 API가 기본 경로입니다.** 미니맥스가 공식 Q&A에서 전 세계 제공이라고 밝힌 경로이고, 종량제 요금도 공개되어 있습니다. 짧은 광고 소재나 SNS 영상처럼 15초 안에서 음향까지 한 번에 나오는 작업 흐름을 시험해 보기에 적합합니다.
- **가중치 직접 실행은 보류합니다.** 라이선스 원문이 한국을 제외 지역으로 명시한 상태라, 사내 GPU에 올려 쓰는 방식은 현재 조건에서 허용되지 않습니다. 개별 승인 신청 경로가 있으니 로컬 실행이 꼭 필요한 조직은 그쪽을 먼저 확인하는 순서입니다.
- **결과물의 상업 활용은 근거를 남기며 진행합니다.** 산출물 조항과 API 약관의 관계가 문서로 정리되어 있지 않으므로, 캠페인 소재처럼 외부에 나가는 결과물은 이용 시점의 약관을 저장해 두고 판단 근거를 남기는 운영이 안전합니다.

## 한국에서는 아예 쓸 수 없는 건가요?

아닙니다. 제한이 명시된 것은 오픈 웨이트, 즉 가중치를 내려받아 직접 실행하는 방식입니다. 하이루오 앱과 공식 API는 미니맥스가 전 세계 제공이라고 설명하는 경로이고, 실제로 국내에서 접속해 쓰는 데 별도 차단이 안내된 바 없습니다. "한국 제외"라는 표현만 보고 모델 전체를 못 쓴다고 읽으면 과장이고, 반대로 아무 제약이 없다고 읽어도 부정확합니다. 경로별로 조건이 다르다는 것이 정확한 요약입니다.

## 오픈 웨이트를 받으면 2K 영상을 만들 수 있나요?

공개된 기본 모델 단독으로는 768p까지입니다. 2K는 별도의 재생성 모델이 맡는 2단계 구조라, 공식 문서 기준으로 "오픈 웨이트로 2K까지 전부 재현"은 성립하지 않습니다. 여기에 앞서 정리한 지역 제한까지 겹치므로, 한국에서 2K 결과물이 필요하다면 현재로서는 API의 재생성 과금(초당 $0.05 추가)을 쓰는 경로가 공식적인 방법입니다.

**3줄 요약:**
- 미니맥스 H3는 텍스트, 이미지, 영상, 오디오를 한 컨텍스트로 읽어 최대 15초 영상을 스테레오 음향과 함께 만드는 33B 옴니모달 모델입니다. 2026년 7월 31일 공개됐고 하이루오 앱과 API로 제공됩니다.
- 2K는 768p 생성 후 재생성하는 2단계 구조이고, 공개된 가중치 단독으로는 768p까지입니다. API 종량제는 2K 초당 $0.13에 재생성 초당 $0.05가 붙습니다.
