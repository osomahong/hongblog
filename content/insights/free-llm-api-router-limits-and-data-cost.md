무료 LLM API 라우터는 여러 업체가 각자 주는 무료 사용 한도를 모아 OpenAI 호환 엔드포인트 하나로 묶어 주는 도구입니다. 여러 매장의 시식 코너를 돌며 접시 하나에 담는 것과 비슷한 방식이고, 공개된 구현이 여럿 나와 있습니다.

AI로 무언가 만들어 보려면 코딩 도구 구독료가 듭니다. 최저 요금제가 월 10달러에서 20달러 선인데, 이것저것 시켜 보며 배우는 동안 한도가 금방 바닥납니다. 그래서 무료로 쓸 방법을 찾게 됩니다.

덜 알려진 쪽은 그 무료가 어떤 조건으로 주어지는지입니다. 한도가 얼마인지는 공식 문서에도 잘 적혀 있지 않고, 무료로 쓰는 대신 무엇을 내주는지는 약관 안쪽에 있습니다. 각 업체의 공식 문서와 약관을 근거로 2026년 9월 7일 기준으로 정리하겠습니다.

## 여러 업체의 무료 한도를 하나로 묶는 방식

무료 사용 한도를 주는 곳은 한둘이 아닙니다. 구글, 엔비디아, Groq, Cerebras, OpenRouter, 클라우드플레어를 비롯해 여러 업체가 홍보와 시험 목적으로 일정량을 무료로 엽니다. 문제는 각각 따로 가입해서 키를 받아야 하고, 한도도 응답 속도도 제각각이라는 점입니다.

라우터는 이 키들을 한자리에 등록해 두고 요청이 올 때마다 쓸 수 있는 곳으로 넘깁니다. 한 곳이 한도에 걸리면 다음 곳으로 넘어가고, 호출하는 쪽에서는 주소 하나만 바라봅니다. OpenAI 호환 형식을 쓰기 때문에 클로드 코드나 코덱스 CLI 같은 도구에 주소와 모델 이름만 바꿔 붙일 수 있습니다.

- **모으는 것**: 여러 업체의 무료 키를 한곳에 등록
- **넘기는 것**: 한도에 걸리면 다음 업체로 자동 전환
- **보이는 것**: 호출하는 쪽에는 엔드포인트 하나

대신 준비 과정이 번거롭습니다. 업체마다 가입하고 키를 발급받아야 하고, 응답이 느리거나 품질이 떨어지는 모델을 걸러 두는 작업도 필요합니다. 한 번 해 두면 오래 쓰지만 처음 들이는 시간이 적지 않습니다.

## 공식 문서로 확인되는 무료 한도

![OpenRouter 공식 문서의 무료 모델 한도 표. 누적 구매 크레딧이 10달러 미만이면 분당 20회에 하루 50회, 10달러 이상이면 분당 20회에 하루 1,000회로 적혀 있다](/images/insights/free-llm-api-router-limits-and-data-cost/openrouter-free-limits.png)

한도를 확인하려다 보면 먼저 막히는 곳이 있습니다. **무료 티어의 정확한 수치를 공식 문서에 적지 않고 계정 설정 화면으로 넘기는 업체가 있습니다.** Groq 공식 문서는 요약만 두고 실제 한도는 계정의 한도 페이지에서 보라고 안내하며, 구글도 AI 스튜디오에서 확인하라고 적어 두었습니다.

수치를 공개해 둔 곳은 OpenRouter입니다. 위 화면이 공식 문서의 표이고 내용은 이렇습니다.

| 누적 구매 크레딧 | 분당 요청 | 하루 요청 |
|---|---|---|
| 10달러 미만 | 20회 | 50회 |
| 10달러 이상 | 20회 | 1,000회 |

한 번이라도 10달러어치를 사 두면 하루 한도가 스무 배가 됩니다. 이후로는 무료 모델만 쓰더라도 구매 이력이 남아 있어 같은 한도가 유지됩니다.

무료 모델이 몇 개나 되는지도 확인할 수 있습니다. 2026년 9월 7일 기준 OpenRouter의 모델 목록 API를 조회하면 전체 430개 가운데 입력과 출력 단가가 모두 0인 모델이 21개입니다. 그중에는 컨텍스트 100만 토큰짜리도 있습니다.

한도를 늘리려고 키를 여러 개 만드는 것은 소용이 없습니다. Groq 공식 문서에 따르면 한도는 개별 사용자가 아니라 조직 단위로 적용됩니다.

## 무료 티어의 대가는 데이터입니다

![구글 제미나이 API 약관의 무료 서비스 절. 무료 서비스에 제출한 콘텐츠와 생성된 대답을 구글 제품과 머신러닝 기술을 개선하고 개발하는 데 사용하며, 인적 검토자가 API 입력과 출력을 읽고 주석을 달 수 있고, 민감한 정보와 기밀 정보를 무료 서비스에 제출하지 말라는 문장이 굵게 강조돼 있다](/images/insights/free-llm-api-router-limits-and-data-cost/gemini-unpaid-terms.png)

무료 사용 한도가 왜 주어지는지는 약관에 적혀 있습니다. 위 화면은 구글 제미나이 API 약관의 무료 서비스 절입니다.

> 무료 서비스를 사용하는 경우 구글은 제출한 콘텐츠와 생성된 대답을 사용하여 구글 제품 및 서비스와 머신러닝 기술을 제공하고, 개선하고, 개발합니다.

여기서 그치지 않습니다. 같은 절에는 사람이 읽는다는 내용도 포함됩니다.

> 구글 제품의 품질을 관리하고 개선하기 위해 인적 검토자가 API 입력 및 출력을 읽고, 주석을 달고, 처리할 수 있습니다.

시식 코너에서 점원이 반응을 지켜보듯, 무료로 쓰는 동안 입력과 출력은 품질 개선의 재료가 됩니다. 구글은 검토자가 보기 전에 계정과 API 키, 클라우드 프로젝트와의 연결을 끊는다고 밝히면서도, 문장 하나를 굵게 강조해 두었습니다.

> 민감한 정보, 기밀 정보 또는 개인 정보를 무료 서비스에 제출하지 마세요.

업무 문서나 고객 정보를 무료 티어에 넣는 것이 왜 위험한지가 여기에 있습니다. 개인 실습이라면 문제가 되지 않지만, 일하면서 쓰는 자료라면 이야기가 달라집니다.

## 결제 계정만 연결해도 데이터 취급이 달라집니다

같은 약관에 실무에서 바로 쓸 수 있는 대목이 있습니다. 구글은 결제 계정을 활성화하면 무료 할당량을 쓰는 경우에도 데이터 사용 방식 측면에서 유료 서비스로 간주한다고 적어 두었습니다.

정리하면 이렇습니다.

| 구분 | 결제 계정 없이 무료 할당량 | 결제 계정 연결 후 무료 할당량 |
|---|---|---|
| 제품 개선에 사용 | 사용함 | 사용하지 않음 |
| 인적 검토자 열람 | 약관에 명시됨 | 해당 조항 없음 |
| 기록 보관 | 제품 개선 목적 포함 | 안전과 법적 요구 목적으로 제한된 기간 |
| 적용 약관 | 무료 서비스 조항 | 데이터 처리 부록 |
| 실제 요금 | 없음 | 할당량 안에서는 없음 |

결제 계정을 연결해도 무료 할당량 안에서 쓰는 동안에는 요금이 나가지 않습니다. 그런데도 데이터 취급 기준은 유료 쪽으로 바뀝니다. 무료 할당량을 쓰면서 데이터 보호 조건을 높이는 방법입니다.

지역에 따라 조건이 다르다는 점도 함께 봐야 합니다. 약관은 유럽 경제 지역과 스위스, 영국을 기반으로 하는 경우 무료로 제공되는 서비스에도 유료 서비스의 데이터 조항이 적용된다고 밝힙니다. 한국은 여기에 들어가지 않습니다.

OpenRouter처럼 여러 업체를 중계하는 곳은 다른 방식으로 다룹니다. 계정 설정에서 학습을 거부하면 프롬프트로 학습하는 제공사로는 요청을 넘기지 않습니다. 다만 선택할 수 있는 모델이 그만큼 줄어듭니다.

## 약관에서 선을 넘는 지점

여러 업체의 무료 한도를 함께 쓰는 것 자체는 각 업체가 열어 둔 범위 안의 일입니다. 문제가 되는 것은 한도를 넘기려는 시도입니다.

- **계정을 여러 개 만들어 한도를 늘리는 것.** 여러 업체가 약관에서 금지하고 있어 적발되면 계정 정지로 이어질 수 있습니다.
- **엔드포인트를 다른 사람과 나눠 쓰거나 되파는 것.** 무료 한도는 가입한 본인에게 주어진 것입니다.
- **무료 한도로 실제 서비스를 돌리는 것.** 시식으로 장사 밑천을 삼지 않듯, 무료 티어는 시험과 학습용으로 열어 둔 몫입니다. 한도는 예고 없이 조정될 수 있어 서비스 안정성도 담보되지 않습니다.

한 업체당 계정 하나를 쓰고, 만든 엔드포인트를 혼자 쓰고, 운영 중인 서비스에 연결하지 않는 선이면 대체로 안전합니다.

## 무료로 돌릴 일과 돈을 낼 일

무료 한도를 다 모아도 유료 구독을 대체하지는 못합니다. 응답 속도와 품질이 고르지 않고, 한도에 걸리면 기다려야 합니다. 그래서 무엇을 어디에 맡길지 나누는 편이 낫습니다.

- **무료로 돌릴 일**: 여러 모델의 성격을 비교해 보는 시험, 공개 자료를 대상으로 한 반복 작업, 문법 정리나 형식 변환처럼 실수해도 확인이 쉬운 일
- **돈을 낼 일**: 업무 자료가 들어가는 작업, 여러 단계를 이어 가며 판단이 쌓이는 작업, 결과를 그대로 내보내야 하는 작업

작업 안에서 나누는 방법도 있습니다. 무엇을 어떻게 만들지 정하는 설계 단계는 성능이 좋은 유료 모델에 맡기고, 정해진 명세대로 코드를 채우는 단계는 값싼 모델이나 무료 한도로 돌리는 방식입니다. 판단이 필요한 단계와 받아쓰기만 하면 되는 단계를 나누면 같은 예산으로 더 많은 일을 끝냅니다.

로컬에서 직접 모델을 돌리는 선택지와 견주는 것도 방법입니다. 어떤 장비가 필요한지는 [DGX 스파크와 RTX 5090 비교](/insights/dgx-vs-rtx-local-ai-comparison)에 정리해 두었습니다.

## 무료 API 키를 여러 개 만들면 한도가 늘어나나요?

늘어나지 않습니다. Groq 공식 문서는 한도가 개별 사용자가 아니라 조직 단위로 적용된다고 밝히고 있어, 같은 계정에서 키를 여러 개 발급받아도 합쳐진 한도를 나눠 쓰게 됩니다. 계정 자체를 여러 개 만드는 방식은 여러 업체 약관이 금지하는 행위여서 정지로 이어질 수 있습니다. 한도를 늘리는 합법적인 방법은 결제 수단을 등록해 상위 등급으로 올라가는 쪽입니다. OpenRouter처럼 소액 구매 이력만으로 한도가 크게 올라가는 곳도 있습니다.

## 회사 업무에 무료 티어를 써도 되나요?

권하기 어렵습니다. 구글 약관은 민감한 정보와 기밀 정보, 개인 정보를 무료 서비스에 제출하지 말라고 명시하고 있고, 무료 티어에 넣은 내용은 제품 개선에 쓰이며 사람이 읽을 수도 있습니다. 회사 코드나 고객 자료가 여기에 들어가면 계약이나 내부 규정을 어기게 됩니다. 업무에 쓰려면 결제 계정을 연결해 데이터 취급 조건을 유료 기준으로 바꾸거나, 처음부터 유료 요금제를 쓰는 편이 맞습니다.

**3줄 요약:**
- 무료 LLM API 라우터는 여러 업체가 각자 주는 무료 사용 한도를 모아 OpenAI 호환 엔드포인트 하나로 묶어 주는 도구입니다.
- OpenRouter 무료 모델은 분당 20회에 하루 50회이고, 누적 10달러어치 크레딧을 산 적이 있으면 하루 1,000회로 올라갑니다.
- 제미나이 API 무료 서비스에 넣은 입력과 출력은 제품 개선에 쓰이고 사람이 읽을 수 있으며, 결제 계정을 연결하면 무료 할당량을 써도 유료와 같은 조건으로 바뀝니다.
