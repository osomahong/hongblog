Paseo는 클로드 코드와 코덱스 같은 코딩 에이전트를 데스크톱과 모바일에서 함께 다루는 자체 호스팅 도구입니다. 책상에서 시작한 작업을 폰에서 이어 보고, 터미널에서 같은 작업을 다시 부를 수 있습니다.

이름 때문에 검색이 잘 안 되는 도구이기도 합니다. 한글로 "파세오"를 넣으면 뉴질랜드에서 넘어온 화장지 브랜드가 먼저 나오고, 영문 "Paseo"는 블록체인 테스트넷 이름과 섞입니다. 도구 이름만으로는 원하는 문서에 닿기 어려워서, 공식 저장소와 문서에서 확인한 내용을 한자리에 정리했습니다. 2026년 8월 기준입니다.

![Paseo 데스크톱 앱 화면으로, 왼쪽에 실행 중인 에이전트 목록이 있고 오른쪽에 작업 내용과 코드 변경 사항이 표시된 모습](/images/insights/paseo-coding-agent-orchestrator/paseo-desktop.png)

## Paseo의 정체: 여러 코딩 에이전트를 한 곳에서 다루는 도구

공식 저장소는 Paseo를 "클로드 코드, 코덱스, 코파일럿, OpenCode, Pi 에이전트를 위한 하나의 인터페이스"로 설명합니다. 에이전트를 새로 만든 것이 아니라, 이미 쓰고 있는 에이전트들을 한 화면에 모아 놓는 도구입니다.

구조는 둘로 나뉩니다.

- **데몬**: 내 컴퓨터에서 도는 로컬 서버입니다. 코딩 에이전트 프로세스를 실제로 띄우고 관리합니다.
- **클라이언트**: 데몬에 붙는 창구입니다. iOS, 안드로이드, 데스크톱, 웹, CLI가 모두 같은 데몬을 바라봅니다.

이 구조 덕분에 작업은 내 컴퓨터에서 돌면서 조작은 어디서나 가능합니다. 클라우드 샌드박스에 코드를 올리지 않고, 평소 쓰던 개발 환경과 설정을 그대로 씁니다.

공식 문서가 내세우는 특징은 다섯 가지입니다.

- **자체 호스팅**: 에이전트가 내 컴퓨터에서 내 개발 환경 그대로 실행됩니다.
- **여러 제공자**: 클로드 코드, 코덱스, 코파일럿, OpenCode, Pi를 같은 화면에서 씁니다.
- **음성 제어**: 받아쓰기로 작업을 시키거나 음성 모드로 대화합니다.
- **여러 기기**: 책상에서 시작하고 폰에서 확인하고 터미널에서 스크립트로 부릅니다.
- **추적 없음**: 텔레메트리와 강제 로그인이 없습니다.

## 검색으로 정보를 찾기 어려운 이름

도구를 익힐 때는 이름으로 자료를 찾는 일이 잦은데, Paseo는 그 단계에서 시간을 더 씁니다.

한글 "파세오"는 화장지 브랜드가 검색 결과 앞자리를 차지합니다. 뉴질랜드에서 들어온 위생용품 브랜드로 국내에 유통되고 있어 쇼핑 결과가 두껍게 쌓여 있습니다. 영문 "Paseo"는 블록체인 테스트넷 이름과 스페인어 낱말로도 쓰여서, 개발 도구 문서가 위로 올라오기 어렵습니다.

그래서 자료를 찾을 때는 검색어를 좁히는 편이 빠릅니다.

- 저장소를 바로 보려면 `getpaseo/paseo`로 찾습니다.
- 문서는 `paseo.sh/docs`에 있습니다.
- 검색창에는 `paseo coding agent`나 `paseo claude code`처럼 용도를 붙입니다.

공식 저장소는 한국어 README도 함께 제공합니다.

## Orca와 겹치는 부분과 다른 부분

코딩 AI 여러 대를 한 화면에서 다루는 도구로는 [Orca를 먼저 정리한 적](/insights/orca-ide-easy-guide)이 있습니다. 두 도구는 출발점이 비슷합니다. 클로드 코드나 코덱스 같은 에이전트를 직접 만들지 않고, 이미 있는 것들을 묶어서 쓰게 해 줍니다. 쓰던 구독을 그대로 연결한다는 점도 같습니다.

달라지는 지점은 접근 방식입니다.

| 항목 | Paseo | Orca |
|---|---|---|
| 기본 형태 | 로컬 데몬에 여러 클라이언트가 접속 | 데스크톱 프로그램 |
| 조작 위치 | 데스크톱, 웹, iOS, 안드로이드, CLI | 데스크톱 |
| 원격 접속 | 종단간 암호화 릴레이 또는 VPN | 해당 없음 |
| 음성 입력 | 있음 | 해당 없음 |
| 공개 시점 | 저장소 2025년 10월 | 2026년 3월 |
| 라이선스 | AGPLv3 | 무료 공개 |

Orca를 정리할 때 대표 사용법으로 꼽았던 것은 같은 지시를 여러 AI에 한 번에 보내고 결과를 비교하는 쪽이었습니다. Paseo는 그보다 기기 사이를 오가는 쪽에 무게를 둡니다. 공식 문구도 "책상에서 시작하고 폰에서 확인한다"는 표현을 씁니다.

둘 중 하나를 골라야 하는 관계는 아닙니다. 데스크톱 앞에 계속 앉아 작업하면 굳이 데몬 구조가 필요 없고, 자리를 자주 비우거나 원격 장비에서 작업을 돌린다면 Paseo 쪽이 맞습니다.

![Paseo 모바일 앱 화면으로, 폰에서 실행 중인 에이전트의 작업 진행 상황과 대화 내용을 확인하는 모습](/images/insights/paseo-coding-agent-orchestrator/paseo-mobile.png)

## 설치 방법 세 가지

먼저 갖춰야 할 것이 하나 있습니다. Paseo는 에이전트를 대신 실행해 줄 뿐이므로, 클로드 코드나 코덱스 같은 에이전트 CLI를 미리 설치하고 로그인해 두어야 합니다.

**데스크톱 앱**이 공식 문서가 권하는 방법입니다. `paseo.sh/download`나 GitHub 릴리스에서 받아 실행하면 데몬이 자동으로 시작됩니다. 따로 설치할 것이 없습니다. 폰을 붙이려면 설정에서 호스트를 고르고 기기 연결을 실행합니다.

**CLI**는 서버나 원격 장비에 쓰기 좋습니다.

```bash
npm install -g @getpaseo/cli
paseo
```

실행하면 기기 연결용 종단간 암호화 릴레이를 켤지 묻습니다. 거절하면 TCP나 Tailscale 같은 VPN으로 직접 붙습니다.

**도커**로는 데몬과 웹 화면을 함께 띄웁니다.

```bash
docker run -d --name paseo \
  -p 6767:6767 \
  -e PASEO_PASSWORD=change-me \
  -v "$PWD/paseo-home:/home/paseo" \
  -v "$PWD:/workspace" \
  ghcr.io/getpaseo/paseo:latest
```

뜬 뒤에 `http://localhost:6767`을 엽니다. 기본 이미지에는 에이전트 CLI가 들어 있지 않으므로, 쓰는 CLI를 얹고 자격 정보를 환경변수나 볼륨으로 넣어야 합니다.

터미널에서 하는 일은 앱에서 하는 일과 같습니다.

```bash
paseo run --provider claude/opus-4.6 "사용자 인증 구현"
paseo run --provider codex/gpt-5.4 --worktree feature-x "기능 X 구현"

paseo ls                           # 실행 중인 에이전트 목록
paseo attach abc123                # 실시간 출력 보기
paseo send abc123 "테스트도 추가해줘" # 후속 지시

paseo --host workstation.local:6767 run "전체 테스트 실행"
```

`--worktree` 옵션은 git worktree를 따로 만들어 작업을 격리합니다. 여러 에이전트를 동시에 돌릴 때 서로 파일을 건드리지 않게 하는 장치입니다.

## 에이전트끼리 일을 넘기는 Skills 네 가지

Paseo는 에이전트가 Paseo를 써서 다른 에이전트를 부리도록 하는 스킬을 함께 배포합니다.

```bash
npx skills add getpaseo/paseo
```

넣고 나면 대화 중에 호출합니다.

- **`/paseo-handoff`**: 에이전트 사이에 일을 넘깁니다. 계획은 클로드로 세우고 구현은 코덱스로 넘기는 식입니다.
- **`/paseo-loop`**: 합격 기준을 정해 두고 에이전트를 반복해서 돌립니다. 검증용 에이전트를 따로 붙일 수 있습니다.
- **`/paseo-advisor`**: 다른 에이전트 하나를 조언자로 띄워 두 번째 의견만 받습니다. 일을 넘기지는 않습니다.
- **`/paseo-committee`**: 성향이 다른 에이전트 둘을 붙여 원인을 따지고 계획을 내게 합니다.

한 모델에 전부 맡기지 않고 역할을 나눠 쓰는 방식입니다. 계획과 구현을 다른 모델에 맡기거나, 판단이 나뉘는 문제에서 의견을 따로 받는 데 쓸 수 있습니다.

## 도입 전에 감안할 점

**아직 초기 단계입니다.** 2026년 8월 7일 기준 최신 릴리스는 7월 30일에 나온 v0.2.5이고, 저장소에 열린 이슈가 709개입니다. 별 12,489개와 포크 1,277개가 붙어 관심은 크지만, 버전 번호는 아직 자리를 잡는 중이라는 뜻입니다. 쓰던 도구를 걷어내고 옮겨 타기보다 병행하면서 살펴보는 편이 안전합니다.

**라이선스를 확인해 두는 편이 좋습니다.** 본체는 AGPLv3이고 서드파티 구성 요소는 각자의 원 라이선스를 따릅니다. 개인이 쓰는 데는 걸림이 없지만, 사내 서비스에 얹거나 수정해서 배포할 계획이라면 AGPL 조건을 먼저 살펴야 합니다.

**원격 접속은 선택 사항입니다.** 릴레이를 켜지 않으면 같은 네트워크나 VPN 안에서만 붙습니다. 도커로 띄울 때 `PASEO_PASSWORD`를 기본값 그대로 두지 않는 것도 함께 챙길 부분입니다.

## 자주 묻는 질문 (AEO)

> Q. Paseo를 쓰려면 클로드 코드 구독이 따로 더 필요한가요?
>
> A. 아닙니다. Paseo는 이미 설치된 에이전트 CLI를 실행할 뿐이라 쓰던 계정을 그대로 씁니다. 다만 에이전트 CLI 자체는 미리 설치하고 로그인해 두어야 합니다.

> Q. Paseo를 쓰면 코드가 외부로 나가나요?
>
> A. 에이전트는 내 컴퓨터의 데몬에서 실행되므로 작업 자체는 로컬에서 이뤄집니다. 공식 저장소는 텔레메트리와 추적, 강제 로그인이 없다고 밝히고 있습니다. 폰에서 붙을 때만 릴레이를 거치며 이 구간은 종단간 암호화된다고 설명합니다.

> Q. 폰에서 코드를 직접 수정할 수 있나요?
>
> A. 폰은 데몬에 붙는 창구이므로 작업 지시와 진행 확인, 변경 내용 검토를 폰에서 합니다. 실제 파일 변경은 데몬이 도는 컴퓨터에서 일어납니다.

> Q. Paseo를 쓰면 기존 편집기를 지워야 하나요?
>
> A. 아닙니다. Paseo는 편집기가 아니라 에이전트를 띄우고 관리하는 도구입니다. 쓰던 편집기는 그대로 두고 함께 씁니다.

**3줄 요약:**
- Paseo는 클로드 코드와 코덱스 같은 코딩 에이전트를 로컬 데몬으로 돌리고 데스크톱, 웹, 폰, 터미널에서 붙어 조작하는 자체 호스팅 도구입니다.
- Orca와 목적은 겹치지만 Paseo는 기기 사이를 오가는 데 무게를 두고, Orca는 데스크톱 한 대에서 여러 AI를 비교하는 쪽에 가깝습니다.
- 최신 릴리스가 v0.2.5이고 열린 이슈가 709개인 단계이므로, 쓰던 도구를 걷어내기보다 병행하며 살펴보는 편이 안전합니다.
