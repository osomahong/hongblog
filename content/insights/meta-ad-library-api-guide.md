메타 광고 라이브러리(Meta Ad Library)는 페이스북과 인스타그램을 비롯한 메타 서비스에서 지금 게재 중인 광고 전체와, 내려간 뒤에도 남는 정치, 사회 이슈 광고를 누구나 검색해 볼 수 있게 공개한 화면입니다. 광고 라이브러리 API는 이 자료를 프로그램으로 가져오는 통로입니다. 다만 가져올 수 있는 광고의 범위가 화면과 다릅니다.

경쟁사가 어떤 소재를 돌리는지 궁금할 때 광고 라이브러리를 열어 보는 방법은 이미 알려져 있습니다. 검색창에 브랜드 이름을 넣으면 그 브랜드가 집행 중인 광고가 소재와 문구까지 그대로 나옵니다.

덜 알려진 것은 API 쪽입니다. 화면에 보이는 광고를 그대로 내려받으려고 API 접근부터 신청하는 경우가 있는데, 신원 확인 절차에만 며칠이 걸리므로 받을 수 있는 범위를 먼저 확인해 두는 편이 낫습니다. 아래 내용은 메타 공식 문서와 광고 라이브러리 화면을 2026년 9월 15일에 확인한 기준입니다.

## 자사 광고 API와 광고 라이브러리 API의 차이

이름이 비슷해서 헷갈리기 쉬운 API가 둘 있습니다. 하나는 내가 집행한 광고의 성과를 받아 오는 마케팅 API이고, 다른 하나는 남의 광고를 조회하는 광고 라이브러리 API입니다. 목적도 권한도 서로 다릅니다.

| 항목 | 마케팅 API (Insights) | 광고 라이브러리 API |
|---|---|---|
| 보는 대상 | 내 광고 계정의 광고 | 누구나 볼 수 있게 공개된 남의 광고 |
| 쓰는 목적 | 자사 성과 측정과 리포트 자동화 | 경쟁사와 시장 조사, 광고 투명성 확인 |
| 엔드포인트 | `{광고계정ID}/insights` | `ads_archive` |
| 필요한 권한 | `ads_read` 이상, 광고 계정 연결 | 신원 확인을 마친 개인 계정과 앱 |
| 받는 항목 | 노출, 클릭, 비용, 전환 실수치 | 소재 문구, 게재 기간, 노출 플랫폼 |
| 한국 상업 광고 | 내 계정이면 받을 수 있음 | 받을 수 없음 |

자사 광고 데이터를 API로 가져오는 쪽은 [비개발자를 위한 Meta Ads API 가이드](/insights/meta-ads-api-data-for-non-developers)에서 필드 매핑과 토큰 발급까지 다뤘습니다. 이 글에서 다루는 것은 반대쪽, 그러니까 내 계정 바깥의 광고를 조사하는 도구입니다. 두 [API](/class/digital-basic/what-is-api)는 같은 Graph API 위에 있지만 필요한 권한과 조회 대상이 다르므로 코드를 하나로 묶어 쓰지 않습니다.

## 광고 라이브러리 화면에서 경쟁사 광고 찾는 순서

화면은 [facebook.com/ads/library](https://www.facebook.com/ads/library/)에서 열립니다. 페이스북 계정으로 로그인하지 않아도 검색하고 결과를 볼 수 있습니다. 순서는 네 단계입니다.

1. **국가를 고릅니다.** 기본값이 비어 있어서 국가를 정하지 않으면 검색이 시작되지 않습니다. 한국 시장을 볼 때는 대한민국으로 둡니다.
2. **광고 분류를 고릅니다.** 모든 광고와 이슈, 선거 또는 정치 가운데 하나를 선택합니다. 상업 광고를 조사할 때는 모든 광고를 고릅니다.
3. **키워드나 광고주 이름을 넣습니다.** 브랜드 이름을 넣으면 그 페이지가 집행하는 광고가 나오고, 일반 키워드를 넣으면 문구와 이미지, 동영상 음성, 클릭 유도 버튼에 그 말이 들어간 광고까지 걸립니다.
4. **필터로 좁힙니다.** 걸 수 있는 필터는 여섯 가지입니다.

- 언어
- 광고주
- 플랫폼
- 미디어 유형
- 활동 상태
- 날짜별 노출(시작 날짜와 종료 날짜)

![메타 광고 라이브러리 검색 결과 화면. 국가는 대한민국, 광고 분류는 모든 광고, 검색어는 영어회화로 두었고 위쪽에 필터와 정렬 기준 버튼, 활동 상태를 게재 중인 광고로 걸어 둔 표시가 있다. 광고 카드마다 활성 표시와 라이브러리 ID, 게재 시작일, 플랫폼 아이콘과 소재가 들어 있다](/images/insights/meta-ad-library-api-guide/01-ad-library-kr-search.png)

위 화면은 검색어 하나로 나온 결과입니다. 카드마다 라이브러리 ID와 게재 시작일이 적힙니다. 플랫폼 아이콘을 보면 페이스북과 인스타그램 가운데 어디에 나가는 광고인지 알 수 있습니다. 결과 수가 약 1,000개처럼 근삿값으로 표시되는 점도 화면의 특징입니다.

카드에서 눈여겨볼 문구가 둘 있습니다. **여러 버전이 있는 광고입니다**는 같은 광고에 소재나 문구가 여러 벌 걸려 있다는 뜻이고, **광고 4개에서 이 크리에이티브 및 문구를 사용합니다**는 같은 소재를 광고 여러 개에 복제해 돌리고 있다는 뜻입니다. 경쟁사가 소재를 몇 벌 만들어 돌리는지 세어 볼 때 이 두 문구가 단서가 됩니다.

## 광고 라이브러리 화면에 나오는 항목과 나오지 않는 항목

진열대에 놓인 물건은 누구나 볼 수 있어도 몇 개 팔렸는지 적힌 장부는 함께 놓여 있지 않듯, 광고 라이브러리도 소재와 문구는 그대로 보여주면서 성과 수치는 공개하지 않습니다. 다만 광고의 종류에 따라 표시되는 항목이 달라집니다.

| 항목 | 일반 상업 광고 | 정치, 사회 이슈 광고 | 영국, 유럽 연합 게재 광고 |
|---|---|---|---|
| 소재와 문구 | 나옴 | 나옴 | 나옴 |
| 페이지 이름과 게재 시작일 | 나옴 | 나옴 | 나옴 |
| 보관 기간 | 보관하지 않음 | 7년 | 마지막 노출 뒤 1년 |
| 지출 금액 | 나오지 않음 | 범위로 나옴 | 나오지 않음 |
| 노출 수 | 나오지 않음 | 범위로 나옴 | 나오지 않음 |
| 총 도달 | 나오지 않음 | 나오지 않음 | 나옴 |
| 연령, 성별 도달 비율 | 나오지 않음 | 나옴 | 나옴 |
| 예상 타겟 규모 | 나오지 않음 | 나옴 | 나오지 않음 |
| 광고비 지불 주체 | 나오지 않음 | 나옴 | 유럽 연합만 나옴 |

이 표는 대한민국과 영국, 유럽 연합 기준입니다. 브라질에 게재된 정치, 사회 이슈 광고는 2024년 8월 15일 이후 만든 것에 한해 총 도달과 광고 단위 타게팅 선택이 추가로 공개됩니다.

표만 보면 차이가 잘 드러나지 않으니 정치, 사회 이슈 광고 화면을 함께 놓겠습니다. 같은 광고 라이브러리인데 카드에 적히는 항목이 늘어납니다.

![메타 광고 라이브러리에서 국가를 미국, 광고 분류를 이슈, 선거 또는 정치로 두고 검색한 결과 화면. 광고 카드마다 예상 타겟 규모와 지출 금액, 노출 수가 범위로 표시되고 광고주 이름 아래에 지불 주체가 적혀 있다](/images/insights/meta-ad-library-api-guide/02-ad-library-political-detail.png)

카드에 예상 타겟 규모와 지출 금액, 노출 수가 범위로 적혀 있습니다. 광고주 이름 아래에는 광고비를 낸 주체가 따로 표시됩니다. 앞의 한국 상업 광고 화면에는 이런 항목이 하나도 없었습니다. 투명성 규제가 걸린 광고에만 숫자가 함께 나오고, 나머지는 소재까지만 공개하는 구조입니다.

보관 여부도 실무에서 중요합니다. 정치, 사회 이슈 광고는 내려간 뒤에도 7년 동안 남지만 **일반 상업 광고는 게재 중인 것만 보이고 종료되면 화면에서 사라집니다.** 경쟁사가 지난 분기에 무엇을 돌렸는지 나중에 확인할 방법이 없다는 뜻입니다.

## 한국 상업 광고도 API로 받을 수 있나요?

받을 수 없습니다. 광고 라이브러리 API가 반환하는 광고는 두 묶음으로 정해져 있습니다.

- **전 세계에 게재된 정치, 사회 이슈 광고 최근 7년치**
- **영국과 유럽 연합에 게재된 모든 종류의 광고 최근 1년치**

공식 문서는 필수 파라미터인 `ad_reached_countries` 설명에 조건을 한 줄로 적어 두었습니다. 유럽 연합 안의 어떤 지역에도 게재되지 않은 광고는 사회 문제, 선거 또는 정치 관련 광고일 때만 반환된다는 내용입니다. 대한민국에만 게재된 화장품 광고나 앱 설치 광고는 이 조건에 해당하지 않으므로 빈 응답이 돌아옵니다.

메타도 같은 안내를 하고 있습니다. 광고 라이브러리 API 페이지는 지금 게재 중인 광고 전체를 찾으려면 광고 라이브러리 화면을 쓰라고 적어 두었습니다. 진열대 뒤에 있는 장부를 묶어서 내주는 창구가 API입니다. 다만 그 창구에서 내주는 장부는 선거 광고와 유럽 광고뿐입니다.

그래서 국내 경쟁사 조사에서 API로 얻을 수 있는 것은 사실상 없습니다. 접근 신청부터 해 두고 화면 조사를 미루면 시간만 쓰게 됩니다. 반대로 유럽 시장에 나가는 브랜드를 조사하거나 정치 광고 지출을 다루는 업무라면 API가 맞는 도구입니다.

## API 접근 준비 3단계와 요청 형태

API를 쓸 일이 있다면 준비 과정은 세 단계입니다. 개발자 계정만 만들면 되는 다른 조회용 API보다 앞 단계가 깁니다.

1. **신원과 위치를 확인합니다.** facebook.com/ID에서 정치 광고를 집행할 때 거치는 확인 절차를 그대로 밟습니다. 제출한 정보를 메타가 확인하는 데 며칠이 걸립니다.
2. **Meta for Developers 계정을 만듭니다.** 계정을 만들 때 플랫폼 정책에 동의합니다.
3. **앱을 추가합니다.** 광고 라이브러리 API 페이지에서 Access the API를 누른 뒤 My Apps에서 앱을 만듭니다.

이 절차를 마치면 액세스 토큰으로 조회를 시작합니다. 요청은 Graph API의 `ads_archive` 엣지를 씁니다. 2026년 9월 15일 확인 기준 최신 버전은 v26.0입니다.

```
GET https://graph.facebook.com/v26.0/ads_archive
  ?ad_reached_countries=['DE']
  &ad_type=ALL
  &search_terms='fitness'
  &search_type=KEYWORD_UNORDERED
  &fields=id,page_name,ad_creative_bodies,ad_delivery_start_time,ad_snapshot_url
  &access_token=YOUR_TOKEN
```

파라미터 가운데 실무에서 자주 쓰는 것을 정리하면 이렇습니다.

| 파라미터 | 설명 |
|---|---|
| `ad_reached_countries` | 필수. ISO 국가 코드 또는 ALL |
| `ad_type` | ALL, POLITICAL_AND_ISSUE_ADS, HOUSING_ADS, EMPLOYMENT_ADS, FINANCIAL_PRODUCTS_AND_SERVICES_ADS |
| `search_terms` | 검색어. 100자 이내로, 광고에 쓰인 언어 그대로 넣습니다 |
| `search_type` | `KEYWORD_UNORDERED`는 낱말 단위, `KEYWORD_EXACT_PHRASE`는 구절 일치 |
| `search_page_ids` | 페이지 ID 최대 10개 |
| `ad_active_status` | ACTIVE, INACTIVE, ALL |
| `media_type` | ALL, IMAGE, MEME, VIDEO, NONE |
| `publisher_platforms` | FACEBOOK, INSTAGRAM, MESSENGER, THREADS, WHATSAPP 등 |

필드는 광고 종류와 게재 지역에 따라 값이 채워지는 범위가 다릅니다. 유효하지 않은 조합을 요청하면 값이 비는 것이 아니라 오류가 돌아옵니다. 요청할 필드를 광고 종류별로 미리 나눠 두는 편이 안전합니다.

| 구분 | 필드 |
|---|---|
| 모든 광고 공통 | `id`, `page_id`, `page_name`, `ad_creative_bodies`, `ad_creative_link_titles`, `ad_delivery_start_time`, `ad_delivery_stop_time`, `ad_snapshot_url`, `publisher_platforms`, `languages` |
| 정치, 사회 이슈 광고 전용 | `spend`, `impressions`, `currency`, `demographic_distribution`, `delivery_by_region`, `estimated_audience_size`, `bylines` |
| 유럽 연합 게재 광고 전용 | `eu_total_reach`, `beneficiary_payers` |
| 영국, 유럽 연합 게재 광고 전용 (브라질 정치 광고 포함) | `target_ages`, `target_gender`, `target_locations`, `age_country_gender_reach_breakdown` |

응답 한 페이지에는 최대 5,000건까지 담기고, 그다음은 응답 끝에 붙는 링크로 이어서 받습니다. 자주 만나는 오류 코드는 네 가지입니다.

- `613`: 호출 한도를 넘었습니다
- `190`: 액세스 토큰이 유효하지 않습니다
- `100`: 파라미터 값이 잘못되었습니다
- `1357045`: 보통 브라우저의 광고 차단 기능 때문에 나옵니다

## 경쟁사 광고를 조사할 때 실제로 쓰는 순서

도구의 범위를 알고 나면 조사 순서가 단순해집니다. 국내 경쟁사 소재를 볼 때는 화면만 씁니다.

- **경쟁사 페이지를 먼저 정합니다.** 키워드 검색은 결과 범위가 너무 넓으므로 광고주 이름으로 페이지를 찾은 뒤 그 페이지의 광고만 봅니다.
- **소재 형식을 필터로 나눕니다.** 미디어 유형을 이미지와 동영상으로 나눠 걸면 경쟁사가 어느 쪽에 비중을 두는지 보입니다.
- **게재 시작일을 기록합니다.** 오래 게재된 소재일수록 성과가 좋았을 가능성이 있습니다. 화면에 성과 수치가 없으므로 게재 기간을 대신 봅니다.
- **소재 버전 수를 셉니다.** 한 광고에 걸린 버전 수, 그리고 같은 소재를 쓰는 광고 개수를 적어 두면 상대의 제작 물량을 가늠할 수 있습니다.
- **검색 조건을 저장해 둡니다.** 화면 오른쪽의 검색 저장 기능으로 조건을 남겨 두면 같은 조건으로 다시 확인하기 쉽습니다.

마지막 항목을 빠뜨리면 조사가 한 번으로 끝납니다. 진열대는 지금 놓인 물건만 보여주므로 지난달에 무엇이 놓여 있었는지 알려면 그때그때 적어 두는 수밖에 없습니다. 상업 광고는 종료되면 화면에서 사라지기 때문에, 2주나 한 달 간격으로 같은 검색을 돌려 라이브러리 ID와 소재를 쌓아 두는 쪽이 낫습니다.

성과를 알 수 없다는 점은 그대로 남습니다. 어떤 소재의 전환이 좋았는지는 광고 라이브러리로 확인할 수 없습니다. 같은 화면으로 국내 이미지 광고 소재 261개를 모아 AI 생성 여부를 가려낸 [메타 광고 라이브러리 AI 생성 소재 비중](/insights/meta-ad-library-ai-creative-share) 조사에서도 이 제약은 그대로였습니다. 소재가 좋은지 나쁜지는 결국 자사 계정에서 직접 나눠 돌려 비교해야 정확합니다.

## 자주 묻는 질문

### 광고 라이브러리를 보려면 페이스북 계정이 필요한가요?

검색과 결과 확인만 하려면 필요하지 않습니다. 로그인하지 않은 상태에서도 국가와 광고 분류를 고르고 키워드로 검색해 광고 카드를 볼 수 있습니다. 다만 주류나 도박처럼 연령 제한이 걸린 소재는 로그인하지 않은 사람에게 보이지 않고, 검색 결과를 내려받으려면 로그인한 뒤 이용 약관에 동의해야 합니다.

### 경쟁사 광고의 지출과 노출도 볼 수 있나요?

상업 광고는 볼 수 없습니다. 지출 금액과 노출 수는 정치, 사회 이슈 광고에만 범위로 표시되고, 유럽 연합과 영국에 게재된 광고에는 총 도달이 표시됩니다. 대한민국에 게재된 일반 광고에는 이런 수치가 없으므로 게재 시작일과 소재 버전 수 같은 간접 단서로 집행 규모를 짐작합니다.

### 광고 라이브러리에서 찾은 자료를 보고서에 써도 되나요?

쓸 수 있습니다. 다만 근거가 둘로 나뉩니다. API로 받은 자료는 메타의 플랫폼 정책에 따라 연구자와 기자가 분석하고 발행할 수 있습니다. 화면에서 검색 결과나 소재를 내려받을 때는 로그인한 뒤 동의하는 이용 약관의 데이터 보관 조건이 적용되므로, 내려받기 전에 그 조건을 확인합니다.

## 3줄 요약

- 메타 광고 라이브러리는 메타 서비스에서 게재 중인 광고 전체와 내려간 정치, 사회 이슈 광고를 페이스북 계정 없이 검색할 수 있는 공개 화면입니다.
- 광고 라이브러리 API가 반환하는 광고는 전 세계 정치, 사회 이슈 광고 7년치와 영국, 유럽 연합에 게재된 광고 1년치뿐이라 한국 상업 광고는 받을 수 없습니다.
- 지출과 노출은 정치, 사회 이슈 광고에만 범위로 표시되므로, 상업 광고 조사에서는 게재 시작일과 소재 버전 수 정도가 단서입니다.
