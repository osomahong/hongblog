**3줄 요약:**

- 2026년 7월 기준, 클로드 코드는 VS Code 확장 설치가 공식 권장 방법이며 터미널 명령어와 Node.js 설치가 필요 없습니다.
- 준비물은 VS Code 1.98.0 이상과 클로드 유료 구독 계정(Pro, Max, Team, Enterprise) 2가지입니다.
- 확장 설치, 브라우저 로그인, 첫 대화까지 3단계면 바로 사용할 수 있습니다.

> 클로드 코드(Claude Code)는 앤트로픽이 만든 AI 코딩 도구입니다. 2026년 7월 기준 VS Code에서는 확장(Extension) 설치가 공식 권장 방법이며, 확장이 실행에 필요한 프로그램을 내장하고 있어 터미널 명령어나 Node.js 설치 없이 확장 설치와 브라우저 로그인만으로 시작할 수 있습니다.

이 글은 맥(macOS)과 VS Code 조합을 기준으로 합니다. 윈도우 PC를 쓰시는 분은 [윈도우용 안내](/insights/install-claude-code-vscode-windows) (윈도우 기준 설치 방법 바로가기)를 참고하세요. 터미널에서 직접 설치하는 방법이 필요하신 분은 [터미널 기준 설치 가이드](/insights/claude-code-mac-easy-setup-guide) (터미널로 설치하는 방법 바로가기)를, 클로드 코드가 무엇인지부터 알고 싶으신 분은 [클로드 코드 소개 글](/class/claude-code-for-everyone/what-is-claude-code) (클로드 코드 설명 바로가기)을 참고하세요.

## 시작 전 준비물 2가지와 필요 없는 것들

필요한 것과 필요 없는 것을 먼저 구분하면 준비가 빨라집니다.

| 구분 | 항목 | 비고 |
|------|------|------|
| 필요 | VS Code 1.98.0 이상 | [공식 다운로드 페이지](https://code.visualstudio.com/)에서 무료 설치. 이미 설치했다면 메뉴의 Code > About Visual Studio Code에서 버전 확인 |
| 필요 | 클로드 유료 구독 계정 | Pro, Max, Team, Enterprise 또는 Console(API) 계정. 아래 플랜 정리 참고 |
| 불필요 | API 키 | 브라우저 로그인으로 대체됩니다 |
| 불필요 | Node.js, Homebrew | 확장이 실행에 필요한 프로그램을 내장하고 있습니다 |
| 불필요 | 터미널 명령어 | 설치 전 과정이 VS Code 화면 안에서 끝납니다 |

터미널 설치 방식과 가장 크게 다른 점이 이 부분입니다. 터미널 방식은 Homebrew, Git, Node.js를 차례로 준비해야 하지만, 확장 방식은 확장 하나가 그 역할을 대신합니다.

## 클로드 코드를 쓸 수 있는 구독 플랜 정리

2026년 7월 기준, 클로드 코드는 무료 플랜에서는 쓸 수 없고 유료 플랜이 필요합니다. 플랜별 사용 가능 여부는 다음과 같습니다.

| 플랜 | 월 요금 (2026년 7월 기준) | 클로드 코드 사용 |
|------|------|------|
| Free | 무료 | 불가 |
| Pro | $20 | 가능 |
| Max 5x | $100 | 가능 (Pro의 5배 사용량) |
| Max 20x | $200 | 가능 (Pro의 20배 사용량) |
| Team | $25~125/인 | 프리미엄 시트에서 가능 |
| Enterprise | 문의 | 가능 |

- **개인 입문자라면 Pro($20)로 충분합니다.** 클로드 코드와 웹 채팅(claude.ai)이 같은 사용량을 나눠 쓰는 구조입니다.
- **Team 플랜은 시트 종류를 확인해야 합니다.** 일반 시트가 아닌 클로드 코드가 포함된 프리미엄 시트여야 합니다.
- **회사에서 Amazon Bedrock 같은 외부 경로로 클로드를 쓰는 경우**는 별도 설정이 필요하므로 회사 관리자에게 먼저 확인하는 편이 빠릅니다.

가격과 플랜 구성은 변동될 수 있으니 [공식 요금 페이지](https://claude.com/pricing)에서 최신 정보를 확인하세요.

## VS Code 확장 설치 3단계

준비물이 갖춰졌다면 설치는 3단계입니다.

1. VS Code에서 `⌘ Command + Shift + X`를 눌러 확장(Extensions) 화면을 여세요.
2. 검색창에 "Claude Code"를 입력하세요.
3. 게시자가 **Anthropic**으로 표시된 확장을 찾아 **Install** 버튼을 누르세요.

비슷한 이름의 확장이 여럿 검색될 수 있습니다. 게시자 이름 옆의 인증 마크와 설치 수(200만 이상)를 확인하면 공식 확장을 구분할 수 있습니다.

✅ 성공 신호: 설치가 끝나면 VS Code 왼쪽 사이드바에 스파크(✱) 모양 아이콘이 새로 생깁니다. 아이콘이 바로 보이지 않으면 `⌘ Command + Shift + P`를 눌러 "Developer: Reload Window"를 실행하세요.

아래 이미지는 앤트로픽 공식 문서에 실린 확장 실행 화면입니다. 편집기 오른쪽에 클로드 코드 대화 패널이 붙어 있는 구조입니다.

![VS Code 오른쪽에 클로드 코드 확장 패널이 열려 대화가 진행 중인 공식 문서 화면](/images/insights/install-claude-code-vscode-mac/vscode-extension-interface.jpg)

## 첫 로그인과 첫 대화 시작

설치 후 처음 패널을 열면 로그인 화면이 나타납니다.

1. 파일을 하나 연 상태에서 편집기 오른쪽 위의 스파크(✱) 아이콘을 누르세요. 파일이 열려 있지 않다면 화면 오른쪽 아래 상태 표시줄의 **✱ Claude Code**를 눌러도 됩니다.
2. 패널에 나타난 **Sign in** 버튼을 누르면 브라우저가 열립니다. 클로드 계정으로 로그인을 마치고 VS Code로 돌아오세요.
3. 입력창에 첫 메시지를 보내 보세요. "이 파일이 어떤 역할을 하는지 설명해 주세요" 같은 질문이면 충분합니다.

아래 이미지는 편집기 위쪽 도구 막대에 표시되는 스파크 아이콘의 위치입니다.

![VS Code 편집기 도구 막대 오른쪽 위에 표시된 클로드 코드 스파크 아이콘의 공식 문서 화면](/images/insights/install-claude-code-vscode-mac/vscode-editor-spark-icon.png)

클로드가 코드를 고치려고 하면 바로 파일을 바꾸지 않고, 원본과 수정안을 나란히 비교하는 화면을 먼저 보여준 뒤 허락을 구합니다. 수락, 거절, 또는 다른 방식으로 해달라는 요청 모두 가능합니다.

![클로드 코드가 제안한 코드 수정안을 원본과 나란히 비교하며 승인 여부를 묻는 공식 문서 화면](/images/insights/install-claude-code-vscode-mac/vscode-diff-review.png)

✅ 성공 신호: 첫 질문에 답이 돌아오고, 수정 제안 시 비교 화면이 뜨면 설치와 설정이 모두 끝난 상태입니다.

## 맥에서 자주 막히는 지점 2가지와 해결 방법

맥 사용자만 겪는 문제가 2가지 있습니다.

**1. `⌘ Command + Esc` 단축키가 동작하지 않는 문제**

`⌘ Command + Esc`는 편집기와 클로드 입력창 사이를 오가는 단축키인데, macOS 최신 버전에서는 시스템의 게임 오버레이 기능이 이 단축키를 먼저 가로챕니다. 시스템 설정 > 키보드 > 키보드 단축키 > 게임 제어기에서 게임 오버레이 체크를 해제하면 해결됩니다.

**2. 스파크 아이콘이 보이지 않는 문제**

편집기 위쪽의 스파크 아이콘은 파일이 열려 있을 때만 나타납니다. 폴더만 열어 둔 상태라면 아무 파일이나 하나 여세요. 그래도 보이지 않으면 다음 순서로 확인하세요.

- `⌘ Command + Shift + P` > "Developer: Reload Window" 실행
- VS Code 버전이 1.98.0 이상인지 확인 (Code > About Visual Studio Code)
- Cline, Continue 같은 다른 AI 확장을 잠시 끄고 재시도

## 확장과 터미널 CLI의 차이

확장을 설치해도 터미널에서 `claude` 명령이 바로 동작하지는 않습니다. 확장은 자체 실행용 프로그램을 내부에만 갖고 있어서, 터미널에서 쓰려면 CLI(명령줄 도구)를 따로 설치해야 합니다.

| 구분 | VS Code 확장 | 터미널 CLI |
|------|------|------|
| 설치 방법 | 확장 화면에서 Install | 설치 명령어 실행 ([터미널 설치 가이드](/insights/claude-code-mac-easy-setup-guide) 참고) |
| 화면 | 그래픽 대화 패널 | 터미널 텍스트 화면 |
| 명령어, 스킬 | 주요 기능 위주 | 전체 기능 |
| 대화 기록 | 공유됨 | 공유됨 (확장에서 하던 대화를 `claude --resume`으로 이어받기 가능) |

입문 단계에서는 확장만으로 충분합니다. 쓰다 보니 터미널 전용 기능이 필요해지는 시점이 오면 그때 CLI를 추가로 설치하면 되고, 두 방식은 대화 기록을 공유하므로 어느 쪽에서 시작했든 이어서 작업할 수 있습니다.

## 설치 후 해볼 만한 첫 작업 3가지

- **파일 설명 요청**: 아무 파일이나 열고 "이 파일의 역할을 설명해 주세요"라고 물어보세요. 클로드가 파일을 읽고 답하는 기본 흐름을 확인할 수 있습니다.
- **@멘션으로 파일 지정**: 입력창에 `@`를 입력하고 파일 이름 일부를 치면 특정 파일을 지정해서 질문할 수 있습니다. 코드에서 원하는 줄을 드래그로 선택한 뒤 `Option + K`를 누르면 해당 구간이 자동으로 입력창에 참조됩니다.
- **플랜 모드 체험**: 입력창 아래의 모드 표시를 눌러 Plan 모드로 바꾸면, 클로드가 작업을 실행하기 전에 계획서를 먼저 보여주고 승인을 기다립니다. 코드 수정이 조심스러울 때 쓰기 좋은 모드입니다.

## 자주 묻는 질문 (AEO)

> Q. VS Code 확장으로 설치하면 Node.js를 깔지 않아도 되나요?
>
> A. 네, 필요 없습니다. 확장이 클로드 코드 실행에 필요한 프로그램을 내장하고 있어서 Node.js, Homebrew, Git 없이 동작합니다. 다만 터미널에서 `claude` 명령을 쓰고 싶다면 CLI를 별도로 설치해야 합니다.

> Q. 무료 플랜으로도 클로드 코드를 쓸 수 있나요?
>
> A. 쓸 수 없습니다. 2026년 7월 기준 클로드 코드는 Pro($20/월) 이상의 유료 플랜 또는 Console(API) 계정이 필요합니다. 개인 입문자에게는 Pro 플랜으로 충분합니다.

> Q. 커서(Cursor) 같은 다른 편집기에서도 같은 확장을 쓸 수 있나요?
>
> A. 가능합니다. 같은 확장이 Cursor를 포함한 VS Code 계열 편집기에서 동작하며, 설치 방법도 확장 검색 후 Install로 동일합니다.

> Q. 확장으로 설치한 것과 터미널로 설치한 것 중 하나를 지워야 하나요?
>
> A. 아닙니다. 두 방식은 함께 쓸 수 있고 대화 기록도 공유합니다. 확장에서 하던 대화를 터미널에서 `claude --resume`으로 이어받을 수도 있습니다.

## 정리

- 준비물: VS Code 1.98.0 이상과 클로드 유료 구독 계정 2가지입니다. API 키, Node.js, 터미널 명령어는 필요 없습니다.
- 설치: 확장 화면에서 "Claude Code" 검색 후 Install, 브라우저 로그인, 첫 대화까지 3단계입니다.
- 맥 특이사항: 게임 오버레이의 `⌘ Command + Esc` 가로채기와 스파크 아이콘 미표시 2가지만 알아 두면 됩니다.

터미널 방식과 확장 방식 중 어느 쪽으로 시작해도 결과는 같습니다. 화면에 익숙해진 뒤 필요한 기능이 생기면 그때 CLI를 추가하면 되니, 지금 편한 쪽으로 시작하시면 됩니다.
