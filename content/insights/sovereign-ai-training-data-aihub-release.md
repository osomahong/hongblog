독파모 학습데이터 개방은 과학기술정보통신부와 한국지능정보사회진흥원이 2026년 8월 27일 독자 AI 파운데이션 모델 정예팀 다섯 곳의 학습용 데이터 29종을 AI허브에 무료로 푼 조치입니다. 독파모는 독자 AI 파운데이션 모델의 줄임말입니다.

독파모 프로젝트가 국가대표 AI 모델을 만들 팀을 단계 평가로 추려 지원하는 사업이라는 것은 비교적 알려져 있습니다. 평가 때마다 어느 팀이 남고 어느 팀이 떨어졌는지가 기사로 나오기 때문입니다.

덜 알려진 쪽은 그 과정에서 만들어진 학습 데이터입니다. 정예팀들이 모델을 만들려고 구축한 자료가 심사를 거쳐 일반에 풀렸습니다. 서가에 꽂혀 있어도 목록을 펴 보지 않으면 찾지 못하듯, 무료로 열려 있어도 어디에 무엇이 있는지 모르면 쓸 수 없습니다. 정부 보도자료와 AI허브 실제 화면을 근거로 2026년 9월 7일 기준으로 정리하겠습니다.

## 과기정통부가 발표한 개방 규모

발표된 규모는 표와 같습니다.

| 항목 | 내용 |
|---|---|
| 발표일 | 2026년 8월 27일 |
| 주관 | 과학기술정보통신부, 한국지능정보사회진흥원 |
| 개방 데이터 | 29종 |
| 건수 | 약 3,544만 건 |
| 토큰 환산 | 약 1조 5,600억 토큰 |
| 학습 가능 규모 | 700억에서 800억 파라미터급 모델 |
| 참여 팀 | 네이버클라우드, 업스테이지, SK텔레콤, NC AI, LG AI연구원 |
| 이용 조건 | 내국인 무료, AI허브 회원 가입 후 다운로드 |
| 위치 | AI허브 안의 독자 AI모델 데이터 |

토큰이라는 단위가 낯설다면 분량을 가늠하기 어렵습니다. 쉽게 말하면 **토큰은 모델이 글을 잘라 읽는 최소 조각**이고, 한국어에서는 짧은 단어 하나가 대략 한두 개에 해당합니다. 1조 5,600억 토큰은 정부가 밝힌 대로 700억에서 800억 파라미터 크기의 모델을 처음부터 학습시키기에 충분한 분량입니다.

공개는 팀들의 선의만으로 이뤄진 것이 아닙니다. 사업 참여 조건에 데이터 구축과 가공 예산으로 확보한 자료 가운데 50% 이상을 공개해야 한다는 항목이 있습니다. 다섯 팀 가운데 넷은 품질 검증을 마친 자료를 전부 냈고, LG AI연구원은 표본을 뽑는 방식으로 기준선을 채웠습니다.

## AI허브에 실제로 올라온 데이터 18종

![AI허브 독자 AI모델 데이터 목록 화면. 상단에 LG AI연구원, 업스테이지, SK텔레콤, 네이버클라우드, NC AI 다섯 팀의 로고가 필터로 놓여 있고, 아래에 데이터 카드마다 다운로드 또는 신청하기 버튼과 용량, 조회수, 다운로드 수가 표시돼 있다](/images/insights/sovereign-ai-training-data-aihub-release/aihub-dataset-list.png)

위 화면은 AI허브의 독자 AI모델 데이터 목록입니다. 발표는 29종이었지만 2026년 9월 7일 기준으로 목록에 올라온 것은 18종입니다. 데이터셋 일련번호가 중간중간 비어 있어 순차적으로 올리는 중으로 보입니다.

분야는 한국어와 영상, 이미지, 멀티모달 둘로 나뉘고 화면 위쪽에 팀별로 걸러 보는 기능이 있습니다. 현재 올라와 있는 것을 성격별로 묶으면 이렇습니다.

- **사전학습용**: 사전 학습 데이터(1.61TB), 다국어 사전학습 데이터(8.63GB)
- **사후학습용**: AI 파운데이션 모델 사후학습용 데이터, 고품질 멀티턴 데이터 집합, 사용자 선호 반영 데이터
- **추론과 에이전트**: 생각과정 씨앗 학습 데이터, 에이전트 행위 능력 데이터, 지식/지능 데이터
- **멀티모달**: 의료 AI 학습 데이터(26GB), 홈 휴머노이드 로봇용 Scene Understanding 데이터셋(38.42GB), 대화 생성형 AI 학습용 데이터
- **평가와 안전성**: 벤치마크 데이터, AI Safety Alignment 데이터, 레드티밍 데이터

용량 차이가 큽니다. 사전 학습 데이터 하나가 1.61TB인 반면 벤치마크 데이터는 2.01MB입니다. 관심이 어디로 쏠렸는지도 숫자로 남아 있는데, 1.61TB짜리 사전 학습 데이터의 다운로드 수가 145회로 가장 많았습니다.

## 정예팀 다섯 곳이 낸 데이터

다섯 팀이 각자의 모델 개발 방향에 맞춰 다른 성격의 자료를 냈습니다.

| 팀 | 낸 데이터 |
|---|---|
| 네이버클라우드 | 영상과 음성 자료. 공개 영상과 방송 영상, 텍스트 클립, 음성 질의응답 |
| 업스테이지 | 사전학습 데이터 1조 토큰과 에이전트 개발용 사후학습 데이터 50만 건 |
| SK텔레콤 | 수학, 과학, 법률 같은 전문 영역 추론 데이터와 한국형 레드티밍 데이터 약 1만 건 |
| NC AI | 실제 제조 현장 문서와 고객 응대 녹취에서 뽑은 언어모델 핵심 능력 데이터 7종 |
| LG AI연구원 | 한국 가정 50곳에서 찍은 영상 17만 클립 이상, 여러 겹으로 라벨을 단 물리 AI 데이터 |

표에 나온 레드티밍(red teaming)은 일반적인 성능 평가보다 상대적으로 낯섭니다. 쉽게 말하면 **모델을 일부러 공격해 위험한 답을 내놓는지 미리 확인하는 점검 방식**이고, 그 점검에 쓰는 질문을 모아 둔 것이 레드티밍 데이터입니다.

눈여겨볼 것은 이 자료들이 한국 상황에 맞춰 만들어졌다는 점입니다. SK텔레콤이 낸 레드티밍 데이터는 국내 법령과 사회 통념을 반영해 만들었고, LG AI연구원의 영상은 한국 가정 안에서 찍었습니다. 해외 공개 데이터로는 채우기 어려운 부분입니다.

## 안전성 데이터는 왜 내려받을 수 없을까요?

목록을 보면 버튼이 두 가지입니다. 대부분은 다운로드지만 두 건에는 신청하기가 붙어 있습니다. AI Safety Alignment 데이터와 AI 파운데이션 모델 레드티밍 데이터입니다.

이 두 건은 안심존 자료입니다. 안심존이라는 이름은 일반 다운로드보다 상대적으로 낯섭니다. 쉽게 말하면 **데이터를 바깥으로 내보내지 않고 제공 기관의 서버 안에서만 열어 보게 하는 환경**입니다. 도서관에서 귀중본은 관외 대출을 막고 열람실 안에서만 보게 하듯, 자료는 서버에 두고 이용자가 그 안으로 들어가 작업합니다.

두 방식의 차이는 이렇습니다.

| 구분 | 일반 데이터 | 안심존 데이터 |
|---|---|---|
| 버튼 | 다운로드 | 신청하기 |
| 받는 방법 | 로그인 후 바로 내려받기 | 신청서와 활용 계획 제출, 심사 통과 후 접속 |
| 자료의 위치 | 내 컴퓨터 | 제공 기관 서버 |
| 가지고 나올 수 있는 것 | 데이터 전체 | 분석 결과물 |
| 해당 데이터 | 나머지 16종 | AI Safety Alignment, 레드티밍 데이터 |

내려받지 못하게 막은 이유는 자료의 성격에 있습니다. 레드티밍 데이터는 모델이 위험한 답을 내놓게 유도하는 질문을 모아 둔 것입니다. 모델을 안전하게 만들려고 쓰는 자료지만, 그대로 퍼지면 반대로 쓰일 위험이 따릅니다.

두 건의 용량은 각각 51.92KB와 187.51KB로 작지만 관심은 적지 않습니다. 레드티밍 데이터는 조회수 791회로 목록에서 두 번째로 높았고, 실제 신청 건수는 4회에 그쳤습니다. 궁금해서 열어 본 사람은 많아도 심사를 거쳐 쓰는 데까지 간 사람은 적다는 뜻이고, 안전성 연구의 문턱이 그만큼 높다는 이야기이기도 합니다.

## 데이터를 내려받기 전에 확인할 조건

![AI허브 사전 학습 데이터 상세 화면. 구축년도 2025, 갱신년월 2026-08, 다운로드 145, 용량 1.61TB가 표시돼 있고 그 아래 내국인만 데이터 신청이 가능하다는 붉은 안내와 다운로드, 샘플 데이터 버튼이 놓여 있다](/images/insights/sovereign-ai-training-data-aihub-release/aihub-pretraining-detail.png)

위 화면은 가장 큰 사전 학습 데이터의 상세 페이지입니다. 여기에 실무에서 확인할 조건이 몇 가지 적혀 있습니다.

- **내국인만 신청 가능합니다.** 상세 페이지 위쪽에 붉은 글씨로 적혀 있는 안내입니다. 해외 법인이나 외국 국적 연구자와 함께 쓸 계획이라면 조건을 먼저 확인해야 합니다.
- **다운로드는 PC에서만 됩니다.** 목록 화면에 안내가 붙어 있고 모바일에서는 받을 수 없습니다.
- **먼저 샘플로 확인합니다.** 상세 페이지에 샘플 데이터 버튼이 따로 있습니다. 1.61TB를 통째로 내려받기 전에 구조와 형식이 쓰려는 용도에 맞는지 보는 편이 낫습니다.
- **구축 시점을 함께 봅니다.** 사전 학습 데이터는 구축년도가 2025년이고 갱신은 2026년 8월입니다. 최신 정보가 필요한 용도라면 시점 차이를 감안해야 합니다.

이 데이터가 나온 배경과 정예팀 구성이 궁금하다면 [독파모 2차 평가 결과](/insights/sovereign-ai-foundation-model-2nd-evaluation)에 평가 과정과 팀별 상황을 정리해 두었습니다.

## 개인이 이 데이터로 모델을 만들 수 있나요?

분량만 놓고 보면 가능하지만 계산 자원이 다른 문제입니다. 700억에서 800억 파라미터급 모델을 처음부터 학습시키려면 개인이 감당하기 어려운 규모의 GPU가 필요합니다. 현실적인 쓰임새는 따로 있습니다. 이미 공개된 모델에 이 데이터로 사후학습을 얹어 한국어 성능이나 특정 분야 능력을 올리는 방식입니다. 사후학습용 데이터와 사용자 선호 반영 데이터, 에이전트 행위 능력 데이터가 그 목적에 맞게 나뉘어 올라와 있습니다.

## 상업적으로 이용해도 되나요?

AI허브는 회원 가입 후 무료로 내려받아 쓰도록 열려 있지만, 데이터마다 이용 조건이 따로 붙습니다. 상세 페이지의 데이터 개요와 이용정책을 확인한 뒤 쓰려는 범위가 허용되는지 보는 편이 안전합니다. 안심존으로 제공되는 두 건은 애초에 반출이 막혀 있어 분석 결과물만 가지고 나오는 방식입니다.

**3줄 요약:**
- 독파모 학습데이터 개방은 과기정통부와 한국지능정보사회진흥원이 2026년 8월 27일 정예팀 다섯 곳의 학습용 데이터 29종을 AI허브에 무료로 푼 조치입니다.
- 분량은 약 3,544만 건에 약 1조 5,600억 토큰이고 700억에서 800억 파라미터급 모델을 학습시킬 수 있는 규모입니다.
- 안전성 정렬과 레드티밍 데이터는 내려받을 수 없고 심사를 거쳐 안심존 안에서만 볼 수 있습니다.
