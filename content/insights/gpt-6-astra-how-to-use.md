GPT-6 아스트라는 OpenAI가 2026년 9월 3일 공개한 모델이고, 컴퓨터를 사람처럼 직접 조작하는 작업에 초점을 두고 있습니다. 양식을 채우고 고객 기록을 고치고 화면에 뜬 문제를 살펴보는 일까지 맡길 수 있게 만들어졌습니다.

새 모델이 나왔다는 소식은 대체로 빨리 퍼집니다. 그런데 정작 써 보려고 모델 목록을 열면 아스트라가 없는 경우가 있습니다. 구독료를 내고 있는데도 그렇습니다.

이럴 때 결제나 계정을 의심하게 되는데, 대부분은 그쪽 문제가 아닙니다. **같은 구독이라도 어느 화면을 열었느냐에 따라 아스트라가 있기도 하고 없기도 합니다.** 사원증 하나로 건물에 들어가도 층마다 열리는 문이 다르듯, 요금제마다 아스트라가 열리는 화면이 정해져 있습니다. 어디에서 열리는지, 열리지 않을 때 무엇을 확인하는지를 공식 문서를 근거로 2026년 9월 14일 기준으로 정리하겠습니다.

![OpenAI 도움말 문서 상단의 안내 박스. GPT-6 Astra로 구동되는 GPT-6 Pro는 Pro $100, Pro $200, 비즈니스, 엔터프라이즈 요금제에서 이용할 수 있고, Plus 요금제에는 ChatGPT Work와 Codex의 GPT-6 Astra가 포함되며, Astra를 쓰려면 Codex CLI 버전이 0.153.0 이상이어야 한다고 적혀 있다](/images/insights/gpt-6-astra-how-to-use/plan-access-callout.png)

## 요금제보다 화면을 먼저 확인합니다

아스트라를 쓸 수 있는 곳은 네 군데입니다. ChatGPT의 일반 Chat, ChatGPT Work, Codex, 그리고 OpenAI API입니다. 앞의 셋은 같은 구독 안에 들어 있는데도 열리는 조건이 서로 다릅니다.

가장 자주 어긋나는 쪽은 Plus입니다. Plus 요금제의 아스트라는 ChatGPT Work와 Codex에 있습니다. 일반 Chat에서 아스트라를 쓰는 옵션에는 GPT-6 Pro라는 이름이 붙어 있고, 이쪽은 Pro $100, Pro $200, Business, Enterprise 요금제에서 열립니다.

정리하면 이렇습니다.

| 요금제 | 일반 Chat | ChatGPT Work | Codex |
|---|---|---|---|
| Free, Go | 없음 | 없음 | 없음 |
| Plus | GPT-6 Pro 없음 | 아스트라 포함 | 아스트라 포함 |
| Pro $100, Pro $200 | GPT-6 Pro | 아스트라 포함 | 아스트라 포함 |
| Business | GPT-6 Pro | 아스트라 포함 | 아스트라 포함 |
| Enterprise | GPT-6 Pro (워크스페이스 권한에 따름) | 아스트라 포함 | 아스트라 포함 |

Plus를 쓰면서 일반 Chat의 모델 목록만 열어 보고 아스트라가 없다고 판단하는 경우가 여기서 나옵니다. 문이 잠긴 것이 아니라 찾는 층이 달랐던 것처럼, 여기서도 권한이 아니라 화면이 문제입니다.

이름 때문에 헷갈리는 것이 하나 더 있습니다. **GPT-6 Pro는 모델 옵션의 이름이고 ChatGPT Pro는 구독 요금제의 이름입니다.** 도움말을 찾을 때 Plus와 Work처럼 요금제와 화면을 함께 적어 두면 다른 조건의 안내와 섞이지 않습니다.

## 모델 목록에 아스트라가 없을 때 확인하는 순서

순서대로 보면 되는데, 앞 단계에서 걸리면 뒤는 볼 필요가 없습니다.

1. **지금 연 화면을 확인합니다.** 일반 Chat인지 Work인지 Codex인지 봅니다. Plus라면 Work와 Codex를 엽니다.
2. **로그인한 계정을 확인합니다.** 개인 요금제를 결제해 두고 회사 워크스페이스 화면을 보고 있거나 그 반대인 경우가 있습니다. 워크스페이스마다 쓸 수 있는 모델이 다릅니다.
3. **앱을 최신 버전으로 올립니다.** 데스크톱 앱은 메뉴에서 업데이트 확인을 직접 눌러야 합니다. 자동 업데이트 알림이나 사이드바 아이콘으로 이미 업데이트했더라도 한 번 더 확인합니다. Codex CLI는 0.153.0 이상이 필요합니다.
4. **순차 제공 상태를 감안합니다.** 아스트라는 일부 조직에 먼저 열린 뒤 며칠에 걸쳐 Plus, Pro, Business, Enterprise로 넓혀졌습니다. 요금제에 포함된다는 말이 지금 내 화면에 떠 있다는 뜻은 아닙니다.
5. **사용량이 남았는지 봅니다.** 모델은 보이는데 선택이 되지 않으면 한도에 걸린 경우입니다. 이어서 다루겠습니다.

확인 과정에서 쓰지 말아야 할 방법도 하나 있습니다. **모델에게 "너는 어떤 모델이니"라고 물어서 판단하지 않습니다.** 언어 모델은 자기 이름을 잘못 답하기도 합니다. 모델 선택기에 표시되는 이름을 기준으로 삼습니다.

## 회사 계정에서 아스트라가 보이지 않는 이유

Enterprise와 Edu 워크스페이스는 조건이 하나 더 붙습니다. 건물에 들어왔더라도 층마다 출입을 따로 허용해야 하듯, 워크스페이스 소유자가 아스트라를 따로 열어 줘야 합니다.

![OpenAI 도움말의 Enterprise 및 Edu 모델 안내. 대상 워크스페이스에서 GPT-6 Astra는 출시 시 기본적으로 비활성화되어 있고, 워크스페이스 소유자가 모델 액세스 제어로 활성화해야 하며, 기존 얼리 모델 액세스 설정은 Astra에 적용되지 않고, 출시 2주 후에도 액세스가 자동으로 활성화되지 않는다고 적혀 있다](/images/insights/gpt-6-astra-how-to-use/enterprise-default-off.png)

확인해 둘 것은 네 가지입니다.

- **출시 시점에 아스트라는 꺼진 상태가 기본값입니다.** 워크스페이스 소유자가 워크스페이스 설정의 모델 액세스 제어에서 전체 또는 특정 역할에 켜야 합니다.
- **기존 얼리 모델 액세스 설정은 아스트라에 적용되지 않습니다.** 새 모델을 미리 받도록 설정해 두었더라도 아스트라 권한이 자동으로 붙지 않습니다.
- **역할이 여러 개면 전부 확인합니다.** 한 역할에서 접근을 허용하면 다른 역할에서 꺼도 계속 열려 있을 수 있습니다.
- **기다려도 자동으로 열리지 않습니다.** 출시 시점에 2주 관리자 미리 보기 절차가 없고, 2주가 지나도 자동으로 켜지지 않습니다.

관리자에게 요청할 때는 워크스페이스 설정의 모델 액세스 제어에서 아스트라를 켜 달라고 정확히 말하는 편이 빠릅니다. 시작 모델이나 기본 모델을 아스트라로 바꾸는 것으로는 권한이 생기지 않습니다.

## Chat에서 쓸 때의 사용량 한도

Pro 요금제를 결제했다고 아스트라를 무제한으로 쓰는 것은 아닙니다. 일반 Chat의 GPT-6 Pro에는 요금제마다 허용량이 정해져 있습니다.

![OpenAI 도움말의 GPT-6 Pro 사용량 한도 표. Pro $200은 주당 200개, Pro $100은 주당 50개, Business Standard는 월 15개, Business Premium은 주당 50개로 적혀 있고 각각 GPT-5.6 Sol Pro와 허용량을 나누는 방식이 함께 표시돼 있다](/images/insights/gpt-6-astra-how-to-use/gpt-6-pro-limits.png)

| 요금제 | Chat의 GPT-6 Pro 허용량 |
|---|---|
| Pro $200 | 주당 200개 |
| Pro $100 | 주당 50개 |
| Business Standard | 월 15개 |
| Business Premium | 주당 50개 |

Pro $100과 Business 요금제는 GPT-5.6 Sol Pro와 이 허용량을 함께 씁니다. 두 모델을 오가며 써도 총량이 늘어나지 않습니다. Pro $200에서는 주간 한도에 닿으면 GPT-5.6 Thinking의 중간 수준으로 자동 전환됩니다.

Work와 Codex의 사용량은 Chat과 따로 집계됩니다. 이쪽은 메시지 개수가 아니라 작업 크기와 추론 수준에 따라 소모량이 달라집니다. Business 스탠더드 시트를 기준으로 5시간 동안 아스트라는 5개에서 45개 사이, GPT-5.6 Luna는 250개에서 2,000개 사이로 추정치가 나와 있습니다. 긴 작업 하나에 짧은 작업 여러 개보다 많은 사용량이 잡힙니다.

크레딧을 사도 순차 제공 중에 아스트라를 먼저 받지는 못합니다. 크레딧은 허용량을 다 쓴 뒤 더 쓰기 위한 것이고, 권한을 앞당기는 수단이 아닙니다.

## API로 쓸 때의 요금 계산

API는 구독과 별개입니다. ChatGPT 구독료를 내고 있어도 API 크레딧이 생기지 않고, API에서 아스트라가 호출된다고 해서 ChatGPT 모델 목록에 뜨는 것도 아닙니다.

표준 요금은 이렇습니다.

| 구분 | 100만 토큰당 |
|---|---|
| 입력 | 10달러 |
| 캐시된 입력 | 1달러 |
| 출력 | 50달러 |

요금을 계산할 때 먼저 볼 것은 **출력 단가가 입력의 다섯 배**라는 점입니다. 토큰 수는 입력이 훨씬 많은데 청구액은 출력 쪽이 더 나오는 일이 생깁니다.

자료를 붙여 보고서 초안을 뽑는 작업으로 계산해 보겠습니다. 한 건에 입력 5만 토큰, 출력 8천 토큰이 든다고 보면 이렇게 나옵니다.

| 항목 | 토큰 | 요금 |
|---|---|---|
| 입력 | 50,000 | 0.5달러 |
| 출력 | 8,000 | 0.4달러 |
| 합계 | 58,000 | 0.9달러 |

입력 토큰이 여섯 배 넘게 많은데도 비용은 비슷한 수준입니다. 같은 작업을 100건 처리하면 90달러가 되는데, 비용을 줄이려면 입력을 줄이는 쪽보다 출력을 짧게 만드는 쪽이 효과가 큽니다.

같은 자료를 반복해서 넣는 작업이라면 캐시를 쓰는 쪽이 비용을 더 크게 줄입니다. 캐시된 입력은 100만 토큰당 1달러여서 입력 단가의 10분의 1입니다. 위 예시에서 자료 부분이 캐시에 걸리면 입력 요금이 0.5달러에서 0.05달러로 내려갑니다.

배율이 붙는 조건도 있습니다.

- **긴 컨텍스트**: 입력 272K 토큰을 넘으면 입력은 2배, 출력은 1.5배가 됩니다. 다만 Codex에서 아스트라를 쓸 때는 이 배율이 붙지 않습니다.
- **패스트 모드**: API에서 표준의 2배 속도에 2배 요금입니다. Work와 Codex에서는 2.5배입니다.
- **무료 API 계정**: 아스트라는 무료 티어를 지원하지 않습니다. 결제가 설정된 프로젝트에서 호출해야 합니다.

도구를 붙여 쓸 계획이라면 Responses API를 씁니다. 모델 페이지에 Chat Completions도 함께 적혀 있지만, 도구 호출에는 Responses가 필요합니다. 가격과 벤치마크를 다른 모델과 나란히 보려면 [GPT-6 아스트라 출시 정리](/insights/openai-astra-model-comparison)에서 클로드, 제미나이와 견준 표를 볼 수 있습니다.

## 아스트라로 먼저 시험해 볼 작업

아스트라의 강점은 답변 품질보다 화면을 다루는 쪽에서 드러납니다. 예로 나온 작업은 온라인 양식 작성, 고객 기록 갱신, 일정 정리, 자료 조사와 요약, 데이터 분석과 그래프 생성, 웹사이트 제작과 화면 점검입니다.

처음 맡겨 볼 작업은 기준 세 가지로 고릅니다.

- **손으로 하면 지루하고 순서가 정해진 일.** 같은 양식에 값을 옮겨 담는 작업이 여기 들어갑니다.
- **결과를 눈으로 바로 확인할 수 있는 일.** 틀렸을 때 알아챌 수 있어야 맡기는 범위를 넓힐 수 있습니다.
- **틀려도 되돌릴 수 있는 일.** 첫 시험은 실제 고객 데이터로 하지 않습니다.

문서와 장표를 만드는 쪽도 함께 봅니다. 기존 템플릿을 따라 슬라이드를 만드는 능력과 필요한 맥락만 골라 담는 쪽이 이번 발표에서 강조된 부분입니다. 사내 양식이 정해져 있는 보고서라면 양식 파일을 함께 주고 결과를 비교해 볼 만합니다.

## 자주 묻는 질문

### 무료 요금제에서도 아스트라를 쓸 수 있나요?

쓸 수 없습니다. 제공 대상은 Plus, Pro, Business, Enterprise이고, Free와 Go에는 GPT-5.6 Luna가 기본 모델로 제공됩니다. API도 무료 티어에서는 아스트라를 지원하지 않습니다.

### Plus를 쓰는데 일반 Chat에서 아스트라를 보고 싶으면 어떻게 하나요?

일반 Chat에서 아스트라를 쓰는 GPT-6 Pro 옵션은 Pro, Business, Enterprise 요금제에 있습니다. Plus를 유지하면서 아스트라를 쓰려면 ChatGPT Work나 Codex를 엽니다.

### API에서는 되는데 ChatGPT 앱에 모델이 없으면 어떻게 하나요?

API 권한과 ChatGPT 구독 권한은 따로 관리됩니다. API 호출이 성공했다는 것은 그 키와 프로젝트에서 쓸 수 있다는 뜻이고, 앱의 모델 목록과는 관계가 없습니다. 앱 쪽은 요금제와 워크스페이스 권한을 다시 확인합니다.

## 3줄 요약

- GPT-6 아스트라는 OpenAI가 2026년 9월 3일 공개한 모델이고 컴퓨터를 직접 조작하는 작업에 초점을 두고 있습니다.
- Plus 요금제는 ChatGPT Work와 Codex에서 아스트라를 쓰고 일반 Chat에서는 쓰지 못하며, Chat의 GPT-6 Pro는 Pro와 Business, Enterprise 요금제에서 열립니다.
- Enterprise와 Edu 워크스페이스에서는 출시 시점에 아스트라가 꺼진 상태이고 소유자가 모델 액세스 제어에서 따로 켜야 합니다.
