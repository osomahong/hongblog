클로드 아카데미(Claude Academy)는 앤트로픽이 운영하는 무료 학습 사이트입니다. 강좌와 튜토리얼, 실제 활용 사례가 `academy.claude.com` 한곳에 모여 있고, 사이트 소개에도 무료라고 적혀 있습니다. 공개 시점은 2026년 8월 20일로 집계됩니다.

클로드 사용법은 대부분 유튜브 영상이나 블로그 글로 익히게 됩니다. 그런데 앤트로픽이 직접 만든 학습 자료가 어디에 얼마나 있는지는 그에 비해 덜 알려져 있습니다. 그러다 보면 이미 바뀐 화면을 설명하는 글을 붙잡고 시간을 쓰기도 합니다.

여러 주소에 흩어져 있던 자료가 서점 서가에 분류돼 꽂히듯 한 사이트로 모였습니다. 2026년 8월 21일 기준 자료 구성과 한국어 지원 범위, 수강 조건, 상황별 학습 순서를 실제 화면과 함께 정리합니다.

![클로드 아카데미 첫 화면. Claude.ai, Claude Cowork, Claude Code, Claude Tag, Claude Platform 다섯 제품별 학습 카드가 한국어로 표시되어 있다](/images/insights/claude-academy-free-courses/academy-home.png)

## 2026년 8월 기준 자료 구성

사이트에 올라온 자료를 한 목록으로 모아 보면 355개입니다. 종류별로 나누면 다음과 같습니다.

| 종류 | 개수 | 성격 |
|---|---|---|
| 강좌 | 22개 | 동영상 레슨과 퀴즈로 이뤄집니다. 대부분 수료 배지가 붙습니다 |
| 튜토리얼 | 119개 | 3분에서 20분 사이의 단일 주제 자료 |
| 활용 사례 | 148개 | 직무와 업종별로 클로드를 쓴 사례 |
| 웨비나 | 표기 없음 | 예정된 라이브 일정과 지난 회차가 함께 올라옵니다 |

첫 화면은 Claude.ai, Claude Cowork, Claude Code, Claude Tag, Claude Platform 다섯 제품으로 나뉩니다. 각각 대화, 작업 위임, 개발, 팀 채널 호출, API 연동을 다룹니다. 여기에 특정 제품에 묶이지 않는 AI Fluency 자료가 따로 있습니다.

이전에 쓰이던 주소도 이 사이트로 이어집니다. `claude.com/resources/courses`와 `anthropic.com/learn` 아래 주소를 열면 `academy.claude.com`의 같은 성격 페이지로 넘어갑니다. 예전 링크를 저장해 둔 분들은 따로 찾아 들어가지 않아도 됩니다.

## 강좌 22개 구성과 예상 소요 시간

강좌 목록은 네 묶음으로 나뉩니다. 이름과 대표 강좌는 다음과 같습니다.

| 묶음 | 강좌 수 | 대표 강좌 | 분량 |
|---|---|---|---|
| 여정 시작하기 | 4개 | Claude 101 | 레슨 13개, 2.5시간 |
| 제품 알아보기 | 5개 | Claude Code in Action | 레슨 9개, 1시간 |
| AI 역량 키우기 | 3개 | AI 역량: 프레임워크 및 기초 | 레슨 14개, 4시간 |
| API로 구축하기 | 3개 | Building with the Claude API | 레슨 67개, 9시간 |

여기에 대상별로 나뉜 AI Fluency 강좌 7개가 더 있습니다. 대상은 다음과 같습니다.

- **빌더용과 학생용**: 만드는 사람과 배우는 사람에 맞춘 두 가지
- **교육자용 세 가지**: 일반 교육자, 유아에서 12학년 교육자, 트레이너 양성
- **조직용 두 가지**: 비영리단체, 소규모 비즈니스

같은 프레임워크를 쓰되 예시와 분량이 대상에 맞춰 달라집니다.

소요 시간이 표기된 강좌 15개를 더하면 약 50시간입니다. API 관련 강좌 세 개가 25시간 넘게 차지하므로, 개발이 필요 없는 분이라면 실제로 들을 분량은 그보다 훨씬 적습니다.

![클로드 아카데미 강좌 목록 화면. 여정 시작하기 묶음에 Claude 101, Claude Code 101, Claude Cowork 소개, Claude Platform 101 카드가 레슨 수와 수료 배지 표시와 함께 놓여 있다](/images/insights/claude-academy-free-courses/academy-courses.png)

## 한국어 지원 범위

한국에서 접속하면 화면이 한국어로 나옵니다. 상단 메뉴, 강좌 목록의 설명, 레슨 본문까지 번역되어 있고, 주소에 `/ko/`가 붙습니다. 화면 아래쪽 언어 선택으로 영어 원문으로 바꿀 수도 있습니다.

다만 모든 요소가 번역된 것은 아닙니다. 강좌 제목은 Claude 101, Introduction to Model Context Protocol처럼 영어로 남은 것이 많고, 일부만 Claude Cowork 소개처럼 한국어로 바뀌었습니다. 학습 목표를 적어 둔 항목도 강좌에 따라 영어 그대로입니다.

레슨을 열면 본문도 한국어로 나옵니다. 아래는 Claude 101의 첫 레슨 화면입니다. 학습 목표, 강좌 로드맵, 본문 요약이 모두 한국어로 나오고 분량은 5분입니다.

![Claude 101 첫 레슨의 한국어 화면. 제목이 "Claude란 무엇인가요?"로 표시되고 학습 목표와 강좌 로드맵이 한국어로 정리되어 있다](/images/insights/claude-academy-free-courses/academy-lesson-korean.png)

번역 문장이 원문 구조를 그대로 따라간 대목도 눈에 띕니다. 뜻을 파악하기 어려운 정도는 아니지만, 용어가 헷갈릴 때는 언어를 영어로 바꿔 같은 문단을 대조해 보면 됩니다.

## 수강 조건: 비용과 계정, 실습 제약

계정 조건은 강좌 페이지에 적혀 있습니다. Claude 101 강좌 페이지는 전제조건으로 Free, Pro, Max, Team, Enterprise 가운데 아무 플랜의 Claude 계정을 적어 두었고, 클로드나 다른 AI 어시스턴트를 써 본 경험은 필요 없다고 안내합니다.

로그인은 나중으로 미룰 수 있습니다. 레슨을 열면 진행 상황을 저장하려면 로그인하라는 안내가 뜨는데, 계정 없이도 내용을 계속 읽을 수 있지만 완료한 레슨은 저장되지 않습니다. 여러 날에 걸쳐 들을 계획이라면 처음부터 로그인해 두는 편이 낫습니다.

실습에는 조건이 하나 더 붙습니다. 같은 페이지는 Cowork와 Enterprise Search처럼 유료 플랜이나 팀, 엔터프라이즈 플랜에서 열리는 기능이 일부 들어 있다고 밝히고, 해당 레슨에 그 사실을 표시한다고 안내합니다. 무료 플랜으로도 레슨은 끝까지 볼 수 있지만 손으로 따라 하는 부분에서 차이가 생깁니다.

강좌를 마치면 수료 배지를 받습니다. 목록에서는 배지가 붙는 것과 그렇지 않은 것을 구분해 표시하는데, Introduction to subagents처럼 짧은 강좌에는 배지가 없습니다.

## 어떤 순서로 들으면 좋을까요?

서가에 책이 꽂혀 있어도 어느 것부터 뽑을지는 각자의 상황에 달려 있습니다. 아래는 공식 권장 순서가 아니라, 강좌 목록에 적힌 대상과 분량을 놓고 정리한 예시입니다.

| 지금 상황 | 순서 | 합계 분량 |
|---|---|---|
| 클로드를 이번에 처음 쓴다 | Claude 101 → AI 역량: 프레임워크 및 기초 | 약 6.5시간 |
| 채팅으로는 매일 쓰지만 그 이상은 써 보지 않았다 | Claude Cowork 소개 → Introduction to agent skills | 약 3.5시간 |
| 코드를 다루고 자동화까지 붙이고 싶다 | Claude Code 101 → Introduction to Model Context Protocol → Building with the Claude API | 약 11시간 |

한 번에 다 들을 필요는 없습니다. 강좌 하나가 한두 시간을 넘겨 부담스럽다면 튜토리얼부터 골라 봐도 됩니다. Claude로 PowerPoint 만들기가 4분, 올바른 Claude 모델 선택하기가 5분이라 점심시간에 하나씩 볼 수 있는 분량입니다.

업무에 바로 쓸 만한 예시를 찾는다면 활용 사례 148개를 먼저 훑어도 됩니다. 금융 서비스 개요나 비영리단체 도입 가이드처럼 직무와 업종을 좁혀 놓은 자료가 많습니다.

## AI Fluency 4D 프레임워크: 위임, 설명, 분별력, 책임감

AI Fluency는 특정 제품 사용법이 아니라 AI와 일하는 방법을 다루는 묶음입니다. 기초 강좌 **AI 역량: 프레임워크 및 기초**는 4D 프레임워크를 축으로 삼습니다. 강좌 설명에 적힌 네 가지와 각 단계에서 다루는 내용은 다음과 같습니다.

| 요소 | 강좌에서 다루는 내용 |
|---|---|
| 위임(Delegation) | 문제를 알아보고 플랫폼을 이해한 뒤 어떤 작업을 맡길지 정하는 판단 |
| 설명(Description) | 결과물, 과정, 수행 방식을 설명하는 방법과 기초 프롬프팅 기법 |
| 분별력(Discernment) | 결과물과 과정, 동작을 비판적으로 평가하고 설명과 번갈아 다듬는 방법 |
| 책임감(Diligence) | 생성, 투명성, 배포 단계에서 결과에 책임을 지는 실천 |

이 프레임워크는 앤트로픽이 혼자 만든 것이 아닙니다. 강좌 소개에 따르면 링링 예술디자인대학의 릭 데이컨(Rick Dakan) 교수와 유니버시티 칼리지 코크의 조지프 펠러(Joseph Feller) 교수가 2023년과 2024년에 걸쳐 개발한 틀을 앤트로픽이 함께 강좌로 옮겼습니다. 제작에는 아일랜드 고등교육청의 부분적인 지원이 들어갔습니다.

강좌는 AI를 쓰는 방식을 자동화, 증강, 에이전시 세 가지로 구분해 설명합니다. 강좌에서 쓰는 이름을 그대로 옮긴 구분입니다. 프롬프트 요령만 모으는 자료와 성격이 다르므로, 도구가 바뀌어도 남는 기준을 잡고 싶은 분들에게 맞습니다.

## 무료라는 말에 조건이 붙지는 않나요?

수강료 자체에는 조건이 없습니다. 사이트 소개에 무료 강좌와 튜토리얼이라고 적혀 있고, 강좌 페이지 어디에도 가격이나 결제 절차가 나오지 않습니다.

조건이 생기는 곳은 실습 쪽입니다. 영상과 본문은 무료 플랜 계정으로 끝까지 볼 수 있지만, Cowork나 Enterprise Search처럼 유료 플랜에서 열리는 기능은 화면을 따라 하기 어렵습니다. 해당 레슨에 그 사실이 표시된다고 강좌 페이지가 안내하므로, 무료 플랜이라면 그 부분은 눈으로 익히고 넘어가도 됩니다.

## 한국어로만 들어도 내용이 이어지나요?

이어집니다. 레슨 본문과 학습 목표, 강좌 로드맵까지 한국어로 나오기 때문에 영어를 읽지 않아도 흐름을 따라갈 수 있습니다.

다만 목록에서 강좌를 찾을 때는 제목이 영어라 헷갈리기도 합니다. 카드 아래 설명이 한국어로 붙어 있으니 그쪽을 보면 무엇을 다루는 강좌인지 알아볼 수 있습니다. 용어가 애매하게 읽히면 화면 아래 언어 선택에서 영어로 바꿔 같은 문단을 대조해 봅니다.

## 기존 Anthropic Academy와 무엇이 다른가요?

이름과 주소가 바뀌었고, 자료 종류가 늘었습니다. 예전에는 강좌 중심으로 알려져 있었는데 지금은 튜토리얼 119개와 활용 사례 148개, 웨비나가 함께 놓여 있습니다.

예전 주소는 새 주소로 이어집니다. `anthropic.com/learn` 아래 페이지와 `claude.com/resources/courses`를 열면 `academy.claude.com`의 대응 페이지로 넘어갑니다. 다만 이전에 받은 수강 이력이나 배지가 어떻게 처리되는지는 공식 안내를 찾지 못했습니다. 예전에 강좌를 들었다면 로그인한 뒤 목록에서 직접 확인하는 편이 확실합니다.

## 3줄 요약

- 클로드 아카데미는 앤트로픽이 운영하는 무료 학습 사이트이고, 2026년 8월 21일 기준 강좌 22개와 튜토리얼 119개, 활용 사례 148개가 올라와 있습니다.
- 무료 플랜을 포함한 Claude 계정이면 들을 수 있고, 로그인 없이 읽을 수는 있지만 진행 상황과 수료 배지는 저장되지 않습니다.
- 화면과 레슨 본문은 한국어로 나오고 강좌 제목은 영어가 많습니다. 클로드를 처음 쓴다면 Claude 101, 채팅으로 이미 쓰고 있다면 Cowork 강좌부터가 무난합니다.
