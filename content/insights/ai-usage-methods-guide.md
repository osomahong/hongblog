요즘 AI를 쓸 수 있는 방법이 정말 많아졌습니다. 문제는 **방법마다 부르는 이름이 다르고, 사용 방식도 다르고, 할 수 있는 일도 다르다**는 겁니다.

- "챗봇이랑 데스크탑 앱이랑 뭐가 달라?"
- "커서가 AI라는데 클로드랑 같이 쓰는건가? 서로 다른 건가?"
- "MCP가 뭔데 포토샵에서 AI를 쓸 수 있다는 거야?"

이런 혼란은 당연합니다. 처음부터 업데이트를 따라왔던 분들이 아니라면 AI를 처음 접하는 경로가 너무 다양해졌기 때문입니다. 이 글에서 **AI를 사용하는 5가지 방법(2026년 03월 버전)**을 한번에 정리하겠습니다.

## 먼저 알아둘 개념 : AI 모델과 인터페이스는 다릅니다

정리에 앞서, 하나만 먼저 구분하겠습니다.

- **AI 모델** : 생각하고 답변을 만들어내는 두뇌 역할. Claude, GPT, Gemini 같은 것
- **인터페이스** : 그 두뇌에 접근하는 방법. 웹사이트, 앱, 터미널, 다른 프로그램 내장 등

같은 Claude 모델이라도 **웹에서 쓸 수도 있고, 앱으로 쓸 수도 있고, 터미널에서 쓸 수도 있고, 커서 같은 코딩 도구 안에 탑재되어 있을 수도 있습니다.** 모델은 하나인데, 접근하는 통로가 여러 개인 겁니다.

이걸 이해하면 아래 내용이 훨씬 쉽게 정리됩니다.

## 한눈에 보는 AI 사용 방법 5가지

| 방법 | 어디서 쓰나 | 대표 서비스 | 난이도 | 주 용도 |
|---|---|---|---|---|
| **1. 웹 챗봇** | 브라우저 | Claude.ai, ChatGPT, Gemini | 가장 쉬움 | 질문, 글쓰기, 번역, 요약 |
| **2. 데스크탑 앱** | PC/Mac 설치 프로그램 | Claude Desktop, ChatGPT Desktop | 쉬움 | 파일 작업, 내 컴퓨터 연동 |
| **3. 터미널 CLI** | 터미널/명령어 창 | Claude Code | 중간 | 코딩, 파일 자동화, 개발 |
| **4. 다른 도구에 탑재된 AI** | 코딩 에디터, 디자인 툴 등 | Cursor, Windsurf, Kiro | 중간 | 특정 작업에 특화된 AI 지원 |
| **5. MCP 연동** | 기존 프로그램 내부 | Photoshop, Notion, PowerPoint 등 | 다양함 | 기존 업무 도구에서 바로 AI 사용 |

이제 하나씩 자세히 살펴보겠습니다.

## 1. 웹 챗봇 : 가장 기본적인 사용법
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773110289076-dfx692.png)

**브라우저에서 AI 웹사이트에 접속해서 대화하는 방식**입니다. 대부분의 사람들이 AI를 처음 접하는 경로이기도 합니다.

### 대표 서비스

| 서비스 | 만든 회사 | AI 모델 | 무료 여부 | 주소 |
|---|---|---|---|---|
| Claude.ai | Anthropic | Claude | 무료 + 유료 | claude.ai |
| ChatGPT | OpenAI | GPT | 무료 + 유료 | chatgpt.com |
| Gemini | Google | Gemini | 무료 + 유료 | gemini.google.com |

### 할 수 있는 일

- 질문하고 답변 받기
- 긴 글 요약하기
- 글쓰기 (블로그, 이메일, 보고서 등)
- 번역
- 코드 작성 및 설명
- 이미지 분석 (사진을 업로드하면 내용을 읽어줌)
- 파일 업로드 후 분석 (PDF, 엑셀 등)

### 이런 분에게 적합합니다

- AI를 처음 사용하는 분
- 설치 없이 바로 쓰고 싶은 분
- 일상적인 질문, 글쓰기, 번역이 주 목적인 분

## 2. 데스크탑 앱 : 내 컴퓨터와 연결되는 AI
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773110317670-c5nfml.png)

**PC나 Mac에 프로그램을 설치해서 사용하는 방식**입니다. 겉보기에는 웹 챗봇과 비슷하지만, 결정적인 차이가 하나 있습니다.

웹 챗봇은 브라우저 안에서만 작동합니다. 반면 데스크탑 앱은 **내 컴퓨터의 파일과 프로그램에 접근할 수 있습니다.** 예를 들어 "바탕화면에 있는 엑셀 파일을 분석해줘"라고 하면, 웹 챗봇은 파일을 직접 업로드해야 하지만, 데스크탑 앱은 컴퓨터에서 바로 파일을 읽을 수 있습니다.

### 대표 서비스

| 서비스 | 플랫폼 | 특징 |
|---|---|---|
| Claude Desktop | Mac, Windows | 컴퓨터 화면 인식(Computer Use), MCP 연동 지원 |
| ChatGPT Desktop | Mac, Windows | 화면 공유, 음성 대화 지원 |

### 웹 챗봇과 뭐가 다른가요?

| 항목 | 웹 챗봇 | 데스크탑 앱 |
|---|---|---|
| 설치 필요 | 없음 | 있음 |
| 내 컴퓨터 파일 접근 | 직접 업로드 필요 | 컴퓨터에서 바로 읽기 가능 |
| 다른 프로그램 연동 | 불가 | MCP 등으로 연동 가능 |
| 화면 인식 | 불가 | 가능 (일부 서비스) |
| 오프라인 사용 | 불가 | 불가 (인터넷 필요) |

### 이런 분에게 적합합니다

- 내 컴퓨터 파일을 AI로 자주 분석하는 분
- 여러 프로그램을 AI와 연결해서 쓰고 싶은 분 (MCP 활용)
- AI를 항상 빠르게 호출하고 싶은 분 (단축키로 바로 실행 가능)

## 3. 터미널 CLI : 개발자를 위한 AI (클로드 코드)
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773110406304-iwl25i.png)

**터미널(명령어 창)에서 텍스트 명령어로 AI를 사용하는 방식**입니다. CLI는 Command Line Interface의 약자로, 마우스 클릭 대신 키보드로 명령어를 입력해서 컴퓨터를 조작하는 환경입니다.

솔직히 말하면, 이 방식은 **개발자나 기술 직군이 아니라면 사용할 일이 거의 없었습니다.** 하지만 현재 가장 강력한 AI 활용법이며, 현재 가장 강력한 클로드 코드의 에이전트와 스킬을 사용할 수 있는 방법입니다.

### 대표 서비스

| 서비스 | 만든 회사 | 특징 |
|---|---|---|
| Claude Code | Anthropic | 코드 작성, 파일 편집, Git 관리, 터미널 명령 실행까지 가능 |
| GitHub Copilot CLI | GitHub(Microsoft) | 터미널 명령어 제안 및 설명 |
| Aider | 오픈소스 | 다양한 AI 모델과 연동 가능한 코딩 에이전트 |

### 뭘 할 수 있나요?

웹 챗봇에서 "이 코드 수정해줘"라고 하면, AI가 수정된 코드를 보여줍니다. 하지만 그걸 직접 복사해서 파일에 붙여넣어야 합니다.

터미널 CLI에서는 다릅니다. **AI가 직접 파일을 열고, 코드를 수정하고, 저장하고, 테스트까지 실행합니다.** 개발자가 일일이 복사-붙여넣기 할 필요가 없습니다.

- 프로젝트 전체 코드를 읽고 이해
- 파일을 직접 생성하고 편집
- 터미널 명령어 실행 (빌드, 테스트, 배포 등)
- Git 커밋, 브랜치 관리
- 버그를 찾아서 직접 수정

### 이런 분에게 적합합니다

- 개발자, 엔지니어
- 터미널 환경에 익숙한 분
- 코딩 작업에서 AI를 최대한 활용하고 싶은 분

## 4. 다른 도구에 탑재된 AI : 특정 작업에 특화
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773110622147-hvdhq7.png)

**코딩 에디터, 디자인 도구, 문서 편집기 같은 기존 프로그램 안에 AI 모델이 내장되어 있는 방식**입니다.

이 경우 별도의 AI 서비스에 접속하는 게 아니라, **이미 사용하고 있는 도구 안에서 AI 기능을 바로 사용**할 수 있습니다. Claude나 GPT 같은 모델이 뒤에서 작동하지만, 사용자는 그 도구의 UI 안에서 자연스럽게 쓰게 됩니다.

### 대표 서비스

| 서비스 | 분야 | 탑재된 AI 모델 | 특징 |
|---|---|---|---|
| Cursor | 코딩 에디터 | Claude, GPT 등 선택 가능 | 코드 자동완성, AI 채팅, 코드 수정 |
| Windsurf | 코딩 에디터 | Claude, GPT 등 | Cursor와 유사, 에이전트 기능 강조 |
| Kiro | 코딩 에디터 | Claude | Amazon(AWS)에서 만든 AI 코딩 에디터 |
| Canva | 디자인 | 자체 AI + 외부 모델 | AI 이미지 생성, 디자인 자동 제안 |
| Notion AI | 문서/메모 | 자체 AI | 문서 요약, 글쓰기 보조, 번역 |
| Microsoft 365 Copilot | 오피스 | GPT | Word, Excel, PowerPoint에서 AI 지원 |

### 웹 챗봇과 뭐가 다른가요?

웹 챗봇은 **범용 도구**입니다. 뭐든 물어볼 수 있지만, 특정 작업에 최적화되어 있지는 않습니다.

도구 탑재형 AI는 **해당 작업에 특화**되어 있습니다. 예를 들어 Cursor에서 코드를 선택하고 "이 함수를 리팩토링해줘"라고 하면, AI가 해당 파일의 맥락을 이미 알고 있기 때문에 훨씬 정확한 결과를 줍니다. 웹 챗봇에서 같은 요청을 하려면 코드를 복사해서 붙여넣고, 프로젝트 구조를 설명해야 합니다.

| 항목 | 웹 챗봇 (Claude.ai 등) | 도구 탑재형 AI (Cursor 등) |
|---|---|---|
| 사용 맥락 | 범용 (아무 질문이나 가능) | 특정 작업에 특화 |
| 작업 파일 접근 | 직접 업로드 필요 | 현재 작업 중인 파일을 자동 인식 |
| 결과 적용 | 복사-붙여넣기 | 도구 안에서 바로 적용 |
| 비용 | AI 서비스 구독료 | 도구 구독료 (AI 모델 사용료 포함 또는 별도) |

### 이런 분에게 적합합니다

- 특정 도구(코딩, 디자인, 문서작업)를 매일 사용하는 분
- 작업 흐름을 끊지 않고 AI를 쓰고 싶은 분
- 복사-붙여넣기 없이 바로 결과를 적용하고 싶은 분

## 5. MCP 연동 : 기존 프로그램에 AI를 연결하는 방법
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773110493300-nh2mo7.png)

이 부분이 가장 최근(AI 본격 등장 이후)에 등장한 개념이라 생소할 수 있습니다.

**MCP(Model Context Protocol)**는 AI 모델이 외부 프로그램과 소통할 수 있게 해주는 **연결 규격**입니다. 쉽게 말해, AI에게 "포토샵을 조작할 수 있는 손"을 달아주는 것입니다.

### MCP가 없을 때 vs 있을 때

| 상황 | MCP 없이 | MCP 연결 후 |
|---|---|---|
| 포토샵 작업 | AI에게 "배경 제거해줘"라고 물으면, 방법을 텍스트로 알려줌 | AI가 직접 포토샵을 열고 배경을 제거해줌 |
| 슬랙 메시지 | AI에게 메시지를 써달라고 하면, 텍스트를 줌. 직접 복사해서 슬랙에 붙여넣어야 함 | AI가 직접 슬랙 채널에 메시지를 보냄 |
| 엑셀 분석 | 파일을 업로드하면 분석 결과를 텍스트로 줌 | AI가 직접 엑셀 파일을 열고 차트를 만들어줌 |

### MCP를 지원하는 프로그램 예시

| 프로그램 | AI가 할 수 있는 일 |
|---|---|
| Photoshop | 이미지 편집, 레이어 조작, 필터 적용 |
| Notion | 페이지 생성, 데이터베이스 조회, 문서 정리 |
| Slack | 메시지 읽기/보내기, 채널 관리 |
| Google Drive | 파일 검색, 문서 생성 및 편집 |
| GitHub | 코드 검색, 이슈 관리, PR 생성 |
| 데이터베이스 | 데이터 조회 및 분석 |

### MCP는 어디서 설정하나요?

현재 MCP를 설정하려면 **Claude Desktop 앱** 또는 **Claude Code(터미널)**에서 연결합니다. 웹 챗봇(claude.ai)에서는 아직 MCP를 직접 연결할 수 없습니다.

설정 과정은 프로그램마다 다르지만, 기본적인 흐름은 이렇습니다.

1. 연결하고 싶은 프로그램의 MCP 서버를 찾습니다 (보통 GitHub에 공개되어 있음)
2. Claude Desktop 또는 Claude Code의 설정 파일에 해당 MCP 서버 정보를 추가합니다
3. AI가 해당 프로그램을 조작할 수 있게 됩니다

기술적인 설정이 필요하기 때문에 완전 초보자에게는 다소 어려울 수 있지만, 한 번 설정하면 업무 효율이 크게 올라갑니다.

### 이런 분에게 적합합니다

- 여러 프로그램을 오가며 작업하는 분
- 반복적인 작업을 AI에게 맡기고 싶은 분
- AI가 "알려주는 것"을 넘어 "직접 해주는 것"을 원하는 분

## 어떤 방법을 선택해야 할까? : 상황별 추천

### 1. 지금 AI를 처음 써보는 분이라면

**웹 챗봇(claude.ai 또는 chatgpt.com)부터 시작하세요.** 설치도 필요 없고, 가입만 하면 바로 쓸 수 있습니다. 여기서 AI가 어떤 일을 할 수 있는지 감을 잡은 후에 다른 방법으로 확장하면 됩니다.

### 2. 업무에서 본격적으로 AI를 활용하고 싶은 분이라면

**데스크탑 앱을 설치하세요.** 웹 챗봇보다 내 컴퓨터 파일에 접근하기 쉽고, 단축키로 빠르게 호출할 수 있어서 업무 중에 자연스럽게 AI를 쓸 수 있습니다.

### 3. 특정 도구(코딩, 디자인 등)에서 AI를 쓰고 싶은 분이라면

**해당 분야에 특화된 AI 도구를 선택하세요.** 코딩이라면 Cursor나 Kiro, 문서 작업이라면 Notion AI, 오피스 작업이라면 Microsoft 365 Copilot이 작업 흐름에 자연스럽게 녹아듭니다.

### 4. AI에게 프로그램을 직접 조작하게 하고 싶은 분이라면

**Claude Desktop + MCP 조합을 사용할 수 있는지 살펴보세요.** 설정에 약간의 기술적 지식이 필요하지만, AI가 단순히 답변을 주는 것을 넘어 실제로 작업을 대신해줍니다.

## 같은 모델, 다른 이름 : 헷갈리는 용어 정리

마지막으로, 같은 것을 다르게 부르는 경우가 많아서 정리합니다.

### AI 모델 이름

| 회사 | 모델 이름 | 흔히 부르는 말 |
|---|---|---|
| Anthropic | Claude (Opus, Sonnet, Haiku) | 클로드 |
| OpenAI | GPT (GPT-4o, o1, o3 등) | 챗GPT, GPT |
| Google | Gemini (Ultra, Pro, Flash) | 제미나이 |
| Meta | Llama | 라마 |
| xAI(일론 머스크) | Grok | 그록 |

주의할 점 : **"Claude"는 서비스 이름이고, "Opus"가 모델 이름입니다.** 쉽게 비유하자면**"삼성"은 서비스, "갤럭시"가 모델**입니다. 서비스와 모델을 구분하면 용어가 훨씬 명확해집니다.

### 인터페이스 용어

| 용어 | 의미 |
|---|---|
| 챗봇 | 대화형 AI 서비스 (웹 또는 앱) |
| CLI | Command Line Interface. 터미널에서 명령어로 조작하는 방식 |
| API | 프로그램끼리 데이터를 주고받는 통로. 개발자가 AI를 자기 서비스에 연결할 때 사용 |
| MCP | Model Context Protocol. AI가 외부 프로그램을 조작할 수 있게 하는 연결 규격 |
| 에이전트 | 사람의 지시를 받아 여러 단계의 작업을 스스로 수행하는 AI |
| LLM | Large Language Model. AI 모델의 기술적 명칭 |

## 마무리

AI를 사용하는 방법은 계속 늘어나고 있고, 앞으로도 더 다양해질 겁니다. 하지만 핵심은 간단합니다.

1. **AI 모델(두뇌)은 Claude, GPT, Gemini 같은 것이고**
2. **그 두뇌에 접근하는 통로(인터페이스)가 웹, 앱, 터미널, 다른 도구 내장, MCP 등으로 다양한 것**

어떤 통로를 선택하든 결국 같은 AI 모델을 사용하는 것이니, **자신의 업무 환경과 목적에 맞는 방법을 하나씩 시도**해보는 것을 추천합니다. 처음에는 웹 챗봇, 익숙해지면 데스크탑 앱, 그 다음에는 특화 도구나 MCP까지. 한꺼번에 다 알 필요는 없습니다.

**3줄 요약:**
- AI 모델(Claude, GPT 등)은 같지만, 접근 방법은 웹 챗봇, 데스크탑 앱, 터미널, 도구 내장, MCP 연동 등 5가지로 나뉩니다.
- 초보자는 웹 챗봇부터, 업무 활용은 데스크탑 앱이나 특화 도구로, 고급 활용은 MCP 연동으로 단계적으로 확장하면 됩니다.
- 서비스 이름(ChatGPT, Claude.ai)과 모델 이름(GPT, Claude)을 구분하면 용어 혼란이 크게 줄어듭니다.
