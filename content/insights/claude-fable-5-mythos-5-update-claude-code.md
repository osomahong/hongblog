앤트로픽이 2026년 6월 9일 그동안 공개를 보류해 온 **클로드 미토스(Claude Mythos)** 계열 모델을 일반 공개했습니다. 정식 이름은 **클로드 페이블 5(Claude Fable 5)**입니다. 미토스와 페이블은 다른 모델이 아니라 같은 모델의 두 이름이며, 이 모델은 [클로드 코드](/class/claude-code-for-everyone/what-is-claude-code)에서도 사용할 수 있습니다.

이 글은 두 부분으로 나뉩니다. 앞쪽은 이번 미토스 업데이트의 핵심(미토스와 페이블의 관계, 성능, 안전장치, 가격)을 요약하고, 뒤쪽은 클로드 코드에서 설치하고 모델을 전환하는 방법을 설명합니다.

## 핵심 요약 한눈에 보기

먼저 이번 업데이트의 핵심을 표로 정리했습니다.

| 항목 | 내용 |
|------|------|
| 공개일 | 2026년 6월 9일 |
| 정식 이름 | 클로드 페이블 5 (미토스 계열의 일반 공개 버전) |
| 성능 | 앤트로픽이 일반 공개한 모델 중 최고 수준 |
| 안전장치 | 사이버보안, 생물학, 증류 영역 자동 차단, 전체 세션의 5% 미만에서 작동 |
| 가격 | 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러 (Opus 4.8의 2배) |
| 무료 기간 | 6월 22일까지 Pro, Max, 팀, 기업 플랜 무료 포함 |
| 클로드 코드 | v2.1.170 이상에서 `/model fable`로 사용 |

각 항목을 아래에서 차례대로 설명하겠습니다.

## 미토스와 페이블, 같은 모델의 두 이름

미토스와 페이블은 기반이 같은 모델입니다. 차이는 성능이 아니라 안전장치를 어디까지 적용했는지에 있습니다.

| 구분 | 클로드 페이블 5 | 클로드 미토스 5 |
|------|---------------|----------------|
| 기반 모델 | 동일 | 동일 |
| 안전장치 | 위험 영역 자동 차단 적용 | 일부 영역 차단 해제 |
| 공개 범위 | 일반 사용자(Pro, Max, 팀, 기업, API) | 사이버 방어 기관 등 소수 협력 대상 |
| 사용 목적 | 범용 작업 | 사이버 방어, 신뢰 기반 연구 |

앤트로픽은 지난 4월 이 모델의 일반 공개를 한 차례 보류했습니다. 사이버보안 악용 가능성을 이유로 들었습니다. 이번에 공개한 페이블 5는 그 위험 영역을 자동으로 걸러내는 분류기를 적용해 일반 사용자도 쓸 수 있게 만든 버전입니다. 미토스 5는 같은 모델에서 일부 안전장치를 푼 버전으로, 사이버 방어처럼 차단이 오히려 방해가 되는 소수 기관에만 미국 정부 협력 프로그램(Project Glasswing) 등을 통해 제공됩니다.

정리하면 일반 사용자가 쓰는 미토스 계열 모델의 정식 이름이 페이블 5입니다. 클로드 코드나 앱에 표시되는 이름도 페이블 5입니다.

## 페이블 5의 성능

페이블 5는 앤트로픽이 일반에 공개한 모델 중 성능이 가장 높습니다. 소프트웨어 엔지니어링, 지식 기반 업무, 비전(이미지 해석), 과학 연구 등 여러 평가에서 최고 수준을 기록했다고 밝혔습니다. 공개된 사례는 다음과 같습니다.

- **소프트웨어 엔지니어링**: 결제 인프라 기업 스트라이프는 5천만 줄 규모의 루비 코드베이스 이전 작업을 페이블 5가 하루 만에 끝냈다고 밝혔습니다. 앤트로픽은 개발팀 전체가 진행해도 두 달 이상 걸리는 분량이라고 설명했습니다.
- **긴 작업 처리**: 수백만 토큰 분량의 맥락을 유지하며, 한 번에 끝나지 않는 며칠 단위의 작업도 이어서 처리합니다.
- **비전**: 과학 자료의 수치를 읽어내고, 화면 캡처만으로 웹앱의 소스 코드를 재구성하기도 합니다.

앤트로픽이 강조한 부분은 단순히 답의 정확도가 아니라, 모델이 스스로 조사하고 행동 전에 검토하며 자기 결과를 더 자주 검증한다는 점입니다. 그래서 단계를 일일이 지시하기보다 원하는 결과를 제시하고 방법을 맡기는 작업에 적합합니다.

## 위험한 요청을 자동으로 막는 안전장치

페이블 5에는 세 가지 분류기(classifier)가 들어 있습니다. 분류기는 요청이 들어올 때 위험한 영역에 해당하는지 한 번 더 판정하는 장치입니다.

- **사이버보안**: 취약점 탐색, 공격 기법 같은 요청을 감지
- **생물학, 화학**: 유전자 치료 설계처럼 악용 소지가 있는 이중 용도 기술을 감시
- **증류(distillation)**: 경쟁 모델을 만들기 위해 능력을 빼가는 시도를 차단

이 세 영역에 해당하면 페이블 5는 응답을 멈추고 Opus 4.8이 대신 답하도록 넘깁니다. 앤트로픽은 이 차단이 전체 세션의 5% 미만에서만 작동한다고 밝혔습니다. 나머지 95% 이상의 작업에서는 미토스 5와 사실상 같은 성능을 사용할 수 있습니다.

> 페이블 5는 위험 영역에서만 답을 멈추고 Opus 4.8로 넘깁니다. 일반적인 코딩이나 글쓰기 작업에서는 차단이 거의 일어나지 않습니다.

## 가격과 무료 이용 기간

페이블 5의 가격은 입력 토큰 100만 개당 10달러, 출력 토큰 100만 개당 50달러입니다. [Opus 4.8](/class/claude-fundamentals/claude-model-family)의 두 배 수준이고, 과거 미토스 프리뷰 가격의 절반 이하입니다.

구독제 사용자에게는 기간 한정 조건이 적용됩니다.

- **2026년 6월 9일 ~ 6월 22일**: Pro, Max, 팀, 기업 플랜에서 추가 비용 없이 포함
- **6월 23일 이후**: 사용량 기반 크레딧 필요(용량이 확보되면 이후 표준 포함으로 전환 예정)

6월 22일까지는 구독자라면 추가 비용 없이 페이블 5를 사용해 볼 수 있습니다.

## 클로드 코드 설치 및 모델 전환 방법

페이블 5는 [클로드 코드](/class/claude-code-for-everyone/what-is-claude-code)에서 사용할 수 있습니다. 설치 또는 업데이트 후 모델을 전환하는 두 단계만 거치면 됩니다.

### 1단계: 클로드 코드 설치 또는 최신 버전 업데이트

클로드 코드를 처음 쓴다면 먼저 설치해야 합니다. npm이 설치된 환경에서 아래 명령으로 설치합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

(터미널이 익숙하지 않다면 [클로드 코드 설치 가이드](/class/claude-code-for-everyone/claude-code-installation-basics)에 단계별 과정이 정리되어 있습니다.)

이미 설치되어 있다면 최신 버전으로 업데이트만 하면 됩니다. 페이블 5는 클로드 코드 v2.1.170 이상에서만 표시되고, 이전 버전은 모델 선택 목록에 나타나지 않습니다.

```bash
claude update
```

설치나 업데이트가 끝나면 버전을 확인합니다.

```bash
claude --version
```

버전 숫자가 2.1.170 이상이면 준비가 끝난 것입니다.

### 2단계: 모델을 페이블 5로 전환

가장 간단한 방법은 세션 안에서 슬래시 명령을 입력하는 것입니다.

```bash
/model fable
```

`/model fable`과 `/model claude-fable-5` 모두 동작합니다. 한 번 선택하면 다음 세션의 기본값으로 저장됩니다. 그 외 방법은 다음과 같습니다.

| 방법 | 명령/설정 | 특징 |
|------|----------|------|
| 세션 중 전환 | `/model fable` | 가장 빠름. 즉시 적용되고 기본값으로 저장됨 |
| 실행 시 지정 | `claude --model fable` | 그 세션에만 적용. 터미널마다 다른 모델 운용 가능 |
| 환경 변수 | `ANTHROPIC_MODEL=claude-fable-5` | 셸 환경 전체에 적용 |
| 설정 파일 고정 | `settings.json`에 `"model": "fable"` | 항상 페이블 5로 시작 |

설정 파일에 고정하는 예시는 이렇습니다.

```json
{
  "model": "fable"
}
```

현재 사용 중인 모델은 `/status`를 입력하거나 상태 표시줄에서 확인할 수 있습니다.

> 페이블 5는 어떤 플랜에서도 기본 모델이 아닙니다. `/model fable`로 직접 선택해야 사용이 시작됩니다.

## 클로드 코드의 자동 폴백

페이블 5로 작업하다 보면 화면에 Opus 4.8로 전환되었다는 안내가 표시될 때가 있습니다. 오류가 아니라 앞서 설명한 안전장치가 작동한 것입니다. 사이버보안이나 생물학 관련 내용이 감지되면 클로드 코드가 해당 요청만 Opus 4.8로 다시 처리하고 안내 문구를 보여줍니다.

이 전환은 세션의 첫 요청부터 일어날 수 있습니다. 첫 요청에는 작업 폴더의 `CLAUDE.md` 내용이나 git 상태 같은 맥락이 함께 전달되기 때문입니다. 보안이나 생물학 관련 자료가 들어 있는 저장소라면 그 맥락만으로도 분류기가 반응할 수 있습니다.

- 다시 페이블 5로 돌아가려면 `/model fable`을 입력합니다.
- 전환 원인을 확인하려면 `claude --safe-mode`로 실행합니다. CLAUDE.md, 스킬, MCP 서버, 훅 같은 사용자 설정을 끈 상태로 켜집니다.
- 보안 연구나 생물학 작업을 본격적으로 진행하면 대부분의 요청이 전환됩니다. 이는 계정 문제가 아니라 해당 분야에서 의도된 동작입니다.

## 모든 작업에 페이블 5가 필요한 것은 아닙니다

페이블 5는 성능이 높지만, 모든 사용자가 바로 전환해야 하는 모델은 아닙니다.

페이블 5가 적합한 작업은 한 번에 끝나지 않는 긴 작업, 원인을 알기 어려운 문제 추적, 대규모 마이그레이션처럼 사람이 직접 하면 며칠 걸리는 일입니다. 가격도 Opus 4.8의 두 배입니다. 파일 몇 개를 수정하거나 간단한 함수를 작성하거나 짧은 질문에 답을 받는 일상 작업이라면 Opus 4.8이나 [Sonnet](/class/claude-fundamentals/claude-model-family)이 더 합리적입니다.

AI 코딩을 처음 시작하는 경우라면 더욱 그렇습니다. 커뮤니티의 후기를 보고 긴 작업을 똑같이 돌려야 한다고 느낄 필요는 없습니다. 작은 작업을 Sonnet으로 익히고, 다루는 작업이 커지면 Opus를, 긴 작업을 맡길 일이 생기면 페이블 5를 선택해도 됩니다.

6월 22일까지는 구독자라면 추가 비용 없이 페이블 5를 사용해 볼 수 있습니다. 본격적인 프로젝트에 바로 투입하기보다, 평소 해보려던 작업 하나를 맡겨 보는 정도로 시작해 보길 권합니다.
