클로드 페이블 5.1(Claude Fable 5.1)은 [앤트로픽](/class/claude-fundamentals/what-is-anthropic)이 2026년 9월 1일 공개한 코딩과 지식 업무용 상위 모델입니다. 함께 나온 클로드 미토스 5.1(Claude Mythos 5.1)은 다른 모델이 아니라 같은 모델에서 안전장치를 완화한 판이고, 검증을 거친 기관에만 열립니다. 앤트로픽은 발표문에서 두 모델을 코딩과 지식 업무 분야의 세계 최고 모델이라고 소개했습니다.

이번 공개에서 실제로 달라진 것은 세 가지입니다. 벤치마크 점수, 캐시 읽기 가격, 안전장치가 잘못 걸리는 빈도입니다. 입력과 출력의 기본 가격은 그대로입니다.

![앤트로픽 공식 발표 페이지에 실린 벤치마크 비교표. Fable 5.1, Fable 5, Opus 5, GPT-5.6 Sol의 에이전틱 과학 연구, 에이전틱 코딩, 지식 업무, 컴퓨터 사용 항목별 점수가 정리되어 있다](/images/insights/claude-fable-5-1-mythos-5-1-update/fable-5-1-benchmark.png)

지금부터 공식 발표문과 앤트로픽 개발자 문서를 기준으로 달라진 점을 정리하고, 플랜별 이용 조건과 [클로드 코드](/class/claude-code-for-everyone/what-is-claude-code)에서 모델을 바꾸는 방법까지 다루겠습니다. 앞선 세대인 페이블 5가 나왔을 때의 내용은 준이아빠블로그의 [클로드 미토스 업데이트 핵심 요약](/insights/claude-fable-5-mythos-5-update-claude-code)에 있고, 지금 기본 모델로 쓰이는 [Opus 5 업데이트 정리](/insights/claude-opus-5-update-and-usage)도 따로 있습니다. 여기 적은 내용은 2026년 9월 2일 기준입니다.

## 한눈에 보는 변경 사항

| 항목 | 내용 |
|---|---|
| 공개일 | 2026년 9월 1일 |
| 모델 ID | `claude-fable-5-1` |
| 컨텍스트 | 100만 토큰, 최대 출력 12만 8천 토큰 |
| 기본 가격 | 입력 100만 토큰당 10달러, 출력 50달러 (페이블 5와 동일) |
| 캐시 읽기 | 100만 토큰당 1달러에서 0.25달러로 인하 |
| 안전장치 | 생물학 오탐 85% 감소, 사이버보안 오탐 60% 감소 |
| 미토스 5.1 | 신뢰 접근 프로그램 대상, 현재 미국 기관 한정 |
| 클로드 코드 | v2.1.255 이상에서 `/model fable` |

## 벤치마크로 본 성능 변화

표에는 에이전틱(agentic)이라는 말이 반복해서 나오는데, 벤치마크 이름보다 이 단어가 먼저 낯설게 느껴지기 쉽습니다. 쉽게 말하면 사람이 단계마다 지시하지 않고 모델이 스스로 도구를 쓰며 끝까지 진행하는 방식입니다. 앤트로픽이 공개한 비교표를 옮기면 다음과 같고, GPT-5.6 Sol은 비교 대상으로 함께 실린 다른 회사 모델입니다.

| 항목 | 페이블 5.1 | 페이블 5 | Opus 5 | GPT-5.6 Sol |
|---|---|---|---|---|
| 에이전틱 과학 연구 (Terminal-Bench-Science 0.1) | 52.6% | 24.7% | 29.0% | 22.4% |
| 에이전틱 코딩 (Terminal-Bench 4.0) | 55.8% | 42.0% | 52.3% | 37.3% |
| 지식 업무 (GDPval-AA v2) | 1853 | 1723 | 1824 | 1711 |
| 컴퓨터 사용 (OSWorld 2.0, strict) | 41.7% | 36.1% | 39.6% | 표기 없음 |
| 다분야 추론 (Humanity's Last Exam, 도구 없음) | 60.9% | 57.8% | 56.6% | 표기 없음 |
| 업무 자동화 (AutomationBench) | 31.4% | 17.1% | 26.9% | 19.6% |

가장 크게 벌어진 항목은 과학 연구입니다. 페이블 5의 24.7%에서 52.6%로 두 배 이상 올랐습니다. 에이전틱 코딩에서는 미토스 5.1이 60.9%로 페이블 5.1보다 높게 표기되어 있는데, 안전장치를 덜 적용한 쪽이 더 높은 점수를 받았습니다.

수치를 읽을 때 앤트로픽이 함께 밝힌 조건 두 가지를 같이 봐야 합니다. 첫째, 페이블 5.1은 운영용 안전장치를 켠 상태로 평가했고 안전장치가 개입한 과제는 0점으로 처리했습니다. 앤트로픽은 이 처리 때문에 점수가 실제보다 낮게 나왔을 수 있다고 적었습니다. 둘째, Terminal-Bench-Science 0.1의 표준오차는 모델당 3.5에서 4.5포인트입니다.

그러면 앞으로 Opus 5 대신 페이블 5.1만 쓰면 될까요? 그렇지는 않습니다. 앤트로픽 개발자 문서는 대부분의 작업을 Opus 5로 시작하고, 까다로운 추론과 오래 걸리는 에이전트 작업이거나 Opus 5를 높은 effort로 돌려도 결과가 부족할 때 페이블 5.1로 넘어가라고 안내합니다.

## 캐시 읽기 75% 인하가 실제 비용에 미치는 영향

캐시 읽기(cache read)라는 말은 입력 토큰이나 출력 토큰보다 상대적으로 낯설 수 있습니다. 쉽게 말하면 앞서 한 번 처리해 둔 맥락을 다시 읽을 때 매기는 값입니다. 같은 서류를 매번 처음부터 읽는 대신 서류함에 넣어 둔 것을 다시 꺼내 보듯, 모델도 이미 처리한 프롬프트를 저장해 두었다가 다시 불러옵니다.

앤트로픽 요금 문서 기준으로 페이블 5.1과 미토스 5.1의 캐시 읽기는 기본 입력가의 2.5%입니다. 다른 모델은 10%가 적용되므로 이 두 모델만 예외입니다.

| 항목 | 페이블 5.1 | 페이블 5 | Opus 5 |
|---|---|---|---|
| 입력 | 10달러 | 10달러 | 5달러 |
| 출력 | 50달러 | 50달러 | 25달러 |
| 캐시 읽기 | 0.25달러 | 1달러 | 0.50달러 |
| 5분 캐시 쓰기 | 12.50달러 | 12.50달러 | 6.25달러 |
| 1시간 캐시 쓰기 | 20달러 | 20달러 | 10달러 |

모두 100만 토큰당 미국 달러 기준입니다. 급하지 않은 요청을 모아 한꺼번에 처리하는 배치 API를 쓰면 입력과 출력이 절반으로 내려가 각각 5달러와 25달러가 됩니다.

기본 가격은 그대로인데 왜 전체 비용이 줄어들까요? 에이전트 작업에서는 같은 서류를 수십 번 다시 꺼내 보기 때문입니다. 도구를 여러 번 호출하는 작업일수록 캐시 읽기가 전체 비용에서 차지하는 몫이 커지고, 그 항목만 4분의 1로 내려가면 합계가 크게 달라집니다.

![앤트로픽 발표 페이지의 비용 지수 그래프. 일반 작업에서는 페이블 5를 100으로 놓았을 때 페이블 5.1이 75이고, 에이전트 작업에서는 55로 표시되어 있다](/images/insights/claude-fable-5-1-mythos-5-1-update/fable-5-1-cost-chart.png)

앤트로픽은 2026년 8월 4주간의 실제 사용량을 지수로 만들어 이 그래프를 냈습니다. 일반 작업은 약 25%, 맥락과 도구가 많은 에이전트 작업은 약 45% 내려갑니다. 도입 파트너인 Cognition은 새 캐시 읽기 가격 덕분에 페이블급 모델을 코드 리뷰 작업에 쓸 수 있게 됐다며 Devin의 Opus 5 트래픽을 공개 당일 페이블 5.1로 옮긴다고 밝혔습니다.

effort라는 설정도 비용에 직접 걸립니다. effort는 컨텍스트나 토큰보다 상대적으로 늦게 생긴 말이라 낯설 수 있습니다. 쉽게 말하면 모델이 얼마나 깊게 생각할지 정하는 값이고, 깊게 생각할수록 토큰을 더 씁니다. 앤트로픽은 페이블 5.1을 낮음이나 중간 effort로 두면 페이블 5와 비슷하거나 더 나은 결과를 훨씬 낮은 비용으로 얻는다고 설명했습니다. 기본값은 제품마다 다릅니다. 클로드 코드는 높음, 클로드 코워크와 claude.ai는 중간입니다.

## 안전장치가 덜 걸리도록 바뀐 부분

오탐(false positive)이라는 말은 안전장치라는 말보다 상대적으로 낯설 수 있습니다. 쉽게 말하면 위험하지 않은 요청을 위험하다고 잘못 판정해 막는 것입니다. 이번 공개에서 앤트로픽이 가장 길게 설명한 것이 이 오탐을 줄인 내용입니다.

그러면 안전장치를 푼 것일까요? 그렇지는 않습니다. 앤트로픽은 진짜 위협을 막는 강도는 유지하면서 위험하지 않은 요청을 덜 막도록 정밀도를 올렸다고 설명했습니다.

- **생물학**: 기초 생물학과 의료 질문처럼 위험하지 않은 요청에 안전장치가 작동하는 빈도가 페이블 5 공개 당시보다 85% 줄었습니다. 다만 생명과학 연구개발 관련 질의는 여전히 Opus 모델로 넘어갑니다.
- **사이버보안**: 오탐 차단이 60% 줄었고, 클로드 코드 사용자는 세션당 안전장치 개입이 평균 약 60% 줄어든다고 앤트로픽은 설명합니다.
- **취약점 작업**: 소프트웨어 취약점을 찾는 작업은 페이블 5.1에서 허용되고, 그 취약점을 쓰는 공격 코드를 만드는 작업은 허용되지 않습니다. 침투 테스트와 공격 코드 생성, 바이너리 기반 취약점 스캔은 Opus 모델로 넘어갑니다.

증류 대응도 함께 들어갔습니다. 증류는 앞선 모델의 능력을 빼내는 방법이고, 앤트로픽은 이것을 안전 문제로 봅니다. 공개일 이후에 만들어진 새 API 계정은 여러 턴 대화에서 클로드의 이전 사고 기록을 남긴 채 앞선 맥락을 직접 고칠 수 없게 바뀌었습니다. 기존 계정은 지금은 영향을 받지 않고, 이후 모델 공개 때 모든 사용자에게 적용됩니다.

기업용으로는 EFS(Enterprise Frontier Safeguards)가 예고됐습니다. 앤트로픽이 아니라 고객이 통제하는 클라우드에 데이터를 두는 방식이고, 2026년 가을부터 단계적으로 열립니다. 그전까지 자격이 되는 고객은 데이터를 남기지 않는 조건으로 페이블 5.1을 씁니다.

## 과학 연구에서 나온 결과 세 가지

앤트로픽은 이번 발표에서 두 모델의 연구 능력을 보여 주는 사례 세 건을 함께 냈습니다.

**단백질 결합체 설계.** 미토스 5.1에 오픈소스 단백질 설계 도구를 붙여 만든 설계를 외부 기관 두 곳이 실험으로 검증했습니다. 세 개 표적에서 Adaptyv Bio 설계 대회에 제출된 최고 설계보다 결합 친화도가 10배 높았고, 12개 표적에서 실제로 결합에 성공한 비율이 50%에 가까웠습니다. 이 분야에서 통상적인 비율은 10%에서 15%입니다.

**금성 고도 지도.** 페이블 5.1이 신경망을 학습시켜 금성의 3분의 1에 해당하는 고해상도 고도 지도를 만들었습니다. 30여 년 전 NASA 마젤란 탐사선이 찍은 레이더 사진과 이미 있던 5분의 1 범위 지도가 재료였습니다. 해상도는 10에서 20킬로미터 수준에서 2에서 3킬로미터로 좁혀졌고, 높이 정확도는 최대 25% 올라갔습니다.

![앤트로픽 발표 페이지의 금성 지도 비교 이미지. 마젤란 레이더 사진, 기존 10에서 20킬로미터 해상도 고도 자료, 새로 만든 300미터 해상도 고도 자료, 금성 표면 화산의 입체 이미지가 나란히 놓여 있다](/images/insights/claude-fable-5-1-mythos-5-1-update/fable-5-1-venus-map.png)

앤트로픽은 이 지도를 크리에이티브 커먼즈 라이선스로 공개했습니다. NASA VERITAS와 ESA EnVision 탐사에 앞서 관측 대상을 고르는 데 쓰이기를 기대한다는 설명이 붙어 있습니다.

**GPU 커널 최적화.** 미토스 5.1이 맞춤 GPU 커널을 작성하고 중간 결과를 저장하는 방식으로 오픈소스 딥러닝 모델 일곱 개를 최대 2.5배 빠르게 만들었습니다. 결과값은 그대로였습니다. 유전체 전체를 훑는 분석에서는 GPU 비용이 30%에서 60% 줄어든다는 추정도 함께 실렸습니다.

## 플랜별 페이블 5.1 이용 조건

페이블 5.1을 쓸 수 있는지는 가입한 플랜에 따라 달라집니다. 앤트로픽 고객센터 문서 기준으로 정리하면 다음과 같습니다.

| 플랜 | 페이블 5.1 이용 | 조건 |
|---|---|---|
| Free | 제공 없음 | 유료 플랜에서만 제공 |
| Pro | 사용량 크레딧 필요 | 플랜 사용 한도에 포함되지 않음 |
| Team 표준 시트 | 사용량 크레딧 필요 | Pro와 같음 |
| Max | 플랜에 포함 | 주간 사용 한도의 50%까지 추가 비용 없음 |
| Team 프리미엄 시트 | 플랜에 포함 | Max와 같음 |

Max 플랜에서 주간 한도의 50%를 다 쓰면 사용량 크레딧으로 이어서 쓰거나 다른 모델로 바꾸면 됩니다. 페이블 5와 페이블 5.1은 플랜에서 같은 조건으로 다뤄집니다.

쓸 수 있는 곳은 웹과 모바일, 데스크톱 앱, Claude Cowork, 클로드 코드, Claude Design, Microsoft 365입니다. API 쪽에서는 Claude API와 Amazon Bedrock, Google Cloud, Microsoft Azure에서 같은 날부터 열렸습니다.

## 클로드 코드에서 페이블 5.1로 바꾸는 방법

### 1단계. 버전 확인과 업데이트

공식 문서 기준으로 페이블 5.1은 클로드 코드 v2.1.255 이상에서 동작합니다. 먼저 지금 버전을 확인합니다.

```bash
claude --version
```

준이아빠블로그를 만드는 데 쓰는 환경에서 2026년 9월 2일에 확인한 값은 아래와 같았습니다.

```
2.1.258 (Claude Code)
```

기준인 v2.1.255보다 높으므로 업데이트하지 않아도 됩니다. 버전이 낮으면 업데이트합니다.

```bash
claude update
```

### 2단계. 모델 전환

터미널에서 클로드 코드를 실행한 뒤 모델을 바꿉니다. 별칭 `fable`은 가장 최신 페이블 모델을 가리킵니다.

```bash
/model fable
```

세션을 시작할 때 지정하는 방법도 있습니다.

```bash
claude --model fable
```

`/model`만 입력하면 선택 화면이 열립니다. 여기서 Enter를 누르면 기본 모델로 저장되고, `s`를 누르면 이번 세션에만 적용됩니다.

### 3단계. effort 확인

페이블 5.1은 클로드 코드에서 기본값이 높음(high)입니다. 비용을 줄이려면 낮춰서 시작해 보는 방법이 있습니다.

```bash
/effort medium
```

쓸 수 있는 값은 낮음(low), 중간(medium), 높음(high), 매우 높음(xhigh), 최대(max)입니다. `/effort`만 입력하면 조절 화면이 열립니다.

## 자주 묻는 질문

### 페이블 5.1과 미토스 5.1은 무엇이 다를까요?

성능이 아니라 안전장치가 다릅니다. 앤트로픽은 두 모델이 같은 모델이며 안전장치 수준만 다르다고 밝혔습니다. 페이블 5.1은 누구나 쓸 수 있고, 미토스 5.1은 사이버 방어와 생명과학 분야의 검증 프로그램을 거친 기관에만 열립니다. 2026년 9월 기준으로 미국 기관만 대상이고, 앤트로픽은 미국 정부와 협의해 범위를 넓히겠다고 밝혔습니다.

### Pro 플랜에서도 페이블 5.1을 쓸 수 있나요?

쓸 수 있지만 플랜 사용 한도에는 포함되지 않습니다. Pro 플랜과 팀 표준 시트에서는 사용량 크레딧을 따로 결제해야 합니다. 플랜에 포함되는 것은 Max 플랜과 팀 프리미엄 시트이고, 이때도 추가 비용 없이 쓰는 범위는 주간 사용 한도의 50%까지입니다.

### 페이블 5로 쓰던 코드에서 모델 이름만 바꾸면 되나요?

API에서는 모델 ID를 `claude-fable-5-1`로 바꾸면 됩니다. 가격 항목 가운데 캐시 읽기만 달라지므로 요금 계산 코드가 있다면 그 값을 함께 고칩니다. 다만 공개일 이후에 만든 새 API 계정은 여러 턴 대화에서 클로드의 이전 사고 기록을 남긴 채 앞선 맥락을 고치는 방식이 막혔으므로, 그 방식을 쓰는 연동이 있으면 확인이 필요합니다.

## 3줄 요약

- 클로드 페이블 5.1은 앤트로픽이 2026년 9월 1일 공개한 코딩과 지식 업무용 상위 모델이고, 미토스 5.1은 같은 모델에서 안전장치를 완화해 검증된 기관에만 여는 판입니다.
- 입력 100만 토큰당 10달러와 출력 50달러는 그대로이고 캐시 읽기만 1달러에서 0.25달러로 내려, 일반 작업은 약 25%, 에이전트 작업은 최대 약 45% 비용이 줄어듭니다.
- Max 플랜과 팀 프리미엄 시트는 주간 사용 한도의 50%까지 포함되고, Pro와 팀 표준 시트는 사용량 크레딧을 따로 써야 합니다.
