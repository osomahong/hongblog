준이아빠블로그는 개설한 지 고작 6개월 만에 평균 게재순위 6위, 평균 클릭률 4.6%를 기록하고 있고, 전체 방문의 86.63%가 자연 검색으로 들어옵니다. 광고 없이 오로지 자연 검색 노출만으로 쌓은 2026년 8월 기준 실측 SEO 성과입니다.

![서치 콘솔 6개월 성과 화면. 클릭수와 노출수 그래프가 개설 초기의 바닥에서 최근으로 올수록 가파르게 상승하는 곡선을 그리고 있다. 절대 수치는 모자이크 처리했고 평균 CTR 4.6%와 평균 게재순위 6이 표시되어 있다](/images/insights/seo-title-creator-guide/gsc-6months-growth.webp)

![GA4 트래픽 획득 보고서 화면. 채널별 세션 그래프가 상승 곡선을 그리고 있고 Organic Search가 전체 세션의 86.63%를 차지한다. 상세 수치는 모자이크 처리했고 비율만 표시되어 있다](/images/insights/seo-title-creator-guide/ga4-organic-ratio.webp)

이 성과의 출발점은 제목입니다. 모든 글의 제목을 감이 아니라 측정으로 정했습니다. 발행 전에 구글과 네이버의 실제 검색 쿼리량과 검색 결과 상위 점유를 조회하고, 그 숫자를 근거로 제목과 목표 검색어를 골랐습니다. 이 과정을 스킬 하나로 묶어 공개한 것이 seo-title-creator입니다. 측정한 근거로 제목을 추천하는 클로드 코드 스킬로, 제목이 필요한 글 내용 전체 또는 핵심 내용을 주면 서치 콘솔, 네이버 검색광고 키워드도구, 실제 검색 결과 세 가지 데이터를 읽고 제목 후보 3개를 각각의 근거와 약점까지 붙여서 제안합니다. [깃허브에 공개](https://github.com/osomahong/seo-title-creator)해 두었고 MIT 라이선스라 누구나 쓸 수 있습니다. CLI를 사용하는 분들이라면 설치는 터미널에서 한 줄이면 끝나고, CLI를 쓰지 않는 분들을 위한 내려받기 방법도 아래 설치 부분에 함께 정리했습니다.

```bash
npx skills add osomahong/seo-title-creator
```

지금부터 seo-title-creator가 어떤 원리로 작동하는지, 이 방식으로 운영한 준이아빠블로그가 어떤 결과를 얻었는지, 어떻게 설치해서 쓰는지를 정리합니다.

![깃허브에 공개된 seo-title-creator 저장소 화면. 근거가 붙은 제목 후보 3개를 추천하고 서치 콘솔 데이터 없이는 추천하지 않는다는 소개가 적혀 있다](/images/insights/seo-title-creator-guide/01-github-repo.png)

## 제목을 감으로 정할 때 놓치는 것: 표기 변형

> 같은 제품을 찾는 검색어여도 구글 애널리틱스, 구글애널리틱스, Google Analytics, GA4 네 가지로 나뉩니다.

한국어 검색의 특징입니다. 사람마다 띄어쓰기가 다르고, 영문으로 치는 사람과 약어로 치는 사람이 따로 있습니다. 검색엔진이 유의어를 어느 정도 연결해 주지만, 유명 브랜드가 아니면 그 연결성은 약합니다. 제목에 어떤 표기를 올리는지에 따라 잡히는 검색어가 달라지는데, 감으로 정한 제목은 이 차이를 인식하지 못한 채 하나를 고르게 됩니다.

실제 사례가 준이아빠블로그의 GEO 가이드 글입니다. 제목 후보에 올랐던 세 표기의 네이버 월간 검색량을 조회하면 이렇게 나옵니다.

```
키워드      | 월간합계 | 경쟁정도
GEO마케팅   |     550 | 높음
GEO최적화   |     220 | 낮음
GEO전략     |      15 | 높음
```

스킬로 확인해 보면 세 가지 표기별로 검색량이 30배 넘게 차이 납니다. 조회에 걸리는 시간은 몇 초입니다. 이 숫자를 알고 제목을 정하는 것과 모르고 정하는 것은 다른 일입니다.

## 작동 원리: 세 가지 데이터와 거부 규칙

> seo-title-creator의 핵심 규칙은 측정한 데이터로만 추천한다는 것입니다.

스킬이 읽는 데이터는 세 가지입니다.

| 데이터 | 확인하는 것 | 필수 여부 |
|---|---|---|
| 구글 서치 콘솔 | 이 사이트가 지금 어떤 검색어에서 몇 위에 있는지 | 항상 필수 |
| 네이버 검색광고 키워드도구 | 표기 변형별 월간 검색량과 경쟁 정도 | 한국어 제목에 필수 |
| 실제 검색 결과 (SERP) | 그 검색어의 상위를 누가 차지하고 있는지 | 권장 (SerpApi 선택) |

제목 하나에 왜 세 종류의 데이터가 필요할까요? 각각 답하는 질문이 다르기 때문입니다. 네이버 검색량으로는 수요가 있는지, 검색 결과 상위 점유로는 그 검색어에서 이길 수 있는지, 서치 콘솔로는 이 사이트가 이미 그 검색어 근처에서 노출을 받고 있는지를 확인합니다. 셋 중 하나만 보면 수요는 있지만 이기기 어려운 검색어와, 이길 수 있지만 수요가 없는 검색어를 구분하지 못합니다.

> 필수 데이터가 없으면 이 스킬은 제목 후보를 하나도 만들지 않습니다.

왜 자격증명이 없으면 아예 멈추게 만들었을까요? 부분 데이터로 만든 추천이 바로 이 스킬이 막으려는 문제이기 때문입니다. 근거 형식을 갖춘 추천은 측정된 것처럼 읽힙니다. 추정 숫자가 측정치의 모양을 하고 나오면, 받아 본 사람은 그 숫자를 믿고 움직입니다. 그래서 서치 콘솔이 연결되어 있지 않으면 스킬은 무엇이 없는지 알리고, 설정 절차를 안내하고, 멈춥니다. 거부가 기본 동작입니다.

## 후보 3개에 근거와 약점이 붙는 이유

> 제목 후보는 항상 3개이고, 후보마다 목표 검색어와 근거, 약점이 함께 붙습니다.

후보 3개는 서로 다른 패턴으로 만들어집니다. 검색창에 치는 문제 상황을 그대로 제목에 올리는 상황형, 주제와 동작을 앞세우는 주제형, 특정 도구나 조건으로 범위를 좁히는 한정형입니다. 패턴을 나눠 두는 이유는 세 후보가 비슷한 제목으로 몰리는 것을 막기 위해서입니다.

검색 결과 상위를 누가 차지했는지에 따라 판정도 달라집니다.

> 커뮤니티 질문 글이 검색 상위에 있으면 그 검색어는 기회입니다.

질문 글이 상위에 있다는 것은 두 가지를 동시에 증명합니다. 그 질문을 하는 사람이 있고, 정리된 답은 아직 없다는 사실입니다. 반대로 공식 문서가 상위를 채우고 있으면 이기기 어려운 검색어로 판정되어 후보에서 빠집니다.

마지막으로 자기잠식 검사를 합니다. 후보 검색어를 이미 잡고 있는 내 글이 있으면 그 후보는 버립니다. 같은 검색어를 두 글이 나눠 잡으면 합쳐진 노출이 늘지 않고 오히려 줄어들기 때문입니다.

이미 발행한 글의 제목도 바꿀 수 있을까요? 스킬의 트리거 중 하나가 정확히 그 경우입니다. 노출이 나오지 않는 기존 글의 제목을 다시 정할 때도 같은 과정이 적용됩니다. 준이아빠블로그도 GEO 가이드 글의 제목과 메타 타이틀이 서로 달랐던 것을 발견하고, 위의 검색량 실측을 근거로 "GEO 최적화" 표기 기준으로 통일했습니다.

## 준이아빠블로그가 얻은 결과

도입부의 누적 그래프를 개별 검색어로 나눠 보면 더 분명해집니다. 준이아빠블로그는 "opus 5 업데이트" 검색에서 공식 문서보다 위인 1위, "메타 mcp" 검색에서 공식 문서 다음인 2위에 노출되어 있습니다. (여러분도 직접 검색해 보세요)

![구글에서 opus 5 업데이트를 검색한 결과 화면. 준이아빠블로그의 Claude Opus 5 업데이트 정리 글이 공식 플랫폼 문서보다 위인 1위에 노출되어 있다](/images/insights/seo-title-creator-guide/serp-opus5-update.webp)

![구글에서 메타 mcp를 검색한 결과 화면. AI 개요 아래 자연 검색 결과에서 준이아빠블로그의 META MCP 글이 공식 문서 다음인 2위에 노출되어 있다](/images/insights/seo-title-creator-guide/serp-meta-mcp.webp)

두 검색어만이 아닙니다. "제미나이 스파크", "GPT 5.6 모델", "orca" 같은 검색어에서도 자연 검색 기준 1위에 노출됩니다. 모두 발행 전에 표기 변형별 검색량과 상위 점유를 확인하고 제목을 정한 글입니다.

검색 순위 바깥의 자리도 잡히기 시작했습니다. 검색이 내놓는 답변에 출처로 뽑히는 [AEO(답변 엔진 최적화)](/class/digital-marketing-terms/what-is-aeo)의 자리입니다. "구글애즈 mcp" 검색에서는 검색 결과 맨 위에 뜨는 구글 AI 개요의 출처로 준이아빠블로그의 글이 인용됩니다. AI 개요 상단의 출처 아이콘에 준이아빠블로그의 캐릭터 썸네일이 들어가 있고, 아래 출처 카드에도 구글 공식 문서와 나란히 올라가 있습니다. 검색 순위(SEO)와 답변 인용(AEO)을 한 화면에서 확인할 수 있는 사례입니다.

![구글에서 구글애즈 mcp를 검색한 결과의 AI 개요 화면. 검색어, AI 개요 상단의 출처 아이콘 속 준이아빠블로그 캐릭터 썸네일, 하단 출처 카드의 준이아빠블로그 글 세 곳을 빨간 박스로 표시했다](/images/insights/seo-title-creator-guide/aeo-googleads-mcp-citation.webp)

물론 이 결과가 제목만의 성과는 아닙니다. 본문의 품질, 내부 링크, 기술적 SEO가 함께 작용했습니다. 다만 그 모든 작업의 시작이 제목과 목표 검색어 선정이었습니다.

같은 과정을 내 블로그에 적용해 보고 싶다면 지금 터미널에서 한 줄이면 시작됩니다.

```bash
npx skills add osomahong/seo-title-creator
```

## 설치와 사용법

클로드 코드가 설치되어 있다면 세 단계면 됩니다.

**1. 스킬 설치 (한 줄)**

```bash
npx skills add osomahong/seo-title-creator
```

오픈 에이전트 스킬 생태계의 표준 설치 명령입니다. 현재 프로젝트에 설치되고, `-g`를 붙이면 모든 프로젝트에서 쓸 수 있게 전역 설치됩니다. 클로드 코드뿐 아니라 Cursor, Codex, Gemini CLI 같은 다른 코딩 에이전트도 같은 명령을 지원합니다.

CLI가 익숙하지 않다면 [깃허브 저장소](https://github.com/osomahong/seo-title-creator)에서 직접 받아도 됩니다. 초록색 Code 버튼에서 Download ZIP으로 내려받아 `~/.claude/skills/seo-title-creator` 폴더에 풀어 넣거나, `git clone https://github.com/osomahong/seo-title-creator.git ~/.claude/skills/seo-title-creator`로 받아도 같은 상태로 설치됩니다.

**2. 데이터 소스 연결**

```bash
node ~/.claude/skills/seo-title-creator/scripts/check-setup.mjs
```

점검 스크립트가 연결 상태를 알려 줍니다. 서치 콘솔은 필수이고, 한국어 제목을 다루면 네이버 검색광고 키워드도구(가입 무료, 심사 없음)도 필수입니다. SerpApi는 선택이고 무료 티어(월 250건)로 충분합니다. 각각의 발급 절차는 스킬 안의 안내 문서(`references/setup-*.md`)에 화면 단위로 정리되어 있습니다.

**3. 실행**

```bash
/seo-title-creator content/insights/my-post.md
```

파일 경로를 줘도 되고, 본문을 붙여 넣어도 되고, 한 줄 주제만 줘도 됩니다. 결과는 항상 같은 형식입니다. 후보 3개, 후보마다 목표 검색어와 네이버 검색량, 상위 점유 성격, 이 사이트의 현재 순위, 그리고 약점이 붙고, 마지막에 어느 것을 권하는지 한 문단으로 끝납니다.

SerpApi가 없으면 못 쓸까요? 쓸 수 있습니다. 상위 점유 확인은 내장 웹 검색으로 대체되고, 그 경우 순위가 근사값이라는 표시가 보고서에 남습니다. 확인하지 못한 데이터를 확인한 것처럼 쓰지 않는 원칙이 여기에도 적용됩니다.

## 쓰기 전에 알아 둘 제약

이 스킬은 데이터를 직접 조회하는 도구라서, 쓰는 사람이 API 키를 반드시 직접 발급해서 제공해야 합니다. 무료로 시작할 수 있지만 각 소스에 제약이 있습니다.

| 항목 | 비용 | 제약 |
|---|---|---|
| 서치 콘솔 API | 무료 | 서비스 계정 발급과 속성 사용자 추가 과정이 필요합니다 (문서에 절차 안내) |
| 네이버 검색광고 API | 무료 | 네이버 검색광고 가입이 필요합니다. 힌트 키워드는 한 번에 5개까지입니다 |
| SerpApi | 무료 티어 | 월 250건 쿼리 제한이 있습니다. 넘어서면 유료 플랜이 필요합니다 |

발급한 키는 전부 내 컴퓨터의 환경 파일(홈 디렉터리의 `.seo-title-advisor.env` 또는 프로젝트의 `.env`)에만 저장되고, 각 공식 API를 호출할 때만 사용됩니다. 스킬 코드에 키를 적는 방식이 아니므로 저장소를 공개해도 키가 함께 올라가지 않습니다. 단, 키 파일을 내 프로젝트 저장소에 둘 때는 `.gitignore`에 `.env`가 들어 있는지 한 번 확인하는 편이 안전합니다.

## 정리

제목은 글에서 가장 적은 글자로 가장 큰 차이를 만드는 부분입니다. seo-title-creator는 제목을 정하는 데 필요한 조회를 대신 돌리고, 근거와 약점이 붙은 후보 3개로 정리해 주는 스킬입니다. 감으로 정한 제목이 틀렸다는 이야기가 아니라, 몇 초면 확인할 수 있는 숫자를 확인하고 정하자는 이야기에 가깝습니다.

```bash
npx skills add osomahong/seo-title-creator
```

써 보고 도움이 됐다면 [깃허브 저장소](https://github.com/osomahong/seo-title-creator)에 스타(⭐)를 눌러 주세요. 스킬이 더 많은 분에게 닿는 데 스타 하나가 큰 힘이 됩니다. 개선 아이디어나 문제 제보는 저장소 이슈로 남겨 주시면 반영하겠습니다.
