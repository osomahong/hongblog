클로드 데스크톱 앱(Claude Desktop)은 앤트로픽이 맥과 윈도우, 리눅스용으로 내놓은 설치형 프로그램입니다. 창 하나에 채팅과 코워크(Cowork), 코드(Code) 탭 세 개가 놓여 있고, 그중 채팅 탭은 브라우저에서 쓰던 화면과 같습니다.

클로드를 한 번쯤 써 본 분에게 브라우저에서 claude.ai에 접속해 질문을 넣고 답을 받는 흐름은 이미 익숙합니다. 맥에서도 사파리나 크롬을 열면 그만이라, 프로그램을 따로 설치해야 하는 이유가 떠오르지 않을 수 있습니다.

덜 알려진 것은 설치형 앱에만 열리는 기능이 따로 있다는 점입니다. 내 컴퓨터의 폴더를 직접 읽고 쓰거나, 보고 있는 화면을 그대로 넘기거나, 맥에 깔린 다른 프로그램에 연결하는 작업은 브라우저판으로 대신하기 어렵습니다. 이 차이를 모르고 앱을 설치하면 브라우저에서 하던 대화를 창만 바꿔 반복하게 됩니다. 아래 내용은 2026년 9월 15일에 앤트로픽 공식 다운로드 페이지와 고객센터 문서에서 확인한 것입니다.

2026년 9월 15일에 확인한 claude.com/download 화면입니다. 제목 아래에 채팅과 코워크, 코드를 한곳에 모았다고 적혀 있고, 맥에서 접속하면 macOS용 내려받기 버튼이 먼저 뜹니다. 아래쪽 카드에는 macOS와 윈도우가 따로 나뉘어 있습니다.

## 클로드 데스크톱 앱과 클로드 코드는 다른 제품입니다

맥에서 클로드를 검색하면 이름이 비슷한 두 가지가 함께 나옵니다. 하나는 이 글에서 다루는 설치형 데스크톱 앱이고, 다른 하나는 터미널에 명령을 입력해 쓰는 클로드 코드(Claude Code) CLI, 즉 명령줄 도구입니다. 이름이 겹쳐서 설치 방법을 찾다가 엉뚱한 안내를 따라가기 쉽습니다.

| 항목 | 클로드 데스크톱 앱 | 터미널용 클로드 코드 CLI |
|---|---|---|
| 설치 방법 | 다운로드 페이지에서 받아 응용 프로그램 폴더로 옮김 | 터미널에서 설치 명령을 실행 |
| 쓰는 화면 | 창과 탭, 버튼 | 검은 터미널 화면 |
| 맥 요구 사양 | macOS 11 이상 | macOS 13 이상 |
| 주로 맡기는 일 | 대화, 자료 정리, 문서 작성, 코딩 | 코딩과 자동화 |
| 무료 플랜 | 채팅 탭은 열림 | 쓸 수 없음 |

여기서 헷갈리기 쉬운 지점을 하나 짚고 가겠습니다. 데스크톱 앱 안에도 코드 탭이 있어서, 터미널을 열지 않고 클로드 코드를 쓸 수 있습니다. 공식 문서는 데스크톱 앱에 클로드 코드가 들어 있어 Node.js나 CLI를 따로 설치하지 않아도 된다고 안내합니다. 다만 터미널에서 `claude` 명령으로 실행하려면 CLI는 따로 설치해야 합니다.

터미널 쪽을 찾아오셨다면 [쉽게 설치하는 클로드코드 세팅가이드(맥)](/insights/claude-code-mac-easy-setup-guide)에 아홉 단계로 정리해 두었습니다. 이 글은 설치형 앱만 다룹니다.

## 맥에 설치하는 순서

공식 고객센터가 안내하는 설치 순서는 다섯 단계입니다.

1. 클로드 다운로드 페이지에 접속합니다.
2. 쓰는 운영체제에 맞는 버전을 고릅니다.
3. 받은 파일을 열어 설치를 끝냅니다.
4. 응용 프로그램 폴더에서 클로드를 실행합니다.
5. 계정으로 로그인합니다.

맥용 설치 파일은 유니버설 빌드, 즉 두 종류의 프로세서에서 모두 동작하는 파일 하나로 제공됩니다. 애플 실리콘(M 시리즈) 맥과 인텔 맥에서 같은 파일을 내려받으면 됩니다. 사전에 설치할 도구는 없고, 로그인에는 평소 claude.ai에서 쓰던 계정을 그대로 씁니다.

## 요금제별로 열리는 기능

![앤트로픽 고객센터의 클로드 데스크톱 설치 문서 화면. 요금제별 제공 기능 표에서 채팅은 무료를 포함한 다섯 요금제에 표시되어 있고 클로드 코드와 클로드 코워크는 Pro 이상에만 표시되어 있다. 표 아래에는 macOS 11 이상이라는 시스템 요구 사항이 적혀 있다](/images/insights/claude-desktop-mac-guide/02-plan-and-requirements.png)

앱은 무료 계정으로도 설치하고 로그인할 수 있습니다. 다만 탭마다 조건이 다릅니다. 2026년 8월 7일자 고객센터 문서의 표를 옮기면 다음과 같습니다.

| 탭 | 무료 | Pro, Max, Team, Enterprise |
|---|---|---|
| 채팅 | 열림 | 열림 |
| 코드 | 열리지 않음 | 열림 |
| 코워크 | 열리지 않음 | 열림 |

같은 문서에 적힌 시스템 요구 사항은 맥이 macOS 11(빅서) 이상이고, 윈도우는 10 이상, 리눅스는 우분투 22.04 LTS 이상이나 데비안 12 이상입니다.

맥에만 있는 기능 두 가지는 요구 사양이 조금 더 높습니다. 다음 절에서 다룰 빠른 입력은 macOS 12 이상, 음성 받아쓰기는 macOS 14 이상이 필요합니다. 오래된 맥이라면 앱은 설치되어도 이 두 가지가 보이지 않을 수 있습니다.

## 데스크톱 앱에서만 되는 것

창문 너머로 물건을 하나씩 건네받는 쪽과 현관 열쇠를 받아 지정한 방에 들어가는 쪽이 다르듯, 브라우저판 클로드는 올려 준 파일만 보고 데스크톱 앱은 연결한 폴더를 직접 읽고 씁니다. 설치형 앱을 쓰는 이유는 대부분 이 차이에서 나옵니다.

### 빠른 입력과 화면 공유

빠른 입력(quick entry)은 다른 앱을 쓰던 중에 클로드 창을 바로 띄우는 기능입니다. 서랍을 열지 않고 책상 위 메모지에 바로 적듯, 보던 화면을 닫지 않은 채 질문을 넣습니다. 공식 안내에 적힌 조작은 세 가지입니다.

- **여는 방법**: Option 키를 두 번 누릅니다. 설정에서 Option + Space나 직접 정한 단축키로 바꿀 수 있습니다.
- **화면 넘기기**: 화면의 일부를 끌어 캡처하거나, 앱 창을 눌러 그대로 첨부합니다.
- **말로 넣기**: Caps Lock을 누르면 음성 받아쓰기가 시작됩니다.

지금 보고 있는 오류 메시지나 표를 말로 설명하는 대신 그대로 넘길 수 있어서, 브라우저판에서 캡처 파일을 저장하고 다시 올리던 두 단계가 줄어듭니다.

### 로컬 파일을 직접 다루는 코워크

코워크(Cowork)라는 이름은 채팅보다 상대적으로 낯설 수 있습니다. 쉽게 말하면 여러 단계로 이어지는 일을 맡겨 두고 다른 일을 하는 작업용 탭입니다. 공식 안내에 적힌 범위는 다음과 같습니다.

- 연결한 폴더의 파일을 올리지 않고 직접 읽고 씁니다
- 자료 조사와 파일 정리, 문서 작성처럼 오래 걸리는 일을 맡습니다
- 코드를 실행할 때는 격리된 가상 머신을 쓰고, 내 컴퓨터에서 여는 세션이면 그 가상 머신도 컴퓨터 안에 만들어집니다

열쇠를 건넨 방만 열리듯, 코워크가 읽고 쓰는 범위도 연결한 폴더로 제한됩니다. 바깥으로 나가는 네트워크 접근도 정해진 규칙을 따릅니다. 폴더를 연결하기 전에 그 안에 외부로 내보낼 수 없는 파일이 섞여 있는지 확인하는 편이 안전합니다.

### 맥 안의 프로그램에 연결하는 데스크톱 확장

커넥터(Connector)는 클로드를 외부 서비스나 프로그램에 잇는 연결 통로입니다. 종류가 둘로 나뉘고, 쓸 수 있는 화면도 서로 다릅니다.

| 종류 | 연결 대상 | 쓸 수 있는 화면 |
|---|---|---|
| 원격 커넥터 | 슬랙, 노션, 깃허브 같은 클라우드 서비스 | 웹, 모바일, 코워크, 데스크톱 앱, 클로드 코드 |
| 데스크톱 확장 | 맥 안의 파일과 클립보드, 내 컴퓨터에서 도는 프로그램 | 데스크톱 앱과 클로드 코드 |

콘센트에 기기를 꽂듯, 데스크톱 확장도 설정의 확장 메뉴에서 한 번 누르면 연결됩니다. 앤트로픽은 이 확장이 민감한 정보를 운영체제의 키체인에 두고, 기업에서는 관리자가 허용할 확장을 미리 정할 수 있다고 설명합니다. 로컬 프로그램을 다루는 기능이라 웹과 모바일에서는 동작하지 않습니다.

무료 플랜에는 제한이 하나 있습니다. 고객센터 안내에 따르면 무료 계정이 직접 주소를 넣어 추가하는 커스텀 커넥터는 한 개까지입니다.

## 브라우저판과 달라지는 지점

| 하려는 일 | 브라우저판 | 맥 데스크톱 앱 |
|---|---|---|
| 대화와 파일 업로드 | 됨 | 됨 |
| 원격 커넥터 연결 | 됨 | 됨 |
| 내 폴더를 올리지 않고 읽고 쓰기 | 되지 않음 | 됨 |
| 맥 안의 프로그램에 연결 | 되지 않음 | 됨 |
| 화면 캡처와 앱 창 첨부 | 되지 않음 | 됨 |
| 클로드가 화면을 눌러 조작 | 되지 않음 | 됨 |

마지막 항목은 공식 문서에 컴퓨터 사용(computer use)이라는 이름으로 나옵니다. 클로드가 화면의 버튼을 직접 누르고 글자를 입력하며 화면 사이를 옮겨 다니는 기능입니다. 웹과 모바일에는 이 기능이 없고, 2026년 9월 15일 기준 베타 단계라 Pro와 Max 플랜에서만 열립니다.

웹에서 연 코워크 세션이 내 컴퓨터의 파일에 닿으려면 그 컴퓨터에서 데스크톱 앱이 켜져 있어야 합니다. 브라우저에서 시작한 작업이라도 열쇠를 쥔 쪽은 설치한 앱입니다.

## 브라우저를 쓰던 분들이 앱을 설치할 이유가 있나요?

> **올린 파일로 끝나는 일이면 브라우저판으로 충분하고, 내 컴퓨터의 폴더나 프로그램이 대상이면 데스크톱 앱이 필요합니다.**

매달 같은 폴더에 쌓이는 광고 리포트 파일을 정리하는 작업을 예로 들어 설명하겠습니다. 브라우저판에서는 파일을 올리고 결과를 내려받아 폴더에 다시 넣는 순서를 매번 반복합니다. 데스크톱 앱에서는 그 폴더를 한 번 연결해 두면 읽고 쓰는 일이 같은 폴더 안에서 끝납니다. 처리할 파일이 많을수록 차이가 커집니다.

반대로 외부 자료를 찾아 초안을 쓰거나 문장을 다듬는 작업이라면 두 화면의 결과가 크게 다르지 않습니다. 이때는 익숙한 브라우저를 그대로 쓰고, 내 컴퓨터의 파일을 다뤄야 할 때만 앱을 여는 방식도 괜찮습니다.

## 공식 문서에서 확인하지 못한 것

기능과 요금 조건은 시간이 지나면 달라지므로, 공식 페이지에서 확인되지 않은 항목은 여기에 적지 않았습니다. 뺀 내용은 세 가지입니다.

- **맥 앱의 자동 갱신 방식**: 리눅스판은 앱이 스스로 갱신하지 않는다고 문서에 적혀 있지만, 맥의 갱신 주기를 밝힌 안내는 확인하지 못했습니다.
- **맥의 여유 공간과 메모리 요구치**: 리눅스에서 코워크를 쓸 때 필요한 용량은 문서에 수치로 적혀 있는데, 맥 기준 수치는 같은 문서에 없습니다.
- **앱 화면의 한국어 표시 범위**: 화면 언어 설정을 다룬 공식 안내를 찾지 못했습니다.

## 자주 묻는 질문

### 맥 몇 버전부터 클로드 데스크톱 앱을 설치할 수 있나요?

macOS 11(빅서) 이상이면 설치됩니다. 다만 Option 키를 두 번 눌러 여는 빠른 입력은 macOS 12 이상, 음성 받아쓰기는 macOS 14 이상에서 동작합니다. 애플 실리콘 맥과 인텔 맥은 같은 설치 파일을 씁니다.

### 무료 플랜으로도 데스크톱 앱을 쓸 수 있나요?

채팅 탭은 무료 플랜에서도 열립니다. 코드와 코워크는 Pro, Max, Team, Enterprise 가운데 하나가 있어야 합니다. 직접 주소를 넣어 추가하는 커스텀 커넥터는 무료 계정도 한 개까지입니다.

### 클로드 코드 CLI를 이미 쓰고 있는데 데스크톱 앱도 설치해야 하나요?

둘 가운데 하나만 써도 됩니다. 터미널 명령과 스크립트가 편하다면 CLI만으로 충분하고, 화면을 나눠 보거나 채팅과 코워크를 같은 창에서 쓰고 싶다면 앱을 더합니다. 데스크톱 앱에는 클로드 코드가 들어 있어서 앱만 설치해도 코드 탭을 쓸 수 있습니다.

## 3줄 요약

1. **클로드 데스크톱 앱은 앤트로픽이 맥과 윈도우, 리눅스용으로 내놓은 설치형 프로그램입니다.** 채팅과 코워크, 코드가 창 하나에 탭 세 개로 놓여 있고, 터미널에 명령을 입력하는 클로드 코드 CLI와는 다른 제품입니다.
2. **맥 요구 사양은 macOS 11 이상입니다.** Option 키를 두 번 눌러 여는 빠른 입력은 macOS 12 이상, 음성 받아쓰기는 macOS 14 이상을 요구하고, 설치 파일은 애플 실리콘과 인텔 맥에 같은 것을 씁니다.
3. **무료 플랜에서는 채팅만 열리고 코드와 코워크는 Pro 이상이 필요합니다.** 데스크톱 확장과 컴퓨터 사용은 브라우저판에 없으므로, 내 컴퓨터의 폴더나 프로그램이 대상인 작업이면 앱을 설치하는 편이 낫습니다.
