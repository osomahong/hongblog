"클로드 코드(Claude Code)가 좋다는데, CLI에서만 된다고?" 여기서 막히는 분들이 많습니다.

CLI라는 단어 자체가 낯설고, 검색해서 나오는 화면을 보면 **검은 배경에 흰 글씨만 가득한 창**이 나옵니다. 영화에서 해커들이 키보드를 빠르게 두드리며 시스템에 침투하는 장면, 그 화면이 떠오르죠. "저건 개발자나 쓰는 거 아냐?"라는 생각이 드는 게 당연합니다.
![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112207530-kuo3qh.png)

하지만 실제로 써보면 생각보다 별거 아닙니다. 그리고 오히려 **웹 채팅보다 CLI가 더 좋은 이유**도 있습니다. 이 글에서 CLI가 뭔지, 왜 두려워할 필요가 없는지, 그리고 클로드 코드를 CLI 말고 다른 방법으로도 쓸 수 있는지까지 정리하겠습니다.

## CLI가 뭔가요?

CLI는 **Command Line Interface**의 약자입니다. 한국어로 하면 "명령줄 인터페이스" 정도 됩니다.

우리가 평소 컴퓨터를 쓸 때는 **마우스로 아이콘을 클릭하고, 버튼을 누르고, 창을 드래그**합니다. 이런 방식을 GUI(Graphic User Interface)라고 부릅니다. 눈에 보이는 그래픽 요소를 통해 조작하는 방식입니다.

CLI는 반대입니다. **키보드로 명령어를 직접 타이핑해서 컴퓨터를 조작하는 방식**입니다. 마우스 클릭 대신 텍스트 명령어를 쓰는 겁니다.

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112884167-2bkyq1.png)

예를 들어, 바탕화면에 있는 파일 목록을 보고 싶다면 이렇게 차이가 납니다.

| 방식 | 하는 일 |
|---|---|
| GUI | 바탕화면 폴더를 더블클릭해서 파일 목록을 눈으로 확인 |
| CLI | 터미널에 `ls ~/Desktop` 이라고 입력하면 파일 목록이 텍스트로 출력 |

결과는 같습니다. 접근 방식만 다를 뿐입니다.

## "해킹 장면"은 맞는데 사실 별건 아닙니다.

영화 속 해커들이 사용하는 그 검은 화면, 맞습니다. 그게 **터미널(Terminal)**이고, 그 안에서 명령어를 입력하는 방식이 CLI입니다.

하지만 영화에서는 해킹이라는 극적인 상황에서 보여주기 때문에 어렵고 위험해 보이는 거지, 실제 터미널은 **그냥 텍스트로 대화하는 창**입니다.

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112294389-ra45on.png)


사실 여러분이 이미 쓰고 있는 것 중에서도 CLI와 비슷한 경험이 있습니다.

- **검색창에 검색어를 입력하고 엔터** : 명령어 대신 검색어를 쓰는 것일 뿐, 구조는 같습니다
- **Claude.ai 웹 채팅에서 질문을 입력하고 전송** : 이것도 텍스트 입력 → 결과 출력의 CLI와 동일한 패턴입니다

CLI는 버튼과 메뉴가 없을 뿐, **"내가 텍스트를 입력하면 컴퓨터가 텍스트로 응답한다"는 단순한 구조**입니다.

## 클로드 코드(Claude Code)에서의 CLI

클로드 코드는 Anthropic이 만든 **터미널 기반 AI 코딩 도구**입니다. Claude.ai가 브라우저에서 쓰는 웹 챗봇이라면, 클로드 코드는 터미널에서 쓰는 AI입니다.

사용 방식은 놀랍도록 단순합니다.

1. 터미널을 엽니다
2. `claude` 라고 입력합니다
3. AI와 대화를 시작합니다

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112380536-s31k4t.png)

그 이후부터는 **Claude.ai 웹 채팅과 거의 같습니다.** 한국어로 질문하면 한국어로 답변합니다. "이 코드 수정해줘", "새 파일 만들어줘", "이 에러 고쳐줘" 같은 요청을 텍스트로 입력하면 AI가 실행합니다.

차이점이 있다면, 웹 채팅에서는 AI가 **답변만** 해주지만, 클로드 코드에서는 AI가 **직접 파일을 편집하고, 명령어를 실행하고, 코드를 수정**합니다. 답변을 복사해서 붙여넣을 필요가 없습니다.

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112419461-s7ubqx.png)

## 웹 채팅보다 CLI가 오히려 더 좋은 이유

"익숙한 웹에서 쓰면 되지, 왜 굳이 CLI를 써야 하나요?"

당연한 질문입니다. 하지만 CLI에는 웹 채팅에서는 불가능한 실질적인 장점이 있습니다.

### 1. 입력/출력 길이 제한이 사실상 없습니다

Claude.ai 웹에서는 한 번에 보낼 수 있는 메시지 길이에 제한이 있습니다. 긴 코드를 붙여넣으면 잘리거나, 응답이 중간에 끊기는 경우가 생기죠.

클로드 코드는 다릅니다. **프로젝트 전체 코드를 읽고, 수십 개의 파일을 한꺼번에 수정하고, 긴 응답도 끊김 없이 출력**합니다. 웹에서 "계속 써줘"를 반복할 필요가 없습니다.

| 항목 | Claude.ai 웹 | Claude Code (CLI) |
|---|---|---|
| 입력 길이 | 제한 있음 (긴 코드 붙여넣기 어려움) | 사실상 무제한 (파일을 직접 읽으므로) |
| 출력 길이 | 제한 있음 (응답이 길면 잘림) | 사실상 무제한 |
| 파일 접근 | 직접 업로드 필요 | 프로젝트 폴더 전체를 자동 인식 |
| 연속 작업 | 매번 컨텍스트를 다시 설명해야 함 | 대화가 이어지면서 맥락 유지 |

### 2. AI가 "알려주는 것"이 아니라 "직접 합니다"

웹 채팅에서 "이 파일의 3번째 줄을 수정해줘"라고 하면, AI가 수정된 코드를 텍스트로 보여줍니다. 그걸 복사해서 에디터에 붙여넣는 건 내 몫입니다.

클로드 코드에서 같은 요청을 하면, **AI가 직접 파일을 열고 3번째 줄을 수정하고 저장합니다.** 내가 할 일은 수정 내용을 확인하고 승인(Y)을 누르는 것뿐입니다.

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112472992-y9lju1.png)


### 3. 내 컴퓨터의 모든 도구를 쓸 수 있습니다

웹 채팅은 브라우저 안에 갇혀 있습니다. 하지만 CLI에서는 AI가 **터미널에서 실행 가능한 모든 명령어를 사용**할 수 있습니다.

- 코드 빌드 및 테스트 실행
- Git으로 버전 관리 (커밋, 브랜치 등)
- npm, pip 같은 패키지 설치
- 데이터베이스 조회
- 파일 검색 및 분석

AI가 단순한 답변 도구가 아니라, **내 컴퓨터에서 일하는 동료**처럼 작동합니다.

### 4. 사용량 제한이 훨씬 넉넉합니다

Claude.ai 웹의 무료 플랜은 하루 사용량 제한이 빠르게 찼습니다. Pro 플랜(유료)에서도 일정량을 초과하면 속도가 느려지는 제한이 있습니다.

클로드 코드는 **API 기반으로 작동**하기 때문에, 사용한 만큼만 비용을 내는 구조입니다. 웹처럼 "오늘 사용량을 초과했습니다"라는 메시지를 만날 일이 적습니다. Max 플랜을 이용하면 정액제로 사용하는 것도 가능합니다.

## 그래서, CLI 말고 다른 방법은 없나요?

있습니다. 클로드 코드를 꼭 터미널에서만 써야 하는 건 아닙니다.

### VS Code, Cursor, Antigravity  같은 코드 에디터 안에서 쓰기

VS Code(Visual Studio Code)는 가장 많이 사용되는 코드 에디터입니다. 클로드 코드는 **VS Code의 터미널 패널에서 바로 실행**할 수 있습니다.

VS Code의 좋은 점은 왼쪽에는 파일 탐색기, 가운데는 코드 편집 화면, 아래쪽에 터미널이 있어서 **코드를 보면서 동시에 AI와 대화할 수 있다**는 것입니다. 순수 터미널보다 훨씬 친숙한 환경입니다.

![image](https://avqz4vnz10fk0ilw.public.blob.vercel-storage.com/uploads/1773112506391-f8lksf.png)


## 클로드 코드 시작하기 : 설치부터 첫 대화까지

실제로 어떻게 시작하는지 간단히 안내합니다.

### 1단계 : Node.js 설치

클로드 코드는 Node.js라는 프로그램이 필요합니다. [nodejs.org](https://nodejs.org/ko/download)에서 LTS 버전을 다운로드해서 설치하면 됩니다. 설치 과정은 일반 프로그램 설치와 동일합니다. 다운로드 → 더블클릭 → 다음 → 완료.

### 2단계 : 클로드 코드 설치

터미널을 열고 아래 명령어를 입력합니다.

```
npm install -g @anthropic-ai/claude-code
```

이 한 줄이면 설치 끝입니다.

### 3단계 : 실행

작업하고 싶은 폴더로 이동한 뒤, 아래 명령어를 입력합니다.

```
claude
```

처음 실행하면 Anthropic 계정 로그인을 요청합니다. 로그인하면 바로 AI와 대화를 시작할 수 있습니다.

### 4단계 : 대화하기

이제부터는 웹 채팅과 같습니다. 한국어로 원하는 작업을 요청하면 됩니다.

- "이 프로젝트의 구조를 설명해줘"
- "README 파일을 만들어줘"
- "이 에러를 고쳐줘" (에러 메시지를 붙여넣기)
- "새로운 페이지를 추가해줘"

AI가 파일을 수정하거나 명령어를 실행할 때는 **반드시 사용자에게 승인을 요청**합니다. 실수로 중요한 파일이 날아가는 일은 없으니 안심하세요.

## 자주 묻는 질문

### Q. 코딩을 전혀 모르는데 클로드 코드를 쓸 수 있나요?

기본적인 대화는 가능하지만, 클로드 코드의 주 용도는 코딩 작업입니다. 코딩 지식이 전혀 없다면 Claude.ai 웹이나 Claude Desktop 앱이 더 적합합니다. 다만, AI에게 "하나하나 설명해줘"라고 요청하면서 코딩을 배우는 용도로는 클로드 코드가 매우 효과적입니다.

### Q. 터미널에서 실수로 잘못된 명령어를 치면 컴퓨터가 망가지나요?

일반적인 명령어로는 컴퓨터가 망가지지 않습니다. 그리고 클로드 코드는 위험한 작업을 실행하기 전에 항상 사용자 승인을 요청하기 때문에, 무심코 엔터를 누르는 것만 조심하면 됩니다.

### Q. 클로드 코드는 무료인가요?

Claude Code 자체는 무료로 설치할 수 있지만, 사용 시 API 비용이 발생합니다. Anthropic 계정에 결제 수단을 등록하고 사용한 만큼 비용을 내는 방식입니다. 또는 Claude Pro/Max 구독이 있으면 해당 플랜의 사용량 내에서 쓸 수 있습니다.

### Q. Windows에서도 되나요?

됩니다. Mac, Windows, Linux 모두 지원합니다. Windows의 경우 PowerShell이나 WSL(Windows Subsystem for Linux)에서 사용할 수 있습니다.

## 마무리

CLI는 낯선 인터페이스일 뿐, 어려운 기술이 아닙니다. **텍스트를 입력하면 결과가 나오는 구조**는 웹 채팅, 카카오톡, 검색창과 정확히 같습니다. 화면이 예쁘지 않을 뿐이죠.

그리고 그 "예쁘지 않은 화면" 덕분에 오히려 입출력 길이 제한 없이 AI를 활용할 수 있고, AI가 직접 파일을 수정하고, 내 컴퓨터의 모든 도구를 사용할 수 있습니다.

클로드 코드를 쓰기 위해 CLI 전문가가 될 필요는 없습니다. `claude`라고 한 단어만 치면 시작할 수 있으니까요. VS Code 같은 익숙한 환경에서 터미널 패널로 시작하는 것도 좋은 방법입니다.

**3줄 요약:**
- CLI는 텍스트로 컴퓨터를 조작하는 방식일 뿐이고, 웹 채팅에서 질문을 입력하는 것과 구조가 같습니다. 검은 화면이 무서워 보여도 실제로는 별거 아닙니다.
- 클로드 코드를 CLI에서 쓰면 입출력 길이 제한이 없고, AI가 파일을 직접 수정하고, 내 컴퓨터 도구를 모두 활용할 수 있어서 웹 채팅보다 강력합니다.
- CLI가 부담스러우면 VS Code 안의 터미널 패널에서 시작하세요. 터미널 테마를 밝게 바꾸는 것만으로도 거부감이 줄어듭니다.
