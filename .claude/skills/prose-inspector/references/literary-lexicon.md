# 문어체 대체 사전

`scripts/check-literary.mjs`가 검출하는 항목의 근거와 대체안. **사용자 교정 이력에서만 늘린다.**

## 등록 원칙

- 근거가 확인된 것만 넣는다: 사용자 직접 지적, `writing-style-guide.md`, 메모리 규칙
- 추측으로 넣지 않는다. 오탐이 늘면 스킬 전체가 무시된다
- 맥락에 따라 허용되는 표현은 `WARN`으로 넣는다
- 한국어는 단어 경계가 없으므로 `결`, `갈래` 같은 짧은 말은 `solo()` 헬퍼로 앞뒤 한글을 배제한다

## HARD: 번역투 구문

| 표현 | 대체 | 근거 |
|---|---|---|
| ~는 데서 옵니다 | ~때문에 생깁니다 | 2026-08 교정 |
| 의미를 갖다 | 소용이 있습니다, ~에 쓰입니다 | 2026-08 교정. `have meaning` 직역 |
| ~와는 무관합니다 | ~와는 상관이 없습니다 | 2026-08 교정 |
| 존재가 아닙니다 / 존재입니다 | 주어를 살려 동사로 서술 | 2026-08 교정. "훑어보는 존재가 아닙니다" → "훑어보지 않습니다" |

| ~에 다름 아니다, ~인 바 | ~입니다 | 일반 문어체 |

## WARN: 맥락에 따라 허용

기계로 판정하지 않는다. 낭독 검수에서 결정한다.

| 표현 | 허용되는 경우 | 바꿔야 하는 경우 |
|---|---|---|
| 짚다 | "손으로 짚다" 같은 실제 동작 | "문제를 짚다" 같은 추상 용법 → 확인하다 |
| 쪼개다 | 물리적으로 나누는 비유 안 | 일반 서술 → 나누다 |
| 구간 | 측정, 시간, 거리 맥락 | "개념을 쌓는 구간" 같은 추상 용법 → 부분, 단계 |
| 좌우하다 | 실제로 결정적일 때 | 과장이면 → 결정합니다, 달라집니다 |
| 덩어리 | 물리적 묶음 | "한 덩어리가 아니라" → 하나의 작업이 아니라 |

## 검출되지 않는 층위 (낭독 검수 전담)

사전으로 잡을 수 없어 사람이 읽어야 하는 항목. 실제로 이번 세션에서 나온 사례다.

| 유형 | 잘못된 예 | 고친 예 |
|---|---|---|
| 호응 어긋남 | 세 **동사**가 순서대로 **일어난다** | 세 **단계**가 순서대로 일어난다 |
| 주어 누락 | 상품이 많은 사이트에서 자주 나옵니다 | **이 상황은** 상품 수가 많은 사이트에서 자주 나옵니다 |
| 목적어 누락 | 낯선 개념은 비유와 예시로 **연결합니다** | 비유와 예시를 **먼저 두고 설명합니다** |
| 주어와 술어 불일치 | **세 이유는** 해법이 전혀 다릅니다 | **이유가 다르면** 해야 할 일도 전혀 다릅니다 |
| 명사 나열 압축 | 가게가 있다는 **사실 자체를** 본 사람이 없습니다 | 가게가 **생긴 것을** 본 사람이 없습니다 |
| 표와 도표 누락 검사 | 마크다운 표 헤더 `읽을 수 있는가` | `가독성` |
| 인접 문장 종결 반복 | ~않습니다. ~않습니다. | 한쪽을 다른 어미로 |

## 표와 HTML 도표 주의

본문만 검사하면 샌다. 이번 세션에서 반말 의문형이 **마크다운 표 3건, 인라인 HTML 도표 3건**에서 나왔다.
`check-literary.mjs`는 `<[^>]+>`로 HTML 태그를 걷어내지만 태그 사이의 **텍스트는 검사 대상에 남는다.**
마크다운 표는 그대로 검사된다. 그래도 눈으로 한 번 더 본다.
