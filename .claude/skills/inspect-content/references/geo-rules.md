# GEO 점검 규칙 (R-GEO-01 ~ R-GEO-07)

Generative Engine Optimization — 생성형 AI 검색 엔진이 콘텐츠를 인용 출처로 선택할 가능성을 높이는 신호. Princeton GEO 연구(KDD 2024) 기반.

가중치 합계 = 100. 대부분 결정론으로 판정 가능하다 — GEO는 통계/링크/연도 등 객관적 신호에 의존하기 때문.

---

## R-GEO-01: 출처 인용 (가중치 20) — 결정론

**결정론 패턴**
- `/(~에 따르면|~가 발표|~가 소개|연구|조사|보고서|보도)/`
- 외부 마크다운 링크: `/\[[^\]]+\]\(https?:\/\/[^)]+\)/` (단, 자사 도메인 `digitalmarketer.co.kr` 제외)
- 기관명 언급 패턴: `/(구글|Google|Meta|OpenAI|Anthropic|맥킨지|가트너|Gartner|Statista|Princeton)/`

**판정**
- PASS: 매칭 2개 이상
- PARTIAL: 1개
- FAIL: 0개

Fix 전략:
- "외부 출처 N개. 주제 관련 2차 자료 최소 2개 인용 권장. 예: `{주제} 관련 Statista/Gartner 보고서 링크 삽입`, `{관련 기관} 발표 자료 참조`"

---

## R-GEO-02: 통계 밀도 (가중치 15) — 결정론

**결정론 패턴**
- 숫자 + 단위: `/\d+(?:\.\d+)?(?:,\d{3})*\s*(?:%|퍼센트|배|달러|억|만 원|만원|원|명|건|개월|일|시간|회)/`
- 순서 표기(`1. ` `2. ` 등)는 제외해야 함 → 라인 시작 위치 검사

**카운트 방법**
```
matches = regex.matchAll(body)
filtered = matches where not at line start after `^\s*\d+\.\s`
count = filtered.length
```

**판정**
- PASS: count ≥ 3
- PARTIAL: 1 ≤ count ≤ 2
- FAIL: count = 0

Fix 전략:
- "본문에 구체적 수치 {count}개. 3개 이상 권장. 추가 후보: (a) 전환율/방문자 관련 통계 (b) 시장 규모 수치 (c) 응답률 등 설문 데이터. 예: '{주제} 관련 업계 통계 X%'"

## R-GEO-03: 구조화 데이터 (가중치 15) — 결정론

**결정론 카운트**
- 표: `|` 포함 라인이 3개 이상 연속 → table 1개
- 불릿 리스트: `^\s*[-*+]\s` 시작 라인이 3개 이상 연속 → list 1개
- 번호 리스트: `^\s*\d+\.\s` 시작 라인이 3개 이상 연속 → list 1개
- 코드 블록: ` ``` ` 쌍

**판정**
- PASS: 표 1개 이상 AND 리스트 2개 이상, 또는 표 2개 이상
- PARTIAL: 표 0개 + 리스트 1개 이상, 또는 표 1개 + 리스트 0~1개
- FAIL: 순수 산문체만 (표/리스트 모두 없음)

Fix 전략:
- "구조화 요소 부족. 비교 표 1개 + 핵심 항목 불릿 리스트 1개 추가 권장. 예: `| 항목 | 설명 | 예시 |` 형식 표, `- 항목 1 - 항목 2` 리스트"

## R-GEO-04: 전문가 신호 (가중치 10) — 의미 판정

**결정론 보조**
- 패턴: `/(실무에서|직접|경험|운영해|담당하며|프로젝트에서|해보니|시도한 결과)/`

**의미 판정**
- 패턴 매칭만으로는 부족. 해당 서술이 실제 경험 기반인지, 일반론인지 판단
- "~하면 좋다"는 일반론, "실제로 ~했을 때 ~결과가 나왔다"는 경험

**판정**
- PASS: 경험 기반 서술 2개 이상
- PARTIAL: 1개 또는 결정론 패턴 매칭만 존재하고 의미 불분명
- FAIL: 완전 일반론

Fix 전략:
- "경험 기반 서술 부족. 다음 섹션에 실무 사례 추가 권장: `{해당 섹션}` → '실제 {프로젝트/상황}에서 {시도}했을 때 {결과}' 형식"

---

## R-GEO-05: 콘텐츠 신선도 (가중치 10) — 결정론

**결정론**
- 현재 연도(today.getFullYear())와 전년도 언급 카운트:
  - `/2026|2025/` 또는 현재/전년도 패턴
- 시점 마커: `/(최근|올해|지난달|이번 주|\d+월 기준|업데이트)/`

**판정**
- PASS: 연도 + 시점 마커 합산 2개 이상
- PARTIAL: 1개
- FAIL: 0개 (시점 정보 없음)

Fix 전략:
- "최신 시점 정보 부족. 도입부 또는 결론에 `{current_year}년 기준` 시점을 명시하고, 참조 데이터에 `{current_year}년 N월 업데이트` 표기 권장"

---

## R-GEO-06: 주제 권위 (가중치 15) — 결정론

**결정론 패턴**
- 내부 링크: `/\[[^\]]+\]\(\/(insights|class|course|tags)\/[^)]+\)/`
- 시리즈 소속: `frontmatter.seriesSlug` 존재 여부

**판정**
- PASS: 내부 링크 2개 이상, 또는 seriesSlug + 내부 링크 1개 이상
- PARTIAL: 내부 링크 1개
- FAIL: 내부 링크 0개, seriesSlug 없음

타입 예외:
- classes: `courseSlug`가 있으면 시리즈 소속과 동등하게 간주

Fix 전략:
- "내부 링크 {count}개. 관련 용어(class) 또는 연관 인사이트로 최소 2개 링크 추가 권장: `[{term}](/class/{slug})`, `[{related post}](/insights/{slug})`. 후보는 tags 교집합 또는 동일 카테고리에서 탐색"

---

## R-GEO-07: 인용 가능성 (가중치 15) — 결정론 + 의미 판정

**결정론**
- 본문을 문장 단위로 분리: `/[.!?。](?=\s|$)/`
- 각 문장 길이 측정 (한글 문자 수 기준, 공백 제외)
- 40 ≤ length ≤ 80 범위 문장 카운트

**의미 판정**
- 해당 범위의 문장들이 "맥락 없이도 의미가 완전한지" — 대명사 시작("이것은", "그래서")이면 제외
- 정의, 비교, 핵심 인사이트를 담고 있는가

**판정**
- PASS: 독립형 문장 3개 이상
- PARTIAL: 1~2개
- FAIL: 0개 (모든 문장이 짧거나 길거나 대명사 의존)

Fix 전략:
- "독립 인용 가능한 문장 부족. 각 H2 섹션 첫 줄을 40-80자 독립 문장으로 재작성 권장. 예: `{주제}는 {정의}입니다. {핵심 특징}이 차별점입니다.`"

## 실행 체크리스트

본문 파싱 후 순서:

```
1. 외부 링크/출처 패턴 카운트 → R-GEO-01
2. 수치+단위 정규식 매칭 → R-GEO-02
3. 표/리스트/코드블록 카운트 → R-GEO-03
4. 경험 서술 패턴 매칭 + 의미 판정 → R-GEO-04
5. 연도/시점 마커 카운트 → R-GEO-05
6. 내부 링크 + seriesSlug → R-GEO-06
7. 문장 길이 분포 + 의미 판정 → R-GEO-07
```

정규식은 한국어 메타문자 처리에 유의한다. 마크다운 마커(`**`, `*`, `_`)는 카운트 전에 제거한 정제 텍스트에 대해 실행하는 것이 안전하다.
