# AEO 점검 규칙 (R-AEO-01 ~ R-AEO-07)

Answer Engine Optimization — Google AI Overviews, Perplexity, ChatGPT 등의 답변 소스로 선택되기 위한 구조 최적화.

가중치 합계 = 100. 결정론 항목과 의미 판정 항목이 혼재되어 있으니 각 규칙의 판정 방식을 따른다.

---

## R-AEO-01: 직접 답변 (가중치 20) — 결정론 + 의미 판정

**결정론 단계**
- 첫 문단(첫 `\n\n` 전까지) 추출
- 문자 수 확인: 50 ≤ charCount ≤ 400
- 정의형 패턴 매칭: `/(란|은|는)\s.{2,40}(입니다|을 말합니다|이다|다)/`

**의미 판정 단계**
- 첫 문단의 답변이 제목(title) 또는 slug가 암시하는 질문에 실제로 대응하는가?
- "배경만 서술", "문제 제기만 있음"이면 FAIL

**판정**
- PASS: 결정론 + 의미 판정 모두 통과
- PARTIAL: 결정론만 통과, 의미 판정 불확실
- FAIL: 첫 문단이 배경/문제 제기만 있거나 400자 초과

Fix 전략:
- "첫 문단을 '결론 선행' 구조로 재작성. 예: '{slug 기반 질문}에 대한 답은 {핵심 답변}입니다. {보충 1문장}.'"

## R-AEO-02: FAQ 스키마 적합성 (가중치 15) — 결정론 + 의미 판정

**결정론**
- H2/H3 헤딩 중 `?`로 끝나는 개수 카운트
- 헤딩 바로 아래에 답변 문단(최소 20자)이 붙어 있는가

**의미 판정**
- Q&A 쌍이 2개 이상 의미상 대응하는가 (헤딩 질문과 본문 답변이 실제 연결되는가)

**판정**
- PASS: 질문형 H2/H3가 2개 이상 + 각 아래에 답변 문단 존재
- PARTIAL: 질문형 1개
- FAIL: 질문형 없음

타입 예외: classes는 정의형 콘텐츠이므로 PARTIAL까지만 적용(만점 없음도 페널티 없음 → PASS로 간주)

Fix 전략:
- "현재 H2 중 질문형 X%. 다음 섹션을 질문형으로 전환 권장: `## {현재}` → `## {질문형 변환}`"

## R-AEO-03: 질문형 헤딩 비율 (가중치 15) — 결정론

**결정론 계산**
```
questionHeadings = H2/H3 count matching:
  - ends with "?"
  - /(란|은 무엇|는 무엇|어떻게|왜|언제|어디서|얼마)/
totalHeadings = all H2/H3 count
ratio = questionHeadings / totalHeadings
```

**판정**
- PASS: ratio ≥ 0.30
- PARTIAL: 0.15 ≤ ratio < 0.30
- FAIL: ratio < 0.15 또는 H2/H3 없음 (insights만)

타입 예외:
- classes: 면제 → PASS
- courses: 면제 → PASS

Fix 전략:
- "H2/H3 N개 중 질문형 M개 ({ratio}%). 검색 의도에 대응하는 질문 형태로 최소 {target}개 변환 제안: `{현재}` → `{변환}`"

## R-AEO-04: 피처드 스니펫 포맷 (가중치 15) — 결정론

**결정론**
- 번호 리스트: `^\s*\d+\.\s` 로 시작하는 라인 3개 이상 연속
- 불릿 리스트: `^\s*[-*+]\s` 로 시작하는 라인 3개 이상 연속
- 표: `|` 문자 포함 라인 3개 이상 연속 (header + separator + row ≥ 1)
- 정의 문단: "X란 ~입니다" 또는 "X는 ~이다" 형태의 2~3문장 블록 (R-AEO-01과 중복 가능)

**판정**
- PASS: 위 4가지 중 2개 이상 형식 포함
- PARTIAL: 1개 포함
- FAIL: 순수 서술형만 (0개)

Fix 전략:
- "피처드 스니펫 포맷 부족. 다음 중 하나 추가 권장: (a) 핵심 절차의 번호 리스트 (b) 비교 표 (c) 3-7개 항목의 불릿 리스트"

## R-AEO-05: 핵심 요약 (가중치 10) — 결정론 + 의미 판정

**결정론**
- 본문에서 다음 패턴 검색:
  - `^## (요약|핵심|정리|TL;DR|한 줄 요약)` (H2 or H3)
  - 또는 본문 첫 200자 안에 "정리하면", "결론부터 말하면" 등 도입 마커

**의미 판정**
- 요약 섹션이 실제로 본문을 3줄 이내로 압축하고 있는가

**판정**
- PASS: 요약 헤딩 존재 + 본문 3문장 이내 압축
- PARTIAL: 요약 헤딩은 있으나 길이 초과
- FAIL: 요약 섹션 없음

Fix 전략:
- "글 마지막에 `## 요약` 섹션 추가 권장. 본문 핵심 3가지를 한 문장씩 정리"

---

## R-AEO-06: 음성 검색 친화 (가중치 10) — 결정론

**결정론**
- 구어체 질문 패턴 카운트:
  ```
  /(어떻게|왜|언제|얼마나|무엇|어떤)\s.{1,30}(까요|나요|죠|는가요|할까|일까)/
  ```
- "~는 무엇인가요", "~는 어떻게 하나요" 형태 포함

**판정**
- PASS: 구어체 질문 문장 2개 이상
- PARTIAL: 1개
- FAIL: 0개

Fix 전략:
- "음성 검색 쿼리에 대응되는 구어체 질문 문장 1~2개를 본문에 삽입. 예: '그럼 {X}는 어떻게 해야 할까요?'"

## R-AEO-07: 엔티티 명확성 (가중치 15) — 의미 판정

**결정론 보조**
- 영문 고유명사/약어 패턴 `[A-Z]{2,}`, `[A-Z][a-z]+[A-Z][a-z]+`를 본문에서 추출
- 각 용어가 본문에서 처음 등장할 때 20자 이내 근처에 설명이 있는지 확인

**의미 판정**
- 주요 전문 용어(GA4, MCP, API 등)가 첫 등장 시 "X란 ~입니다" 또는 "X(영어명)는 ~" 형태로 정의되는가
- 본문에서 가장 자주 등장하는 고유 용어 2~3개를 대상으로 판정

**판정**
- PASS: 주요 용어 2개 이상이 첫 등장 시 정의됨
- PARTIAL: 1개만 정의
- FAIL: 전문 용어가 설명 없이 사용됨

Fix 전략:
- "용어 `{term}` 정의 누락. 첫 등장 위치에 삽입: `{term}(풀네임)은 ~입니다.`"

---

## 점수 산출

영역 점수 = Σ(PASS 가중치) + Σ(PARTIAL 가중치 × 0.5)

결정론 판정 부분은 반드시 먼저 실행하고, 의미 판정이 필요한 항목(R-AEO-01 본문 답변 대응, R-AEO-02 Q&A 의미 연결, R-AEO-05 요약 품질, R-AEO-07 엔티티 정의)은 결정론 결과를 뒤집거나 PARTIAL로 낮추는 용도로만 사용한다.
