# GEO(Generative Engine Optimization) 체크리스트

생성형 AI 검색 엔진이 콘텐츠를 인용 출처로 선택할 가능성을 높이기 위한 최적화 기준입니다.
Princeton 대학의 GEO 연구(KDD 2024)와 실무 사례를 기반으로 작성되었습니다.

## 점검 항목

### 1. 출처 인용 (가중치: 20)

**기준**: 2개 이상의 외부 출처 참조가 포함되어 있는가.

인정되는 형태:
- "~에 따르면", "~의 연구에서", "~가 발표한 자료에 의하면"
- 외부 링크 또는 출처 명시
- 기관명/연구명 구체적 언급

- PASS: 2개 이상 외부 출처
- PARTIAL: 1개
- FAIL: 외부 출처 없음

**Princeton 연구 결과**: 출처 인용 추가 시 AI 가시성 약 30~40% 향상

### 2. 통계 밀도 (가중치: 15)

**기준**: 2개 이상의 구체적 수치 데이터가 맥락과 함께 제시되어 있는가.

인정되는 형태:
- "전환율이 23% 증가했습니다"
- "2026년 기준 시장 규모는 1,200억 달러입니다"
- "응답자의 67%가 ~라고 답했습니다"

단순 나열 비인정: "1, 2, 3단계" 같은 순서 숫자는 통계로 간주하지 않음

- PASS: 3개 이상 통계
- PARTIAL: 1~2개
- FAIL: 구체적 수치 없음

**Princeton 연구 결과**: 통계 추가 시 AI 가시성 약 30~40% 향상

### 3. 구조화 데이터 (가중치: 15)

**기준**: 콘텐츠에 다음 구조화 요소가 적절히 사용되어 있는가.

- 마크다운 표 (비교, 정리)
- 불릿/번호 리스트
- 코드 블록 (기술 콘텐츠의 경우)
- 명확한 H2/H3 계층 구조

- PASS: 표 1개 이상 + 리스트 2개 이상, 또는 표 2개 이상
- PARTIAL: 리스트만 있고 표 없음
- FAIL: 순수 산문체만 존재

### 4. 전문가 신호 (가중치: 10)

**기준**: 콘텐츠에 전문성/경험을 나타내는 신호가 포함되어 있는가.

인정되는 형태:
- "실무에서 확인한 결과", "직접 운영해 본 경험으로는"
- "N년간 ~를 담당하며", "실제 프로젝트에서"
- 특정 도구/방법론의 구체적 사용 사례

- PASS: 2개 이상 경험 기반 서술
- PARTIAL: 1개
- FAIL: 일반론만 서술, 경험적 근거 없음

### 5. 콘텐츠 신선도 (가중치: 10)

**기준**: 올해 또는 최근 6개월 이내의 정보/이벤트를 참조하고 있는가.

인정되는 형태:
- "2026년 3월 기준", "최근 업데이트에 따르면"
- 올해 출시된 도구/기능 언급
- 최신 통계 데이터 인용

- PASS: 2개 이상 최신 참조
- PARTIAL: 1개
- FAIL: 시점 정보 없이 일반적 서술만 존재

### 6. 주제 권위 (가중치: 15)

**기준**: 해당 주제에 대한 사이트의 권위를 보여주는 신호가 있는가.

인정되는 형태:
- 같은 주제의 다른 글로 이어지는 내부 링크 1개 이상
- 시리즈 소속 (연속성 있는 콘텐츠)
- 관련 용어 사전(Class) 또는 FAQ와의 교차 참조
- 일관된 전문 용어 사용

- PASS: 내부 링크 2개 이상 또는 시리즈 소속 + 내부 링크 1개
- PARTIAL: 내부 링크 1개
- FAIL: 내부 링크 없음, 고립된 콘텐츠

### 7. 인용 가능성 (가중치: 15)

**기준**: AI가 직접 인용할 수 있는 독립형 문장(standalone sentence)이 2개 이상 있는가.

인용 가능한 문장의 특징:
- 맥락 없이도 의미가 완전한 문장
- 정의, 비교, 핵심 인사이트를 담고 있음
- 40~80자 사이의 간결한 길이
- 예: "MCP는 AI의 USB 포트입니다. 외부 서비스를 AI에 연결하는 표준 규격입니다."

- PASS: 3개 이상
- PARTIAL: 1~2개
- FAIL: 모든 문장이 전후 맥락 없이는 의미 불완전

## 점수 산출

총점 = 각 항목 (PASS=가중치 만점, PARTIAL=가중치 50%, FAIL=0) 합산

| 등급 | 점수 범위 |
|------|----------|
| A | 80-100 |
| B | 60-79 |
| C | 40-59 |
| D | 0-39 |

## 참고: Princeton GEO 연구의 9가지 최적화 기법 (효과 순)

1. 출처 인용 (Cite Sources) +30~40%
2. 통계 추가 (Add Statistics) +30~40%
3. 전문가 인용 (Quotation Addition) +약 20%
4. 기술 용어 사용 (Technical Terms) +약 15%
5. 권위 있는 어투 (Authoritative Tone) +약 10%
6. 유창한 표현 (Fluency Optimization) +약 5%
7. 독자 친화 언어 (Easy to Understand) +약 5%
8. 키워드 스터핑 (Keyword Stuffing) -15% ← 역효과
9. 짧은 답변 강제 (Forced Brevity) -10% ← 역효과
