# SNS 카피 문체 규칙

hongblog 본문 규칙(`~/.claude/korean-prose.md`)을 SNS에 맞게 조정한 것이다.
SNS는 짧고 구어에 가깝지만, 번역투와 과장, AI 티는 본문보다 더 빨리 들킨다.
피드에서는 한 문장만 어색해도 스크롤로 넘어가기 때문이다.

## 그대로 지키는 것 (HARD)

| 항목 | 이유 |
|---|---|
| 줄표(—), 가운뎃점(·), 말줄임표(…) 금지 | SNS에서도 그대로 위반이다. 쉼표와 마침표로 끊는다 |
| 번역투 11종 금지 | "~에 대해", "~을 통해", "~중 하나입니다", "~에 의해", 이중 피동 |
| 과장 수사 금지 | "혁명적", "마법처럼", "놀랍게도", "차원이 다른", "상상초월" |
| AI식 지시문 금지 | "상상해 보세요", "기억해 두세요", "주목해 주세요" |
| 근거 없는 최상급 금지 | "가장 중요한", "최초로", "역대급" |
| 검증 안 된 단정 금지 | 블로그 본문에 없는 수치나 주장을 SNS에서 새로 만들지 않는다 |
| 맞춤법 | 콘텐츠(o) 컨텐츠(x), 메시지(o) 메세지(x) |

## 완화하는 것 (SNS 특성)

| 항목 | 본문 규칙 | SNS에서는 |
|---|---|---|
| 문장 길이 | 완결 문장 | 명사형 종결, 한 단어 문장 허용 ("이게 문제입니다." → "여기서 막힙니다.") |
| 어투 | 합쇼체 통일 | 합쇼체 기본. 쓰레드는 해요체 섞어도 된다. 한 게시물 안에서는 하나로 |
| 문단 | 완결된 단락 | 한두 문장마다 줄바꿈. 모바일 화면에서 벽처럼 보이지 않게 |
| 제목 규칙 | 완결 문장 | SNS 훅은 명사구, 질문형 모두 허용 |

## SNS에서 특히 조심할 것

**이모지**: 아예 안 쓰거나, 게시물당 1~2개까지. 문장마다 붙이면 광고 계정처럼 보인다.
이모지로 감정을 대신하지 말고 문장으로 쓴다. 불릿 대신 쓰는 이모지(🔹, ✅)는 특히 AI 티가 난다.

**느낌표**: 게시물당 최대 1개. 없어도 된다. 느낌표가 두 개 이상이면 톤이 급하게 들린다.

**뻔한 훅 금지**: "여러분 이거 아셨나요?", "충격적인 사실", "이것만 알아도", "1분이면 끝",
"모르면 손해" 같은 문구는 쓰지 않는다. 정보를 정직하게 요약하는 쪽이 오래 간다.

**본문에 없는 말 금지**: SNS 카피는 블로그 글의 요약이지 창작이 아니다.
수치, 날짜, 제품명, 조건은 본문에서 그대로 가져온다. 기억으로 채우지 않는다.

**질문으로 시작하지 않기**: "~해보신 적 있나요?"로 시작하는 도입은 AI 카피의 전형이다.
질문을 쓰려면 게시물 중간이나 끝의 CTA 자리에 하나만 둔다.

**같은 어미 반복 금지**: 짧은 글일수록 "~습니다"가 세 번 연속되면 기계적으로 들린다.
명사형 종결이나 "~죠", "~더군요"를 섞어 리듬을 만든다.

## 카드뉴스 문구 어휘 (2026-08-04 사용자 교정)

카드와 SNS 문구는 블로그 본문보다 한 단계 더 일상어로 쓴다. 문법상 맞아도
딱딱한 한자어 동사는 피드에서 어색하게 읽힌다.

| 딱딱함 | 자연스러움 |
|---|---|
| 원문과 대조하세요 | 원문과 꼭 비교해 보세요 |
| 확인이 필요합니다 | 꼭 확인해 보세요 |
| 검토를 권합니다 | 한번 살펴보세요 |

"꼭", "한번" 같은 부사를 더해 말하듯 만드는 것이 요령이다. 판단 기준은
"동료에게 말로 할 때 그대로 나오는 문장인가"이다.

## 자기 검수 질문 다섯 개

작성 후 소리 내어 읽는다고 가정하고 점검한다.

1. 첫 문장이 스크롤을 멈추게 하는가, 아니면 뻔한 도입인가
2. 블로그 본문에 없는 내용을 지어내지 않았는가
3. 이모지와 느낌표가 규칙 안에 있는가
4. 인접한 두 문장의 끝이 겹치지 않는가
5. 광고 문구처럼 들리는 문장이 있는가
