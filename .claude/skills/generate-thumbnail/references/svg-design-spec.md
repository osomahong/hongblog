# SVG 썸네일 디자인 스펙

## 캔버스

- 크기: 1200 x 630px (OG 표준)
- 출력: PNG (via @resvg/resvg-js)
- 폰트: Pretendard OTF (`node_modules/pretendard/dist/public/static/`)

정사각형 크롭(카카오톡): 중앙 630x630 → 제목 텍스트 보존

## 배경 레이어 (하→상)

1. `#F3F3F3` 베이스
2. 도트 그리드: 40x40, `#D0D0D0`, r=1.5
3. 코너 장식: 좌상(-12°), 우하(12°), 카테고리 색상 12% opacity
4. 8px 검정 인셋 테두리

## 장식 요소 (우측)

영역: x=900~1120, y=120~520

### MARKETING: 겹친 오프셋 사각형
- 3개 사각형, 크기 감소 (140→120→100)
- 빨강 fill (opacity 0.25→0.15), 4px 검정 테두리
- 각각 -6°, 4°, -3° 회전

### AI_TECH: 연결 노드 그래프
- 6개 노드(원), 7개 엣지(선)
- 금색 fill (opacity 0.35), 3px 검정 테두리

### DATA: 추상 바 차트
- 5개 바, 높이 [200, 140, 260, 180, 220]
- 파랑 fill (opacity 0.3), 3px 검정 테두리
- 하단 기준선 4px
