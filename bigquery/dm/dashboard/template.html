데이터 출처

GA4 속성 520024278의 일별 내보내기와 Search Console 대량 내보내기를 hong-project2511(asia-northeast3)에서 analytics_dm으로 가공한 값이다. 로컬 개발 트래픽은 제외했다.

갱신 주기

예약 쿼리 네 건이 매일 UTC 23:00부터 20분 간격으로 돈다. events → sessions → content_daily → search_content_daily 순서다. GA4 내보내기가 일별뿐이라 D-1이 상한이고, 검색면 지표는 Search Console 사후 보정을 반영하려고 최근 10일을 다시 만든다.

읽을 때 주의

검색어는 페이지별 일간 상위 10개만 담아서 합산값이 전체 노출보다 작다. 익명 처리된 검색어는 페이지 합계에는 들어가고 검색어 표에는 빠진다. 평균 순위는 노출 가중 평균이다.
